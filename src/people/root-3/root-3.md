根号三，游戏名 root 3。名字是数学题，玩法是应用题：怎么用一条巡洋打多人，怎么把九张击杀换成两亿，怎么退出联盟之后还跟老朋友聊天而不触发全联盟警报。

他在[2020 年末的个人回忆录](https://tieba.baidu.com/p/7173850192)开头先立了一块牌坊：“不针对某一团体，但是精准针对所有提到过的人。”往下果然教官、朋友、军团长、联盟老板挨个登场，一部 PVP 成长史，写着写着就写成了离职交接纠纷。

::: 红料 从打捞仔到欧莎三哥
据本人回忆，2019 年先在国服跟教官练护卫单挑，随后来到欧服，进了 AOM 的泛银河共和大学。起步办法十分朴素：催朋友开无畏刷怪，自己开促进跟后面打捞；后来氪金上无畏，借钱吃脑浆，每天刷三小时，一个月还清。未来的收割手，先把自己刷成了标准生产人口。

随后他用小号 hg-joe 到 TST 混低安，跟吉纳卡道标学小船，给自己定下百次单杀的目标。拿够击杀、挂好 Loki，便回到欧莎，跟桂花树、辰枫开双 Loki 抓毒蜥、伊什塔。第一次被子根剧本掉，第二次换船再来；后来发现刷怪的人学会规避，就改为逐星系扫人。

这段经历最有意思的变化，是昨天追着他杀的人，后来成了虫洞队友。敌对本地从骂街变成一句“三哥好”，他也回一句早上好——船照炸，招呼照打，终于有点玩家之间过招的味道。[来源：回忆录第 12、31、41、69 楼](https://tieba.baidu.com/p/7173850192)。
:::

::: 红料 VNI 出门，巡洋也有自己的天花板
Loki 蹲得久了，他开始嫌无聊，受深渊漫步录像启发改玩 Vexor Navy Issue，捏纤维四处打架，不死不回，后来加上截击前置，摸出了自己的多开习惯。本人说，常规单杀旗舰、出了录像，还拿到久不上线的军团长送的一张月卡。

这份自述背后也有实打实的战斗积累：取材时 zKillboard 收录 **4195 次击杀、587 次单杀**，常用船前两位是 Loki 与 Vexor Navy Issue。三哥的履历不是靠论坛签名挂出来的，至少船确实一直在飞。[自述](https://tieba.baidu.com/p/7173850192)，[角色战绩](https://zkillboard.com/character/2115523951/)。
:::

::: 红料 三次邀请没接，最后去找一群三哥
按本人说法，[路小兔](../2115301692/)问过要不要资助他打 FRT，[N老板](../1618197191/)也来私聊，子根与 0204 USB 又邀他进洞；他当时都没接。后来尝试过 FPC，仍觉得刷任务无聊，便找[斑鸠](../2113386745/)加入 F1 Monkey.——他的想象很直白：想知道“一堆根号三出去收割是啥感觉”。

回忆录写到这里终于扬眉吐气：在 AOM 一年约一千四百次击杀，加入 F1 不到三个月又增加九百多；还有了参加比赛的机会，本人记作队伍第七名。这个名次按他的当年自述记，最开心的却不只是名次，而是打完能互道 GF，不必每次炸船都先讨论民族大义。[来源：第 69、83 楼](https://tieba.baidu.com/p/7173850192)。
:::

::: 黑料 把击杀福利刷成了制度补丁
[军用馒头](../2115140351/)当年的福利，据三哥自述，是九张 FRT 高价值击杀换两亿 ISK。他领了七十亿；还跑去 008 军团领击杀福利，一个月又拿七十多亿，最后“害得他们改了福利制度”。

别人的加盟礼是月卡，他的离职纪念品是制度修订。后来 008 的小背心拿这件事说他，三哥反问：入团是你同意的，规则是你定的，击杀是我打的，如今怎么又成我的问题？这笔账两边算得都很顺，只是一个按制度结算，一个按感情追缴。本人把这个操作写进了回忆录，连替会计省点面子的意思也没有。[来源：第 70、84 楼](https://tieba.baidu.com/p/7173850192)。
:::

::: 黑料 声望重置了，人情账却没清零
加入 F1 后，三哥说自己曾避开 AOM 生产船，洞开到欧米斯特还劝队友压掉。后来队伍在非塔波利斯吃了两条小航，AOM 压洞、起超旗围堵，他便认为再避让说不过去了。再往后，桂花树回来叫他上 YY 聊天，误给蓝马，引出封 IP、撤马和馒头的公开怒骂。

三哥的回应也不是客气话：在回忆录里把联盟 CEO 骂成不懂游戏的“半吊子云玩家”，军团管理被挨个点名。吧友 yu37980000 在 146 楼反过来批他：以前对你好，只要后来有一点不顺心，就立刻喷人曝光；他在[另一个本地争吵帖](https://tieba.baidu.com/p/7230494549)里又以“声望摆在那里”回应旧友质疑，对方就追问：离开之后声望重置，朋友是不是也全部重置？

三哥坚持自己要的是纯粹 PVP，旧东家惦记的是培养与交情。一个按游戏规则开火，一个按旧情判断为人，最后谁都觉得对方没听懂。偏偏他说“我不在乎”，又认真写完了一整篇长文——三哥不在乎的事情，读者倒是都有机会在乎一下。[离职风波与反对意见](https://tieba.baidu.com/p/7173850192)。
:::

::: 评
根号三把 EVE 玩成了一套不断升级的解题过程：护卫练手，Loki 积累，VNI 找乐子，虫洞找队友。最难的一道题却一直没有标准答案：声望可以清零，人情到底能不能。

至少在福利这一科，他答得太好了，老师只好把卷子改了。
