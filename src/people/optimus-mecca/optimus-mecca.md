娃娃，游戏角色 Optimus Mecca，B站的“星月也想睡觉”。2018年，他就挂着“娃上将出品”教采星玩家开大航刷怪，简介还招呼新人有问题就私聊 PAN-STARRS。有人来学操作，有人嫌门槛高得扯着蛋，还有人怀疑这堂课是在把萌新往昂贵的大船上推。一堂刷怪课，评论区先打起了招生官司。

他在贴吧用“国际小米兰”写[欧服周年回忆录](https://tieba.baidu.com/p/6064853777/)，把自己叫作“双泰坦莽夫无名小卒”：偶像是[N老板](../1618197191/)，买了拉格纳洛克就想学着满底特波色，交过罚款，被抓还要跑去外文语音求救。别人夸他敢飙，也有人骂他玩心太重、出了事让队友擦屁股。教别人发财的人，自己的娱乐账单也不算清静。

到了2026年，这位老教师又给自己安排了一场“萌新大航搬家被抓”：简介哭着感谢W佬救命，观众却纷纷说是钓鱼。他自己接了一句“演员的自我修养（）”。娃上将的课堂开了多年，萌新这个角色倒一直给自己留着。

::: 红料 徐朗给船，他给后来人开课
按2019年的回忆录，娃娃回到欧服后，真正把他领进采星的是徐朗：介绍联盟分布、华人圈的位置，还赞助数罐脑浆和一条神装绝念。他变卖旧驻地资产去了 KZ9T，开始刷刷刷。后来自己录大航教学，也有观众在帖子里说“跟你学的大航刷怪和投弹”，他对教程称赞回了“谢谢QWQ”。

看样子，采星这条教学链很直观：前辈先给船和脑浆，后辈再给视频。娃娃没有把第一条船供成纪念品，而是顺着这条路把课堂越开越贵；新人能不能跟上另说，旗舰的梦想倒传得很快。
:::

::: 红料 偶尔上线，定向多看一眼就撞上大航
2019年7月，他发[《论收割时斥候坚持纪律性的好处》](https://tieba.baidu.com/p/6201112799/)。[炒鸡](../2117995654/)问“我还以为你AFK了”，他承认确实不怎么玩，只是当天上线一次，跟队时定向留了个心眼。

他说自己扫到八个杆子、七个力场；打掉第一个“鸡窝”后，又扫到隔壁的机库和没力场的杆子，“直接起飞”。帖子晒出的超大型船舶维护阵列掉落清单里，真有一条夜神。观众追问那条夜神开回去了没，他先在楼里喊“咸鱼牛逼”。

别人上线找活动，他偶尔上线就找到了别人的停车场。标题还一本正经讲斥候纪律，实际奖励却是一堂教人别把大航忘在没力场的地方的课。
:::

::: 红料 大航课堂，学生反过来补讲义
2018年5月的[《采星者联盟大航刷怪教学和pyfa初探/骑脸心得》](https://www.bilibili.com/video/BV1qp411Z7yT/)留下了真来学习的观众：有人刚买小航，把大航当下一个目标；有人还在打捞，就先来旁听。2020年，Lovight又在评论区补了“课代表总结”，解释舰载机指派快捷键与船体 Approach 共用，以及如何切换锁定目标。娃娃回他“感谢感谢”，承认早期视频里不少操作自己也是后来逐渐学会的。

同年8月的[泰坦波色与大航进阶教学](https://www.bilibili.com/video/BV14s411F7Hh/)更把口号推到“三开大航不是梦”。观众问配装、问多开小窗口，也有人直接喊“娃娃你又来带坏人了”。看样子，他的教学很容易把人教出下一笔预算：眼前这条船还没开明白，下一条的梦想已经排好队了。

下面的作品精选从这两篇老课堂接到后来的战斗与军团生活。

::: 红料 三开是梦想，十开成了评论区的大脑疑问
2025年10月，他又发了[《司令&W佬反时区CFI队大战SUS掠夺凤凰队！十开月刃缪宁后勤第一视角》](https://www.bilibili.com/video/BV1gty2BdEGH/)，简介写“战损手速双赢”，并附战报。观众“烦恼泡沫”直接赞“十开跟队，娃娃太强了”，另一人说自己双开都手忙脚乱，还有人问“你有几个大脑”。

从早年教学喊“三开大航不是梦”，到如今把十开后勤挂在投稿标题上，娃娃给观众出的题越来越像手忙脚乱测试。课堂还在，学费未必先交，手指大概得先练。

::: 红料 告别怯薛，游戏还得继续

::: 黑料 UALX逃出监狱，最后五秒还在纠正操作
回忆录里最像娃上将的一段，是借朋友的神使 去 UALX。他说自己只签到一条星城，剩下时间都在掉线，号主一直喷他。等到终于要撤，N老板让泰坦吃电池、换扫射炮、清拦截，最后喊能跳的赶紧跳。他偏偏脑子一抽，先跃迁向本地小堡垒。

半路才想起来：能旗舰跳走，自己跃迁干什么？临近维护，落点还有敌对拦截与泡泡。按他的说法，最后五秒泡泡刚好消失，他疯狂右键电容、点跳跃，在关服窗口弹出前落到了诱导铁壁。

朋友把泰坦借给他去打架，结果先陪他掉线，再陪他赶关服末班车。平日教人开大航，到了这种时刻，老师也得靠最后五秒抢答。

::: 黑料 自己飙自己负责，捞过他的队友来对账
2019年3月12日，他在回忆录里一面说交过几次波色罚款，一面自嘲“逆时区波色，被抓了跑到老外mumble疯狂呼救”。他自述波过HK租地狞獾队、两次Goons大捷队和Goons的BC3队，第二次打大捷还险些翻车，并感谢老杨替他打泡泡。对泰坦损失的态度也很豪迈：早备好秒补的钱，“没有fax的飙车才刺激”。蓝色松露在楼里批他“个人主义的飙超期”，说自己的船当然能折腾，但出了事又要别人擦屁股。

三天后，他专门发[《针对老李大酱的回复》](https://tieba.baidu.com/p/6068103998/)，向[老李](../2113515731/)划清账目：“我从来没让fax救过，我也不带诱导，自己飙自己承担后果”，又说自己没有在YY或mumble大喊“草救我”。他反驳不会常规、不敢出底特的评价，自述曾开冥府打 Legacy 小航，去了 INIT 还一路土路去打 Sotiyo；在领地练波色也是为了实战，总不能上战场才“用嘴去打”。

[乌鸦王](../2113213717/)随即回帖：“你看他交过多少次飙车罚款我们就捞过他几次，有一次还是和老李一起去的。”娃娃强调自己扛后果，队友翻出来的却是出车记录。看样子，他算的是船钱，别人算的是救场的人情；钱包可以备好秒补，队友的时间却不能跟着一起秒补。

他宣布“最后一次回复，不会再看贴吧，影响心情”。楼里仍在等老李到位，甚至喊起“快遥修老李的蛋”。本想结清自己的救援账，围观群众却又把老李拖回了抢修现场。

::: 黑料 回忆录说不吵架，写到一半还是端瓜
周年回忆录开头，他说不涉及过去的吵架，过去的事情就让它过去。写到一半，自己又改口：“回忆录没有瓜怎么好看”，接着谈采星的x40脚本风波、脚本刷钱买矿造超旗的说法，以及他所指的管理不作为。他说，玩泰坦被骂也是原因，但更主要是时区不合、熬夜受不了，后来去了 INIT 鸽群。

这段出走还留着另一场误会。2018年[熊猫牧场的自述帖](https://tieba.baidu.com/p/5887448721/)把娃娃列进被踢的人，帖主又记不清他是否参加对喷。娃娃亲自纠正：“我自己退的群啊喂！虽然算是被踢团吧233”，说吵起来以前自己已经退群，并告诉问去向的人，当时还在WC体系里的FBC。帖主这才认出“你是娃娃啊”，又说若他还在，估计也得参战。

娃娃想分清的是自己有没有下场，熟人猜的却是他在场会不会忍住。至于后来去了鸽群，他在回忆录里承认活动多，但“朋友都不在了也就那样吧”。看样子，换阵营能换活动表，未必换得来原来那群陪他飙车、骂他、又去捞他的人。楼里还有个熟人向他道歉，说自己这么喷他，他仍把自己当朋友；这份交情，倒比换团按钮难按得多。

::: 黑料 萌新入门，起步先上大航

bili_34428295则质疑采星把新人往大航上推，拿“可以吃多少KFC”讽刺背后的利益；[冷剑](../2114027991/)的账号 HomuraHikari 回应说，那位萌新是自己找到合同，军团研究后组织安保，一路诱导接回家，并反驳欧服RMT的说法。一个担心新人被当生意，一个强调是新人买船、军团接船。娃娃本来挂的是教学招牌，评论区却先替他审起了招生方式：课还没上完，新人的钱包已经成了争论中心。

::: 评
娃娃的本事，是能把大航开成课堂，也能开成片场。教人时“三开大航不是梦”，轮到自己搬家又是萌新哭着求救；观众从学生变成剧评人，他还肯亲自下来接一句“演员的自我修养”。

他愿意教新人，也确实把救过自己的人写进了回忆录；只是一吵到谁替谁擦屁股，账本又各算各的。群友替他写《娃娃经》，他替别人发补课通知，队友还得替他的“自己负责”留一张出车单。这个娃娃不怎么省心，但懂得把上船、下船和嘴仗都变成下一篇投稿。
:::
