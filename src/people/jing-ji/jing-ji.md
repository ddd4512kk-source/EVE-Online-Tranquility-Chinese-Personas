
景纪，收录角色 Pinkpuma，2018 年建号。角色头衔写着“不是魔像的我不开！”，B 站和贴吧里则长期经营另一门生意：把高安任务拆成一张张流程表，再把导弹、炮术和船型配置讲到你能自己算。

::: 红料 把九种燃烧拆成三条涅迦尔
2019 年，他在 eve欧服吧发了《摸鱼日入百亿：涅伽尔燃烧者任务全攻略》。燃烧者和团队燃烧加起来九种，他建议准备三条涅迦尔，分别应付不同敌人，少换装备，也少一次“白给”的机会。帖子从技能、脑插讲到每种任务的抗性、网子和弹药；读者问配置 CPU 超了，他也认真解释 PYFA 模拟结果和脑插需求。

攻略写得够细，开头的“日入百亿”却先给自己拆台，后面还会算给你看。
:::

::: 红料 一船刷八，三百五十万技能
2021 年，景纪把燃烧攻略继续做成视频，标题是[《一张卡，一刷八——极限350万技能 燃烧者一船通刷》](https://www.bilibili.com/video/BV1WM4y1u7To)。简介给出一套单船通刷八种燃烧者的方案，约三百五十万技能起步，船和装备投入约十四亿 ISK；视频播放量超过五万。高安任务党不必先练成全能飞行员，先备好一条船，也能开张。

后来他还做了[全燃烧导弹配置分享](https://www.bilibili.com/video/BV1Nf4y1Q7dq)、[四级任务流程](https://www.bilibili.com/video/BV1qK41177C4)和[“炮术命中、伤害浮动计算详解”](https://www.bilibili.com/video/BV1pU4y1b7rr)。讲配置之外，也把命中和伤害拆成公式，主打一个能自己算就别只会抄装配。
:::

::: 红料 攻略还管售后
攻略楼里有读者说自己超载没几轮就被打爆，还用了药。景纪翻战斗记录后指出，前几轮已经吃了约 1200 点伤害，随后单轮又吃八百多，怀疑是“进结构了啊……没开修，疲劳驾驶？”技术支持不只告诉你装什么，还顺手查一下你是怎么把船开没的。
:::

::: 黑料 日入百亿，先肝二十三小时
这标题不是读者揭穿的，是景纪自己在攻略第一段认的：“日入百亿说的是一天刷23小时，而且lp还有点值钱的情况，所以我是标题党。”他还现身说法：某天休息，一边看《小李飞刀》一边刷，剧里李寻欢刚自报梅花盗，他已经刷出十亿 ISK，外加七位数忠诚点。所谓摸鱼，是电视剧在摸鱼，手还在接任务。
:::

::: 红料 脱稿的终极形态是没稿，漏了就写置顶
2019年的[《无限燃烧》](https://www.bilibili.com/video/BV12J411e7D1/)下面，景纪先自嘲“脱稿的终极形态就是没稿”，随后把漏讲的东西写成置顶补丁：故事线留着不交、声望危险时哪些任务值得接、技能怎样准备，一条条往下补。别人拿视频当完工，他把评论区接成了更新日志，还说以后改良配置就在同页更新。所谓无限，不光是任务能接下去，老师的讲义也得接着修。

后来做[导弹配置分享](https://www.bilibili.com/video/BV1Nf4y1Q7dq/)，他又把“站桩”“稳定”、所需技能和自用取舍写在简介，顺手损一句“导弹辅助都不满，还敢自称导弹党？”讲到[炮术计算](https://www.bilibili.com/video/BV1pU4y1b7rr/)，更要让观众“摆脱pyfa，成为人工pyfa”。抄作业的人本来只想知道买哪条船，听到后来却得兼修公式；老师不只是发答案，还想把学生训练成下一台计算器。
:::

::: 红料 B站作品精选

::: 评
别人标题写“日入百亿”，读者先看收益，景纪先把计算条件摆上桌：一天二十三小时，LP 还得值钱。嘴上承认标题党，手里却真给了九种燃烧配置、一船刷八教程和伤害公式。高安任务这份工作，被他写成了既能照抄、也能自己算的说明书。
:::
