
嘎子哥，游戏名YAGAHA，头衔干脆写着“嘎子哥 CEO”。他2021年8月进了[夺米台风](../2113029856/)的星华，两个号在那里一待就是四年半，跟着星华一路漂到Goons。

2026年2月7日，Goons把星华清出联盟。对外公布的原因是前CEO台风被定性为间谍、军团存在违规；Goons内部月度贴文里，说法是“违反EULA的活动”，指的是RMT卖ISK。九个小时后，2月8日凌晨，他用小号YAGAHA3新建了昆仑（Kun-Lun），从此成了昆仑的CEO。

::: 红料 星华沉船，九小时后另起昆仑
据昆仑一方发出的通告，星华和台风切割，重组为“昆仑”：嘎子哥任CEO，耳田、[虚实](../2122263187/)管理，正在办理重新加入GSF；通告还专门澄清，台风的个人RMT行为没有动用军团资产。

新团的路不算直。按联盟记录，昆仑2月9日先挂进DC的Dracarys.，第二天就离开，2月13日才回到Goons。YAGAHA3的简介里至今还留着一个“D.C 联盟位标”文件夹，记录着这段短暂的转团插曲。

Goons对这批回头客并不客气。月度“Shit List”贴文写道：踢走星华时，那些自称与违规无关的成员聚成了昆仑，又自称和星华此前可疑的领导层毫无关系，“无论如何都拴着短绳”。

嘎子哥把团拉起来后，招新简介写得很松弛：自称“小蜜蜂华人核心力量之一”，公司理念是“无为而治，随便玩玩”；新人给5亿启动资金，30天内可领60本技能书，战损全补，“打得开心 玩的爽”。管理名单上，总监有[幻象](../2114944316/)、总监兼外交虚实，另有一位俄语外交明月。到2026年10月，这个从星华残部里拉起来的团已有八百多个角色。
:::

::: 红料 三百亿罚单退回二百九十亿
短绳很快就被人拽了一下。2026年7月3日，KZU的马克瑞在QN-6J2被昆仑两组电鱼队电死，初判昆仑赔30B，KZU方面有人在群里自夸“200%赔偿是我们谈的”。昆仑的[一八](../2119472256/)不服，继续上诉，指控KZU截断日志误导仲裁。7月7日，据仲裁转述，Ranger Gama认定30B罚单越界，按1B上限处理，退回29B。

KZU那边早有人在团里说：“重组的星华不允许和别人产生刷怪矛盾。”这番话把友军眼里的旧印象摆了出来：昆仑刚被踢过一次，星华最好别再惹事。这一回昆仑没认，30B的罚单最后只剩1B。
:::

::: 红料 CEO的公章之外，还有自己的出勤表
嘎子哥的两个号，也把星华时期的战斗经历带进了昆仑。他的[主号战绩](https://zkillboard.com/character/2118729398/)与[YAGAHA3](https://zkillboard.com/character/2119032128/)各有一千多、两千多次参与击杀，一个号开过噩梦、超旗和掠夺舰，另一个号留下洛基、电子战船和重突的记录。CEO的名片是后来能贴到招新广告上的东西，先前那些跟着队伍出门的日子，却早已记在两个号的战报里。

2023年X47大战期间，他还在星华，北方战场的名单里已有他的名字；[星城被拆的那张KM](https://zkillboard.com/kill/108161468/)里，他开着舰队型狂暴上场。那时跟着军团去别人家门口开火，三年后却轮到自己收拾一个被联盟赶出门的军团。开炮时只管眼前目标，重组时却得把人、船和旧名声一起搬走，哪一样都不像换一条船那么利索。

所以昆仑的“无为而治”，并不是一个从没上过前线的人坐在办公室里写出来的清闲口号。他跟过旧团打仗，也得在旧团翻船以后把人接住。战报能留下参与击杀，联盟却不会因为你出过勤，就把前任留下的短绳一起剪断；机库里能换新船，CEO手里那份旧账还得继续拿着。
:::

::: 评
嘎子哥接手的是一个刚被联盟开除、前CEO被扣上间谍帽子的烂摊子，九小时建团，五天回盟，再把它经营成八百人的大团。理念写着“无为而治”，实际上他上任第一天就要四处办手续。

可惜短绳是Goons给的，不由他解。每回和友军起摩擦，别人想起来的还是星华。
:::
