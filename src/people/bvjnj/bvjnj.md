
辉夜，游戏角色bvjnj，另有一个只差一个字母的小号bvnjnj，两个号同一天建、同一天进团。B站上他就叫bvjnj，签名写着“EVE玩家 勋奖章收藏爱好者 世界男子复合弓一哥们”。2022到2023年间，他跟着FRT的舰队东奔西跑，把一场又一场会战录下来、配上字幕传到B站；后来兴趣转向射箭和生活视频，EVE的投稿停在了2023年春天。

[少侠](../2118354268/)2025年做FRT南征的视频，片尾素材致谢里还挂着bvjnj的名字。人不在一线拍片了，旧录像还在给后来人当素材库。

::: 红料 自家人写的败仗标题
随军UP录到自家输了，标题一般要留点体面，辉夜自己也写过《0.1龙的荣耀 旗舰抗压虽败犹荣》。可这份体面他给得很吝啬：2023年3月FRT在斐德吃了一场大亏，他上传的标题就叫[《FRT败走斐德》](https://www.bilibili.com/video/BV1SM4y1k7su/)，简介四个字：“损失惨重”。评论里有人夸“跳脸的身姿非常的帅气，挨揍的背影十分的狼狈”，他亲自补刀：“200人贴400人脸非常帅气，就是之后医保卡被打飞了。”

第二天FRT又在同一个地方栽了，他接着传了[《FRT再次败走斐德》](https://www.bilibili.com/video/BV1R54y1M7No/)，简介只有一句：“事实证明人会在一条河流里淹死两次。”又过了两天，X47那场六千人会战总算守住了，他的标题是[《终于没有败走但是坐牢的6000人X47会战》](https://www.bilibili.com/video/BV1cg4y147PA/)——赢了也不放过，“坐牢”两个字照样写进去。一个月后又一条，干脆叫《被举报重传 X47混战 FRT狂送120B》，头一回传的让人举报下了架，重传时标题里照样写着“FRT狂送120B”，评论区还嫌他“标题攻击性有待提高”。

辉夜是FRT舰队里嘴最毒的那个记录员。敌人骂FRT要排队，他自己先骂完了；对面的玩家看他的频道，几乎不用再做剪辑就能拿去庆功。可也正因为他不替自家遮丑，评论区里“FRT药丸”和“五舅是真的硬”能吵在一起，这些录像反倒成了那几年北方战争最不加滤镜的现场记录。
:::

::: 红料 会战录像与联盟会议
辉夜的EVE投稿大多是第一视角的会战全程：[《从接战开始就注定了悲剧|FRT折戟纳瓦拉》](https://www.bilibili.com/video/BV1NY4y177ae/)、[《2000人血战 战损不到20B》](https://www.bilibili.com/video/BV1P24y177VF/)、北方日常战斗合集，再加上一部《1500人会战 字幕解说》。2022年夏天熊猫人宣战北方，他从第一天录起，标题里写“邪恶熊猫人”，给自家起外号也不嘴软。

他还录过联盟会议。2023年4月19日FRT开联盟大会，他当晚就把[带字幕的会议录像](https://www.bilibili.com/video/BV1Vs4y1d7yN/)传了上去，评论区第一句是“真快啊”，第二句是“n老板这贱贱的声音”。AOM开大会，他也录了一份。普通成员能把盟主讲话原样搬上公开平台，FRT那几年的透明度有一半是他这种人手快给逼出来的。

其中一条叫《brave已经落魄到用隐轰守集结点了吗 附：老板你别唱了你诱导死了》，看标题就知道，语音里有位老板唱得正欢，诱导却先没了，他把这段照样剪进去。评论回他：“唱的不错！下次不许再唱了！剪的不错！下次还是这样剪！”
:::

::: 黑料 墨者群里的两千字检讨
[卡戎](../2122236063/)后来在贴吧回忆自己在墨者的经历，说第一次带队翻车后，墨者联盟群里骂声一片；几天后，墨者当时的招新官FG开始拿他父母开骂，“还有一个叫辉夜的人支持FG骂我”，污言秽语乱飞，他自己也“运起抗压吧八级的功力”对骂了很久。第二天[紫电](../2115311168/)有空出来管，各打五十大板，让卡戎和辉夜各写两千字检讨。

照卡戎的说法，他写了、发群里了；辉夜死活不写，还跟着FG接着骂，最后被紫电踢出了群。FG那边更进一步，招新时要求新人必须骂卡戎，后来也被紫电赶出了墨者。

这段只有卡戎一方的讲述，辉夜没有出来回应。但拍了两年FRT败仗都不嘴软的人，到了群里吵架照样不嘴软——录像里敢骂自家，群里也敢骂别人；唯独两千字的检讨，一个字都不肯交。
:::

辉夜给FRT留下的，是一摞不加滤镜的败仗录像和一份没交的检讨。标题毒、嘴也毒，好处是他从不替任何人粉饰，包括自家联盟；坏处是轮到他自己写检讨的时候，这份诚实就不知道去哪了。
