老鹰是玄武学院（Xuanwu college）的老板。2023 年，他用 Autumn oak 创立军团；后来 CEO 栏轮到 ZQ-EAgle-FC，换的是他的小号，不是换了主人。玄武在帝国系办高安新手团，招牌是从零教到能挣第一张月卡；几年后，军团已有上千个角色。教学做得认真，毕业手续却办得惊险：有人想去零安被晾着，有人换团成了间谍嫌疑人，有位管运输的老成员则连游戏都退了。校长管的不止入学，还有毕业生该往哪里走。

::: 红料 千余角色的新手学校
[2022 年一位新人的回忆](https://tieba.baidu.com/p/7947390094)里，老鹰还在 HWB 带人：新人看了他的视频进团，当晚领到一条船，跟活动本分钱，第一次就分到 1 亿 ISK。新人后来承认，自己在队里几乎没帮上忙，老鹰照样给了钱；第二天老鹰忙着运货，还替他找人组队。新人在高安起步能遇到这样肯发船、肯分钱的老玩家，算得上运气好。老鹰也确实不是光靠广告拉人的空壳校长。

[玄武学院的军团简介](https://evemaps.dotlan.net/corp/Xuanwu_college)列着新手礼包、+3 脑插、四级任务路线和国土教学。到 2026 年的[玄武与朱雀招新](https://tieba.baidu.com/p/10364237418)，课程又扩成教官带、文字教程、视频教程三套，还写明第一张月卡补助和入团福利。军团能收进上千个角色，光靠一句“萌新欢迎”可办不到。

吵到后来，离团的老成员也承认：“玄武的新手指引做的是真不错。”[八云](../2121812924/)说老鹰在高安带出不少新人，出去以后有人练成火力、有人带起舰队。玄武的教材确实能教人上路；最有趣的是，毕业生把本事带去别家时，学校未必还愿意把他们算作优秀校友。
:::

::: 黑料 想去零安，先在校门口等答复
[八云](../2121812924/)在[《朱雀战术小队的瓜》](https://tieba.baidu.com/p/8968264055)里讲了自己的开头：刚入坑时不懂低安规则和配船，白送过船，也给新人讲错过东西，因此被管理警告。他后来找老鹰，希望去零安发展，还申请在玄武高安团做战斗指挥，两件事都被冷处理。

犯过新手错误，管理不急着给指挥位，倒也说得过去；可一家挂着“从零教学”的军团，总不能只把新人留在永远的新手位置。人想往前走，校门却半开不开。他先考虑换去别家，又听说老鹰与那边相熟，担心走了还被穿小鞋，最后投了 FRT。玄武教会他出站，却没教会管理怎样送一个想毕业的人出门。
:::

::: 黑料 卖号留群，留成了一桩间谍案
这位成员换团时还想留在玄武的老群里聊天，于是谎称卖了角色；这点小聪明给老东家递了现成把柄。身份露馅，玄武一边把他往间谍方向想，一边连高安新手团也踢了他。有人替管理说话：去敌对阵营还不退出旧群，确实叫人难办；当事人则反问，自己在高安团，连零安群都没进，究竟能偷走什么秘密？

后来[伊利法尔](../2117737129/)又说他拿玄武配置去收割朱雀。他答得很冲：自己去贝斯那一次，开的是自己配的小托，玄武哪里来他的“小托机密配置”？楼里有人笑“谁家间谍闲得没事偷小托配置”。一场本可用“退群”结束的别扭，在老鹰的玄武变成了从卖号、间谍到军机配置的全套审查。错在撒谎留群的人有一份；把每个想走的人都当潜伏者，学校管理也有一份。
:::

::: 黑料 零安聊不得，配船也怕带坏新人
另一位吧友说，老鹰在群里不让聊零安的事；有人回忆自己在玄武问过零安发展，得到的也是“生产机密不能透露”的话。楼里还有旧成员说，连分享一套配船都怕被管理说成带坏新人。玄武的教程能从职业代理人讲到四级任务，课堂内容很丰富；可一谈到学校门外的玩法，黑板忽然擦得很干净。

校规管到了什么程度？有人提起零安生产，听到的回答是“生产机密不能透露”；还有旧成员说，在玄武连分享配船都不敢，怕被扣上“带坏新人”的帽子。EVE 玩了二十多年，公开配装满天飞，玄武却把配船聊出了实验室保密条例的气势。老鹰能把教程做得细，却让想教别人的老成员先学会闭嘴。
:::

::: 黑料 运输部长退坑，校长继续招生
[《朱雀战术小队的瓜》](https://tieba.baidu.com/p/8968264055)里，旧成员又点出一位离开的玄武管理：原运输部长祖祖，因为与管理 GM 不合，退团后[发视频告别 EVE](https://www.bilibili.com/video/BV1mu411N77G/)。运输不是摆设，军团上千个角色要买船、搬货、给新人送物资，总得有人跑这条线。能管这摊事的人走到退坑，留下的不只是一个空头衔。

祖祖的视频标题是“氪金上万毅然退坑”，评论里有人谢他照顾新人。另一边，发帖人还数起小 C、鬼老师、胡椒、给新人便宜卖过 +3 脑插的萝卜，以及后来离开的镜子，问玄武为什么总有人往外走。每个人走的缘由不能一锅煮，但运输、教学、带队的熟手陆续出现在离校名单上，老鹰这个 CEO 总该看看教职工办公室。玄武擅长招新人，招来以后谁替他们搬货、教课、带队，这一题不能永远交给下一批新人答。
:::

::: 黑料 指挥走了，招牌还叫战术小队
发帖人说，镜子离开前，玄武已经只剩他一个人常带战斗队；他自己申请当高安战斗指挥，又被老鹰冷处理。另一边，[玄武的招新](https://tieba.baidu.com/p/10364237418)仍写着教官带队、PVP 小队、从高安衔接零安。招牌挂得齐全，能实际把人领出站的，却是越数越少。

打仗的指挥不是把教材多印几份就能长出来。一个想带队的人被晾着，一个已经带队的人走了，一串旧成员的名字跟着被数出来；老鹰若只顾守住“新人学校”的入口，出口就成了人才输送管道。别人办学院培养战斗骨干，玄武办学院，骨干毕业后先给别家交学费。
:::

::: 黑料 新人群先问月卡，入侵问题却送出门
玄武的招牌是照看新人，招新帖里也确实列了补助。可有人讲起另一套接待流程：2022 年在 B 站看四级任务教程，进了“高安新手帮助”群，先被问月卡充了没有；他说已买年卡，觉得群里对有无入团意向的新人态度不同。后来他只是问了一句“入侵是不是天天有得打”，第二天便发现自己被踢出群。

另一名吧友据此骂老鹰用教学视频引新人、惦记新人首充。骂归骂，那段入群经历已经够损：新人问玩法，接待先问月卡，随后人没了。学校公开写“包教包会”，学生问到课程表外的入侵，得到的却像是一张退学通知。玄武可以说自家教程很好，老鹰也得解释，为什么有新人连第二个问题都没问完就被请出了教室。
:::

::: 评
老鹰办玄武有真本事：教材有人夸，招新有人来，千余角色也不是凭空飞进军团的。偏偏学校越大，门卫越忙。想去零安的等答复，换团的查间谍，聊配置的怕带坏新人，问入侵的出了群；管运输的走了，带队的也走了。

最好的新人学校，应该教人有一天不再需要学校。玄武把前半句做得响亮；等毕业生真走到门口，老鹰又舍不得把门彻底打开。
:::
