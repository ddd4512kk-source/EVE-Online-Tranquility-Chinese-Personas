
哈威，Husky Weoo，混沌仲裁（CACX）的成员，自挂头衔“摸鱼选手”。2025年五月，退团者老兰州55写帖批评混沌，指[石头](../2121840947/)能让大队停下来等自己。哈威用“哈威s”账号下场，一连几条回复解释：你以为是在罚站，实际上是在等人清掉蹭LP的小船。

::: 红料 摸鱼选手，出勤比鱼还忙
哈威这个自称摸鱼的号，公开KB累计有9266条参与击杀，目标价值约4.63T ISK；损失418条、约30.52B，solo记录239条。乌鸦、狂热和海军灾难都开，混沌有队伍出门，他这个“摸鱼选手”往往也在名单里。头衔里摸鱼，出勤账倒不薄；到了社区争论，连等待这件事也愿意出来解释。

2025年8月，[Y-MPWL的星城攻防](../../battles/y-mpwl-2025/)打到装甲计时，INIT与守方围着建筑纠缠，哈威随FRT的飓风队从后面切进来。鹏鲲队前面忙着压计时，背后又挨了一轮火；哈威自己的飓风也留在了损失名单上。这一场他不是守城的人，也不是拆城的人，看到两家打得热闹，第三方便带着自己的火力过来加了一道题。

第二年[埃加奥的旗舰混战](../../battles/akkio-2026/)又换成另一种景象：无畏轮流入场，大船一条条烧，哈威开着乌鸦和队友一起接战。旗舰们负责让账单越滚越大，常规队仍要在旁边照样开火；从普罗的飓风到低安的乌鸦，他的“摸鱼”都得先坐进驾驶舱。
:::

::: 红料 给清蹭子的刀斧手作解释
在[退团避坑帖](https://tieba.baidu.com/p/9749065335/)里，哈威说同卫队的小护卫会拉远或隐身，临近结算才来分LP；普通跟队者打同卫队要掉声望，石头专门干这份活。还得等最后一个球再打，打早了，对方换船回来，仍能接着蹭。哈威把等到最后一个球的原因和动手边界都逐条讲明：这份活要有人做，时机也不能乱。

:::

::: 黑料 算清了蹭子，没算服等船的人
老兰州55并不反对清人，反问的是：既然早知道要清，为什么不能提前到隔壁一两跳，偏要等舰队停下来，才从远处赶过来？哈威判断石头“应该是刚上线”，把选择摆成多等一会儿、清掉蹭子多挣LP，或者少等、让蹭子继续分。他说自己肯定选前者，又指楼主“纯为了黑而黑”。

楼主算的却是另一笔账：几十分钟里，大队还能多绕多少杆子？哈威讨厌外人白分一口，退团者讨厌自己替别人付时间。一个盯着结算名单，一个盯着等待时间；各自把账算得越明白，越觉得对面装听不懂：一个不愿白分LP，一个不愿白等大队。
:::

::: 评
哈威替石头讲的是一套有操作细节的道理，楼主追问的也是一件具体事：清人值得，准备能不能早一点？军团争论常卡在这里——会解释为什么要等，不等于已经解释了为什么非得这样等。
:::
