青衣，游戏名 Chess Player，2018 年建号，F1 Monkey.（Esports Petopia）的比赛队员，2023 年和[斑鸠](../2113386745/)一起作为“雇佣兵”进了 FRT 的 AT19 阵容并夺冠。角色简介开头是一句日文：“身構えているときには、死神は来ないものだ”（有所防备的时候，死神是不会来的）。

贴吧里，他用“官子青衣-”讲小船、翻译风筝教程，也当过欧服吧的小吧主。教新人时，能把一条船为什么这样配讲到楼中楼；管吵架时，也能把已经删掉的瓜重新种在自己的说明帖里。赛场拿冠军，简介替斑鸠挡黑粉，吧务还得挨两边的骂，这件日文护身符要管的事未免太多。

::: 红料 配装先问用途，老师也要改答案
2020 年，他写[《数据不是一切》](https://tieba.baidu.com/p/6485012540)，起因是讨论配置时总有人拿纸面伤害压人：赫卡特伤害那么高，怎么可能打不过？他把扰频内风筝、射程、控速、炮扰拆开讲，想教人把对手的高伤害关在够不着自己的地方。乌鸦王提醒赫卡特切狙击模式后射程更长，他起先反驳，随即回来纠正：“sry，是11km，我当时切了速度模式，记忆错乱了。”教人别迷信面板的老师，自己也得先确认面板切对了模式。

到2023年，他又被一个新人刺激得开了[《一个配置是怎样炼成的》](https://tieba.baidu.com/p/8439732466)：新人抄来杆子solo强制者，却准备拿去刷怪。他于是从“你要拿这个配置干什么”讲起，教人到KB找损失、把配置导进模拟工具，再用流浪的炮、弹药和毁电一步步拆出思路。别人认为流浪只有一套标准答案，他坚持“他不该是那个唯一答案”，讲配置如何迎合用途，而不是给新人一张照抄后自动包赢的符。

他还在2020年翻译了[维德马克风筝教学](https://tieba.baidu.com/p/6899441216)，发帖补答高蛇太贵、大电池要不要带、总览怎么调。读者谢翻译，也嫌画质；后来配装帖到2024年仍有新人来问，他继续按两人小队的搭配和电子战答。青衣这份耐心是真的，嘴也没有因此变软：有人故意伸手要“能打二十人反收割”的配置，他回“不会开掠夺建议退出联盟，有点丢人了”。老师负责讲原理，包治百病的神船请另寻高人。
:::

::: 红料 退游回来，给杆子区写说明书
2023 年 5 月，青衣在贴吧用“官子青衣-”发了[《卫队战争初体验-杆子区散人入门》](https://tieba.baidu.com/p/8397141290)。他回坑后试了一圈：纤维和虫洞太费找架时间，反收割又“抢不过蓝加的隐投”，最后在改版后的低安杆子区找到了乐子。比赛选手也得解决普通玩家的难题：船准备好了，架在哪里？

找到地方，他便把入队、修复声望、辨认杆子限制、找前线星系一路写成图文教程，还提醒新人留意 d-scan。他自称曾手贱把声望打坏，索性把自己查过的补救办法也写进去；推荐两三个人开护卫、驱逐，人多再上巡洋。晒出的战果里既有单杀，也有自己炸船——杆子区的说明书，作者已经拿船交过学费。

有人问大战场在哪看，他教人认地图上的双剑标；有人问无人机能不能绕杆子，他也接着答。另一个熟人倒省了技术问题，直接问：“青衣你又活了？”刚退完游，回来连新手教材都编好了，这次复活颇有售后服务。
:::

::: 黑料 《如何定义鸠黑》
青衣简介的主体，是一篇长文：《如何定义鸠黑》——“鸠黑”就是黑斑鸠的人。文章分两大类：

**一、传统鸠黑**，标准五条，包括“在 PVP 方面拒绝接受斑鸠理念”“与斑鸠耻与为伍”“拒绝正常价格销售物品给斑鸠及斑鸠同伙”，以及“具备以上任意条件后高喊自己要好好玩游戏”。还附了行为分析：鸠黑“会在斑鸠势威时隐藏于各种两位数个位数 QQ 群甚至私聊中，斑鸠示弱时出现在各类大群里”。

**二、潜在鸠黑**，也是五条，比如“开设直播引导/纵容弹幕内的鸠黑发言，越指名道姓的越要保护”“搬运斑鸠言论至鸠黑，搬运鸠黑言论至斑鸠，并且打着和平使者名义”。结论是潜在鸠黑“最终只有两种形态，一类鸠黑/鸠白”，对付他们只能拿“看得见的成绩和态度”。

在 EVE 里给队友的黑粉写一套分类学，青衣大概是第一人。

这套护鸠学说在[短风筝教程的楼中楼](https://tieba.baidu.com/p/6485012540)里也有实战。有人说“鸠极审判”早就存在，指斑鸠抄配置，他反复回“空口无凭”“谁主张谁举证”，最后让对方别再“狂倒垃圾”。技术课还没讲完，鸠白已经替老师的老师站上了辩论席。
:::

::: 黑料 一个月算挖坟，吧主来后重划线
2020年9月，欧服吧因大战和直播封禁吵成一片。青衣发[吧务说明](https://tieba.baidu.com/p/6978361245)，说已经把许多违规账号封了一天，要求别拿现实私事攻击人，也别用辱骂把政工越炒越低级。有人说他只在FRT反击时出来执法，他答自己一天封了十来个号，FRT确实占多数；对00区的真假爆料不熟，相关帖子由其他吧务处理。

但他的“挖坟”尺度也惹出了事。一个吧友问，四个月前的小管家帖子，正常回复怎么也被删？青衣起先说“严格来说超过一个月的帖子就叫挖坟”，没营养的帖子老顶在首页污染版面。后来[连山](../94321893/)找他沟通，他回来道歉，承认处理不当，要重新界定挖坟期限。赛场上距离差一公里会出事，贴吧里日期差一个月也能挨炮；这一次，重画尺子的是大吧主。
:::

::: 黑料 瓜吃完了，身份还没认对
2021年8月，青衣又发[《HJ对喷贴删除处理》](https://tieba.baidu.com/p/7509723353)，称三篇吵架帖符合吧规，自己吃完瓜，觉得没建设性，于是删掉。楼里马上有人骂“青衣吃完就删”，也有人问，怎么把对线的一方算成了雷霆？他解释自己很久不玩低安，看着聊天来路先入为主，认不得名字。

一名自称代表雷霆的回复者澄清，被点的人不属于雷霆，而在他们黑名单里。青衣随即道歉：“先入为主了，鞠躬。”至于他在说明里沿用的“洋人的狗”称呼，面对质疑，他坚持那是对方自称；吧友却不认，自称能不能变成小吧主给人的定性，又吵出新一轮。删三帖本想给对喷收场，结果当事人、团属和吧务用词一起回炉。青衣的删帖键很果断，认人这一步却慢了半拍。
:::

::: 评
青衣是斑鸠最坚定的鸠白：比赛一起打，冠军一起拿，退游一起退，回坑一起回，还在简介里替他立了一部《鸠黑分类法》。但只记这部分类法，就漏掉了给新人拆配置、翻教程的耐心，也漏掉了小吧主挥删帖键时挨的骂。

教配船，他坚持不能只背一个答案；管贴吧，他有时先定了答案，才回来重认人、重划线。好在模式记错会改，误认雷霆会道歉，被连山指出问题也肯回头。护鸠与配船的功课没耽误，吧务这门课，还得继续交学费。
:::
