
千里，贴吧号“极光快递员”，2023年3月入坑，头一个号在宇宙魔药里每天炸三艘狂怒才下线。照他在[入坑一年回忆录](https://tieba.baidu.com/p/8959392146)里的自述，此后一年他在DC的帝皇之镰、宽带山，帝国的PLA之间转了一圈，最后又回到宇宙魔药，去天使区吃鸡。

一年换四家团本来不算什么，稀罕的是他每到一处都混成了能说上话的人，走的时候也都吵了一架。这篇回忆录发出来，就成了一桌对账的饭局：老东家的人逐条拍桌子，他逐条贴截图。

千里的游戏日子也不只有电鱼和对账。主号Senri0527最常用的是净化隐轰和飓风级舰队型，前者把人塞进一条小船里，后者又把他送回常规舰队的火力位；狼、洛基和轻拦也轮得到。到2026年10月，这个号有三百多条击杀、一百来次损失，参与击杀的目标累计一千六百多亿ISK，其中绝大多数击杀留在宇宙魔药时期。嘴上走过DC、帝国好几家，枪口最忙的日子，却是在回到老东家以后。

2024年5月，他刚在招募帖里喊完“只要你敢刷，狂怒都去救”，三天后就在0-G8NO开着飓风级舰队型，跟队参与拆掉莱塔卢，又出现在使徒级后勤航母的击杀名单里。招新广告负责让人把船开出去，他自己也有跟着队伍拆房、打旗舰的出勤；只是这份战绩的底色更像舰队成员，日常并不靠单挑撑门面。说起船该怎么养，他能铺开几个账号的分工；真到开火时，自己的号照样得坐进队伍里。后来那堂被荣耀打断的账号课，背后也有这套刷钱、养号、出船的生活，才让一句“别教我做事”记了那么久。


::: 红料 新人垫钱当招新官
千里进帝皇之镰时还是新人，第二个号Senri9067就是在那里起的，挂着两条YST慢慢刷。原招新官退休去了虫洞，他顺手接了班，于是一个入坑才几个月的人开始带比自己还新的人。

据他自述，军团长[工程项目](../208043276/)放假失联，新人的启动资金都是他先垫；攒下第一笔钱，想的是军团缺+3脑插，便找人订了50套，也是先自掏腰包，后来军团才把钱转回来。他带新的路子也和老人不一样：老人直接给答案，他把自己踩过的坑一个个讲给新人听，为此还和团里的老人闹得不愉快。

他走后，团里反倒有人替他说话。指控他的777也补了一句：千里确实是帝皇之镰曾经最好的招新官，“因为确实是真的进人”。夕悦诗风吟则代表帝皇之镰出来收尾，说他带来的新人和价值远不止那点福利，祝他前程似锦。

::: 黑料 一本雷裔账，两边各算各的
千里跟着ender跳去宽带山，据说ender还开大航来接他的雷裔。半年后的2024年3月，帝皇之镰有人在群里说他卷走了机库里六条全装雷裔。

回忆录里他先自己算账：电鱼补贴正式实施后，工程项目只给了他3B船体补贴；招新官每月一张月卡的工资，只发了第一个月；借给别人的金卡至今没还。言下之意，团欠他的比他拿团的多。

777（舍-尔-纳）随即进楼拆账：反收割补损是福利不是义务，电鱼船补了四条，还漏说了掠夺福利，又冷笑一句“幸好你旗舰技能都还没好”。千里回嘴：第四个电鱼号是到了PLA才建的，哪来四份补贴；掠夺技能也是在PLA才点好；船只拿到三条，三天后就退团。777的回应是：“拿来船三天就跑路好意思说。”

两边就这样把福利、工资和跑路时间来回对了几轮，谁也没把账对平。按千里的算法他是被拖欠的招新官，按777的算法他是拿完福利就走的人。大概两种说法都有对的地方：一个肯垫钱带新的人，确实也在拿到补贴三天后走了。
:::

::: 黑料 中文频道卖号之争
777在楼里又添两条：一是说他在PLA洗了新人机库里的狂怒拿去自爆骗保，二是说他在中文频道公开用人民币卖号。

千里的回应是，RF-那片狂怒阵是他跟洪大买了三十条自己铺的，人到PLA之后才被闲人扫出来全打掉，他连补损都没申请。卖号则全走论坛、收ISK，买家多是老外，转移费也是他自己出的，国服来找他RMT的他都拒了，还贴了截图请大家对照。777追问2月21日在新中文和中文频道发的广告是不是他，千里让他拿截图来，777回了三个字：“没截图”。

号确实是卖了。去了天使区之后，他发现天使怪不适合电鱼，想把全部电鱼号打包80B、附送四条渔船一起出手，论坛不让打包，最后只能一个个卖。指控的人说那是人民币生意，被指控的人说那是论坛交易，到头来两边都没截图对得上。

::: 黑料 宽带山仲裁里的铁头娃
到了宽带山，老陈请他继续做招新官，他一口回绝，说只想电鱼攒年卡。没过多久，杰森带人刷小米旗舰本，一条轻拦反复跳脸、扫描配置，第三次被杰森打死，由此引出长达十天的仲裁。据千里说，本来两人道歉赔钱已经了结，后来不知为何又要重新仲裁，杰森一气之下走了，带走一批新人和一位新FC。

千里自称“铁头娃”，跑去找[随风](../2115325500/)讨说法，随风不回；又找[2gg](../2119781938/)，换来一句“我是kds的人，如果有必要我会介入”。他把截图拿给[低调](../2115988005/)看，低调劝他别管了，他才收手，转头在新闻群里内涵随风，随风直接退了群。再加上卡彻送了出去，他觉得自己每天电鱼交的税“真的恶心”，于是跟老陈说要去帝国看看，DC还有没有救。

::: 黑料 在PLA顶撞荣耀
去了PLA，日子起初很舒服：老玩家佛系，圣诞节还真有人送礼。年底[极端荣耀](../1664583033/)回来了，开始按技能等级挂群头衔，要求一个号火力、后勤都得点上。千里多开，一个号点一门，船都开得了，头衔却一直卡着升不上去。他建议统计所有角色的技能，荣耀叫他闭嘴，别教他做事。

他又提议用空间站上锁的箱子做共享机库，荣耀回他：“你想洗机库是吧。”千里在回忆录里的评价只有一句：他的ID没取错，极端荣耀。

后来有位大佬退坑分遗产，送了他元帅和夜神。他觉得太贵重，就把夜神零价挂给荣耀，荣耀秒接，一句话没说；还是千里自己找上门讲了这事，荣耀才回了一句“还好你没自己拿”。加上LP税一上来就是15%，他攒够年卡，过完年便回了宇宙魔药。

::: 红料 换了东家，没戒掉教新人
回到宇宙魔药之后，他很快又干上了熟悉的活。2024年5月，他给COPO.发[招募帖](https://tieba.baidu.com/p/9010112704)，招牌干脆叫“接收DC难民”：离DC只有十七跳，天使区地多人少，“只要你敢刷，狂怒都去救”。以前带新人离开一个地方，如今就在另一个地方朝老东家招手；有人说DC打小绿人还行，他立刻催随风，等两个月了，怎么还不来？招新广告可以卖福利，也可以顺便激将。

招新官可以不当，教人的毛病却很难戒。到了2026年，千里又在贴吧开[深渊教学坑](https://tieba.baidu.com/p/10743233530)，开宗明义：不教一条船的固定打法，要教的是能让人自己琢磨打法的底子。别人等着抄配置，他把深渊怪比作一个班的同学，先认名字、摸脾气，再决定谁好欺负、谁不好惹；游戏记事本里的小抄叫“功法”，打熟了自己长出来的经验叫“心法”。一套刷钱教程，让他讲出了武林门派开山授徒的架势。

楼里有人问，为什么要打同学？他答：“你要当校霸。”对方坚持要当学霸，他就回“那就理论知识V”。这位教官的课堂很有新伊甸特色：认识同学，是为了更有效地揍同学；学会理论，是为了别把自己的船交成学费。有人补充无敌机制，他道谢；有人追问三开，他也直说自己只会基础。爱教不等于样样都会，至少这回他还肯把不会的那一截留给别人。

两个月后，他又写[账号规划](https://tieba.baidu.com/p/10895010537)：常规、特种、无畏、后勤航母、泰坦各占什么位置，三个账号怎么把打架、生产和背面角色塞进去。他连将来落魄时去杆子区复活的退路都留好了，第四个账号则只是设想，因为不想继续加号。以前那个为火力、后勤技能头衔与荣耀争执的多开玩家，如今把自己的账本摊成了公开课程。

当然，课前还得先点一下旧仇。帖子第一楼就提醒大家，同样的话题曾被“某极端”评价为“你在教我玩游戏？”。荣耀那句话过了两年多，还在替千里的新教程打广告。千里退出过不少军团，唯独这堂课，他一直没有下课。
:::

::: 红料 炸鱼课还附送一根打印条
教人用船之外，千里还给键盘做起了配套。2026年5月，他发[《炸鱼辅助开发完毕》](https://tieba.baidu.com/p/10712250675)，亮出来的却不是软件，而是一根横跨F1到F8的3D打印支架：十八厘米宽，一体成型，不容易丢，按下去一排技能一起启动。新伊甸的技术升级到这里很朴素，屏幕里造星舰，屏幕外先造根能压键盘的条。

他把模型放进公开模型库，让大家自行下载打印，觉得好用再赞助ISK；有人催上架，他仍让人自己打，或者找附近代打。楼里马上分出两派：一派惊呼“物理WG”，追问CCP管不管；另一派掏出了祖传方案——筷子。接着连筷子会不会漏按两端、到底需不需要锯短，都能争出一门手艺。千里负责改良生产工具，群众负责证明民间早有土法。

模型公开之后，有人说要印十个八个拿去卖，后来真有回帖说团友十块钱还包邮。原作者张口要的是游戏币打赏，观众已经替他把周边生意盘起来了。那个曾替新人垫启动资金、替军团买脑插的人，兜兜转转，连炸鱼时手指不够用都想替人解决。教官的售后范围越来越宽，最后竟从游戏频道一路修到了键盘上。

::: 黑料 账号规划得明白，合同多挂一个零
2026年7月，刚给新人讲完角色怎么分工，千里就用小号Mono Cat CN演示了另一门必修课：[合同也得看清楚](https://tieba.baidu.com/p/10907812962)。他出黄币时挂错了合同，5000张飞行员执照只收了二十多亿。他在楼里哀号，自己头昏眼花多挂了一个零，种菜半年，一朝挂错，连发“求求了，真要破产了”。账号可以规划出九个角色，一个零却能把九个人的劳动成果一齐搬走。

他把帖子起名“反向诈骗第一人”，有人看成是在骂接合同的人，有人替他解释，这是自己骗了自己。更大的争执随后上桌：合同自愿接、愿赌服输，跑贴吧寻人算不算盘外招？千里回嘴，自己只是试着追回一点，又不是逼人全退。他把要求降到退一半黄币，认下失误，还想着给这场事故留个能商量的结尾。

可贴吧不会只替人递话。有人追问他是不是堵过鸿沟，有人拿举报来补刀，他只能喊“杀人诛心”。有人批评先发帖再沟通，他又解释，早上就私聊、发邮件，等到中午才来贴吧寻人。合同上的一个零没看住，发帖后的每一个字倒得挨个解释；本来求的是退款，最后还得兼任自己的公关。

收尾并不圆满：对方删了好友，他说消息已经通知到位，事情到此结束。到了8月，他仍回帖说，这次是真没退；随后又提起自己接过零价全装夜神，也还了。以前他把夜神零价挂给荣耀，如今自己挂错合同，却等不到同样的回礼。流动审计员终于遇见一本最难对的账：别人欠不欠可以吵，自己多按的那个零，吵不回来。

::: 评
千里这一年像个流动审计员，每进一家团都把规矩翻出来对一遍，每走一家团都留下一本对不平的账。他带新的热心是真的，被人记住的福利账也是真的；夹在中间的，是他那点改不掉的较真。

圈里难得有人一年就能和DC、帝国两边的管理层都吵过一轮。别人退团悄无声息，他退团要开发布会；发布会开完，还得接着给新人上课。只是这位老师讲得清账号该怎么养，却没防住合同里多出来的一个零。前半本教材叫如何在新伊甸活下去，后半本是本人亲付的学费。
:::
