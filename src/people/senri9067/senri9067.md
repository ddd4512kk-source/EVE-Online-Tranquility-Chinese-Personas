
千里，贴吧号“极光快递员”，2023年3月入坑，头一个号在宇宙魔药里每天炸三艘狂怒才下线。照他在[入坑一年回忆录](https://tieba.baidu.com/p/8959392146)里的自述，此后一年他在DC的帝皇之镰、宽带山，帝国的PLA之间转了一圈，最后又回到宇宙魔药，去天使区吃鸡。

一年换四家团本来不算什么，稀罕的是他每到一处都混成了能说上话的人，走的时候也都吵了一架。这篇回忆录发出来，就成了一桌对账的饭局：老东家的人逐条拍桌子，他逐条贴截图。

::: 红料 新人垫钱当招新官
千里进帝皇之镰时还是新人，第二个号Senri9067就是在那里起的，挂着两条YST慢慢刷。原招新官退休去了虫洞，他顺手接了班，于是一个入坑才几个月的人开始带比自己还新的人。

据他自述，军团长[工程项目](../208043276/)放假失联，新人的启动资金都是他先垫；攒下第一笔钱，想的是军团缺+3脑插，便找人订了50套，也是先自掏腰包，后来军团才把钱转回来。他带新的路子也和老人不一样：老人直接给答案，他把自己踩过的坑一个个讲给新人听，为此还和团里的老人闹得不愉快。

他走后，团里反倒有人替他说话。指控他的777也补了一句：千里确实是帝皇之镰曾经最好的招新官，“因为确实是真的进人”。夕悦诗风吟则代表帝皇之镰出来收尾，说他带来的新人和价值远不止那点福利，祝他前程似锦。
:::

::: 黑料 一本雷裔账，两边各算各的
千里跟着ender跳去宽带山，据说ender还开大航来接他的雷裔。半年后的2024年3月，帝皇之镰有人在群里说他卷走了机库里六条全装雷裔。

回忆录里他先自己算账：电鱼补贴正式实施后，工程项目只给了他3B船体补贴；招新官每月一张月卡的工资，只发了第一个月；借给别人的金卡至今没还。言下之意，团欠他的比他拿团的多。

777（舍-尔-纳）随即进楼拆账：反收割补损是福利不是义务，电鱼船补了四条，还漏说了掠夺福利，又冷笑一句“幸好你旗舰技能都还没好”。千里回嘴：第四个电鱼号是到了PLA才建的，哪来四份补贴；掠夺技能也是在PLA才点好；船只拿到三条，三天后就退团。777的回应是：“拿来船三天就跑路好意思说。”

两边就这样把福利、工资和跑路时间来回对了几轮，谁也没把账对平。按千里的算法他是被拖欠的招新官，按777的算法他是拿完福利就走的人。大概两种说法都有对的地方：一个肯垫钱带新的人，确实也在拿到补贴三天后走了。
:::

::: 黑料 中文频道卖号之争
777在楼里又添两条：一是说他在PLA洗了新人机库里的狂怒拿去自爆骗保，二是说他在中文频道公开用人民币卖号。

千里的回应是，RF-那片狂怒阵是他跟洪大买了三十条自己铺的，人到PLA之后才被闲人扫出来全打掉，他连补损都没申请。卖号则全走论坛、收ISK，买家多是老外，转移费也是他自己出的，国服来找他RMT的他都拒了，还贴了截图请大家对照。777追问2月21日在新中文和中文频道发的广告是不是他，千里让他拿截图来，777回了三个字：“没截图”。

号确实是卖了。去了天使区之后，他发现天使怪不适合电鱼，想把全部电鱼号打包80B、附送四条渔船一起出手，论坛不让打包，最后只能一个个卖。指控的人说那是人民币生意，被指控的人说那是论坛交易，到头来两边都没截图对得上。
:::

::: 黑料 宽带山仲裁里的铁头娃
到了宽带山，老陈请他继续做招新官，他一口回绝，说只想电鱼攒年卡。没过多久，杰森带人刷小米旗舰本，一条轻拦反复跳脸、扫描配置，第三次被杰森打死，由此引出长达十天的仲裁。据千里说，本来两人道歉赔钱已经了结，后来不知为何又要重新仲裁，杰森一气之下走了，带走一批新人和一位新FC。

千里自称“铁头娃”，跑去找[随风](../2115325500/)讨说法，随风不回；又找[2gg](../2119781938/)，换来一句“我是kds的人，如果有必要我会介入”。他把截图拿给[低调](../2115988005/)看，低调劝他别管了，他才收手，转头在新闻群里内涵随风，随风直接退了群。再加上卡彻送了出去，他觉得自己每天电鱼交的税“真的恶心”，于是跟老陈说要去帝国看看，DC还有没有救。
:::

::: 黑料 在PLA顶撞荣耀
去了PLA，日子起初很舒服：老玩家佛系，圣诞节还真有人送礼。年底[极端荣耀](../1664583033/)回来了，开始按技能等级挂群头衔，要求一个号火力、后勤都得点上。千里多开，一个号点一门，船都开得了，头衔却一直卡着升不上去。他建议统计所有角色的技能，荣耀叫他闭嘴，别教他做事。

他又提议用空间站上锁的箱子做共享机库，荣耀回他：“你想洗机库是吧。”千里在回忆录里的评价只有一句：他的ID没取错，极端荣耀。

后来有位大佬退坑分遗产，送了他元帅和夜神。他觉得太贵重，就把夜神零价挂给荣耀，荣耀秒接，一句话没说；还是千里自己找上门讲了这事，荣耀才回了一句“还好你没自己拿”。加上LP税一上来就是15%，他攒够年卡，过完年便回了宇宙魔药。
:::

::: 评
千里这一年像个流动审计员，每进一家团都把规矩翻出来对一遍，每走一家团都留下一本对不平的账。他带新的热心是真的，被人记住的福利账也是真的；夹在中间的，是他那点改不掉的较真。

圈里难得有人一年就能和DC、帝国两边的管理层都吵过一轮。别人退团悄无声息，他退团要开发布会。
:::
