
扎枪，ZhaQiang，早年在 BOP 带暴风队，后来被[炽天](../2120421439/)招进深夜诗人，又跟着[陌然](../2114453889/)另建承天府。陌然在[回忆录](https://tieba.baidu.com/p/8738371316)里记住他的方式很特别：这位 FC 不只带人上船，还自己把船搓出来。别的指挥等人齐，他的队伍还要等货齐。

::: 红料 工厂交了船，指挥也跟着上船
扎枪的活不只停在给暴风拧螺丝。BOP时自己造船、自己带队，后来去了低安，既开过小队也和朋友合组公开舰队；再后来进了执法队，仍在FRT的战场上活动。他的[战斗记录](https://zkillboard.com/character/2118780937/)已经攒下五千多次参与击杀，开的船从狂热、巴盖斯到元帅都有，舰队和猎物都换了好几种。

2026年[艾蒂斯星城战](../../battles/atioth-2026/)，扎枪也随执法队到了凛冬一侧。帝国要把桥头堡摆到门前，凛冬拉人拆堡，双方把常规队、旗舰与泰坦一层层压上去；人越聚越多，节点最后顶不住，连登录都成了战斗的一部分。扎枪从给暴风队赶生产进度，走到万人大会战里跟着大队出勤；旧队伍等他造好船，新战场则连等客户端响应都得有耐心。

小队指挥最熟悉的是把一队人拉起来，万人战场则把几十支队伍塞进同一个地方。他在两边都留过足迹，能从记录里看出的，是参与与长期带队的经历；船厂出过货，战场也见过人，扎枪没有只把舰队留在生产线上。
:::

::: 红料 从暴风队到公开队
据陌然回忆，他在 DC 时就听说过扎枪的暴风队，印象是“活跃而又肯干的 FC”。能经常起队，还能自己造船，打架的兴致与补货的耐性得同时在线；暴风从生产线开到集合点，他一人接了两段差事。

2023 年，炽天把他当新人招进 LN1P。陌然听了很高兴：多来一个 FC，总该多些内容和舰队。扎枪在 2023—2024 年间也跟式姐合组过公开舰队，按陌然的说法，把 Y 老板“揍了一顿”。从自家暴风队走到公开队，他带队的手艺没有只留在旧联盟的传闻里。

进了深夜诗人，陌然盼来的热闹却没跟着 FC 一起入团。扎枪先刷了一段五级任务，发现耶舒尔没有很适合自己的内容和舰队，渐渐进入 AFK。原先是等船造好就能起队，后来船能买、人也有，偏偏找不着值得把人喊起来的事。招新招进一个指挥，机库添了名字，集合频道没按预想添上声音。
:::

::: 红料 跟着朋友另挂门牌
后来陌然与旧管理对军团发展的分歧越谈越大，带一批愿意同行的人新建 Benigno Numine（承天府，BGNM），扎枪和 Tony 都在其中。新团仍加入 Shadow Cartel，仍住耶舒尔。扎枪随朋友换了门牌，却没换掉这片熟悉的低安；内容可以挑，同行的人也得挑；最后留下来的交情，比一纸招新承诺耐用；扎枪仍和陌然一起加入新团。
:::

::: 黑料 起队先看生产进度
陌然记下的 BOP 团内传闻是：暴风队什么时候起，全看扎枪什么时候把暴风搓好。照这个说法，舰队时刻表得贴在工厂门口：队员催出击，指挥先看生产进度；造船与起队一条龙，连等待也包了；队员能不能出门，先看暴风是否搓好。

:::

::: 评
扎枪最有辨识度的本事，是把暴风的生产线接到了舰队集合点。可船造得出来，内容未必造得出来：陌然盼的是多一个起队的人，他先交上的却是一份五级任务出勤。
:::
