侃侃熊在B站叫团子Yuigahama，游戏里的Mei Kanata、Mei Konata，以及Mikoto那几台编号机，都是他的人。这个名字很像一位安静看番的观众，频道里装的却是欧服舰队的日常：诱导跳错、抓人磨蹭、大场面没签上最想签的船，还有新年给金主办的一场抢救失败纪念。

他曾在早年的评论里说自己“一直是全宇宙白”；后来战斗记录越攒越多，熟人也顺着评论区过来认人。游戏里有几层关系，频道里便有几种乐子，唯独录像标题不肯替现场留多少体面。

::: 红料 两天得罪两家，先声明全宇宙白
2023年，他给一条投稿起名[《如何在2天内同时得罪2大黑恶势力》](https://www.bilibili.com/video/BV19X4y1n7da/)，简介又说“不让放音频就听听歌8”。标题把排场摆足，声音这一关却先让了一步，大概很懂得什么叫既想把乐子端出来，又得把不方便放的部分盖上。评论里有人追着问标题什么意思，也有人直接祝他“指定没你好果子吃嗷”，两家还没点明，观众先把后果替他安排上了。

[W佬](../93331025/)则拿他的号开起玩笑：“dc一个号，ndrc一个号，你现在还差init一个、ph一个号就集齐了。”他回得很快：“没号在dc哦，一直是全宇宙白。”熟人想给他拼一套阵营收藏，他先把其中一格退货；别人看账号分布猜立场，他说自己压根不认那套蓝加。后来再看他频道里那些杂七杂八的交火，倒也不奇怪：真把全宇宙当白名，选题至少是不用愁的。
:::

::: 红料 诱导点错了，录像不能白录
2024年12月，他上传[《卡彻值守舰队混入spy，跳错诱导无奈反打》](https://www.bilibili.com/video/BV1mdqZY3ETT/)，简介直接挂了战报。按他的标题，这场值守先碰上了间谍和错诱导，原定的出门方式出了岔子，最后只好反打。观众把里面的笑点接成了两句话：“PH的诱导一开，进来一坨goons”“我刚才爽射常规。”还有人追问，诱导也能跳错，真是人才，要重用。

他把这场混乱留下来，评论区就各找各的乐子：有人问切屏软件，有人惦记上周抓大航的录像怎么还不发，也有人给“爽射常规”反复捧场。战场上的原计划有没有实现，标题已经交代得够狼狈；录像的目的却一点没耽误，反打、认熟人、催下一期，全在一个楼里办了。看样子，对这位UP而言，局面越不按剧本走，片名反而越好起。

几个月后的[《这都能跑？PK最慢的一集》](https://www.bilibili.com/video/BV1SiLdzFEbV/)，他又把疑问写在自己作品的门口。评论里有人问255公里外的诱导开了半天为什么没人进，也有人认真教两种快速解除锁定的方法。题目像是在问对面怎么活下来的，观众却顺手把键位课送上门；他的频道不只保存战斗，也保存大家看完以后忍不住伸过来按鼠标的那只手。
:::

::: 黑料 大场面拍到了，最想签的没签上
2025年8月，他上传[《深夜1.5T的剧本（没签上巨蟒）》](https://www.bilibili.com/video/BV1a2hKzPEdP/)，简介给出原战报，标题则把自己的遗憾塞进括号。前半截把大场面的招牌挂得很足，后半截忽然缩回个人的小账：再大的热闹，没把名字留在巨蟒的单子上，还是觉得少了点什么。观众接得也准，一句“还没锁上就无了”，另一句“操作要提升”，把括号里的苦水又拧出几滴。

偏偏这楼还有新人跑来求助，说主线第二个任务就炸船了，现在人在太空飘着，该怎么办。他没有嫌这道题太小，回的是“进空间站坐上新手船出来打”。同一层楼，一边遗憾巨蟒没签上，一边指导别人先找条新手船，欧服的贫富差距就这样挤在了评论区里。看样子，大船的签名可以错过，小船的售后还得做；这位熊的宇宙再大，最后也免不了兼一下新人客服。
:::

::: 红料 新年抢救金主，悼词先备好了
2026年开年，他又发[《新年120主治医师团队抢救大金主失败》](https://www.bilibili.com/video/BV1ARicBwEL8/)，简介只有一句“沉痛悼念木老板”。标题先把舰队改成医院，再把结局写成病历，节目效果倒比悼词还早到场。评论里有人问被枪的哥们犯了什么天条，有人问这么大的牌面为何要五个长枪伺候，还有人操心“还有复活风险吗”。这份新年祝福，听起来很难说是在盼金主回来还是在替追悼会补手续。

[白菜](../2116041057/)也来凑热闹，说看他们这么浪费燃料不带自己，只好投敌。团子负责给现场起一个医疗剧式的名字，熟人负责把油钱和阵营关系一起端上来，悲剧就这样被大家围着分成了笑话。真正让这条投稿有他个人味道的，大概正是这套写法：船和战斗是宇宙里常见的东西，给金主写“抢救失败”，还要让朋友在楼下追讨燃料局的席位，才像熟人的频道。
:::

::: 评
侃侃熊的频道像军团活动散场后的那桌饭：有人复盘错诱导，有人嫌手慢，有人计较没赶上，有人趁乱问新人该上什么船。他把这些场面存下来，常常还先在标题里给自己添一句括号。宇宙里的大事留给联盟写公报，他更愿意记住自己没签上的那条巨蟒——公报谁都能转，这个遗憾才是自己的。
:::
