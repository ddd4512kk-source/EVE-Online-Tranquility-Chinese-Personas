小珈，B站的眠眠渡春，游戏角色Tenma Gabriel White。他参加欧服舰队，也把自己跟队时的窘事发出来：第一次开FAX，有人教停车、有人问为什么不修队友；后来坐上黑隐，船炸了，才回头查FC喊的“MJD”究竟是哪三个单词的缩写。

他的游戏名片也很配这套经历：几条洛基损失，反复配着“升天”，后面还挂着“小珈的广播”和“小珈的总览”。炸过的船留作纪念，能用的设置继续分享，错题本和工具箱挨着摆。

这位UP的频道里既有自己的战斗记录，也有和社区熟人一起做的更新节目。合作名单上能找到他，评论区里更常见的却是一个还在交学费的小珈：别人把高光剪出来，他把“收到”和“原来如此”也一起留着。

::: 红料 第一次FAX救援，评论区接着带新
2025年1月，小珈发了[《纪念一下第一次fax救援》](https://www.bilibili.com/video/BV17AfRYiE3H/)，简介只有兴冲冲的“jumpjumpjump”。第一次把旗舰开到救援现场，纪念照还没晾干，评论区已经开始查作业：有观众说队友的重拦都锁上了，怎么还不开修，他回答“开泡泡了修不了呀”。救援船开到了，不等于眼前每个人都能奶，第一堂课便先从这个误会讲起。

接着有人提醒会战旗舰先停船、没挨打可以不开抗、速度降下来再开模块，他一条条回“收到”。还有观众反过来抬杠：真等速度降下来，诱导可能先死了。大船上的操作原来不只在舰队里有人教，发到网上还能再开一轮课；小珈倒也不急着把第一次写成教科书，老老实实收下了这一串课后批注。旗舰贵归贵，“收到”两个字仍是新人最好用的装备。
:::

::: 红料 修链很好玩，无人机先下班
第一次FAX救援之前，他已经发过[《一种没什么用但是看着很好玩的无人机摇修链》](https://www.bilibili.com/video/BV1WZwyefEHn/)。标题先把实用价值压低，再老老实实承认好玩；观众却替他担心，跟队带这个，怕不是要被当成“活爹”。他回答得很有实战体感：无人机大多第一波架就被对面或者自己家的炸弹炸没了，后面只剩干瞪眼。精巧的小玩具还没来得及展示多久，自己人的炸弹也能替对面提前验收，军团的快乐有时确实很费耗材。

[W佬](../93331025/)在楼里认出他跟着zigan的队，还有人一脸茫然问什么游戏，他回“ff14”。明明发的是EVE，无人机还在修链，先给另一款游戏招起了客，正经问题到了他手里也能拐个弯。过了些天，他的[军团活动记录](https://www.bilibili.com/video/BV1SGFie6Eis/)又起名“参加军团活动的时候突然被抓”，简介怀疑“有个蓝星spy”，并把投稿拆成正片和活动全程。玩具能坏、活动能出岔子，纪念录像倒是一样不少；这位UP的军团生活，连年会都不肯只留合影。
:::

::: 红料 大家的更新节目，他也来搭把手
小珈还参与了[76](../2117010442/)等人的中文社区节目。[回坑与入坑、2024—2026欧服事件回顾](https://www.bilibili.com/video/BV1JWti66ERx/)、[引擎开源新闻](https://www.bilibili.com/video/BV1CnNE6uErg/)和[海四克隆服务更新](https://www.bilibili.com/video/BV1MY5C66EtJ/)的公开团队里，都能看见“眠眠渡春”，署名是“合舞”。同一群人轮流挂着策划、调音、手工制作之类的名目，把更新和社区大事攒成节目，名单倒颇有军团熟人临时搭台的味道。

8月[《这泰坦是俺拾嘞》第二集](https://www.bilibili.com/video/BV1F1496xEea/)的五人团队又给他换了个名目：“作曲”；[死枪](../2114324057/)署“舞者”，NoNo负责上传，76署参演。资讯节目里合舞，泰坦喜剧里作曲，熟人们连工种也排得像接力赛。片名忙着争泰坦归谁，名单先把这一桌人各自的座位摆齐了。

他自己那边还在问跳刀怎么听、超载怎么开，到了合作名单里，又和[少侠](../2118354268/)、[NoNo](../2113426221/)等人一起出现。看样子，玩家不必先把每条船开成满分，才能来替社区添点东西。前线继续交学费，节目继续搭把手；一个“收到”回得勤的人，游戏之外倒也没有只当观众。
:::

::: 黑料 船没了，才查到MJD是什么意思
2026年6月，他发[《如果你们觉得逼死一个跳刀马上转完的救世很好玩的话你们可以继续》](https://www.bilibili.com/video/BV1siEo6SEQT/)，简介先把玩笑说破：“标题是玩梗！！！”这是他第二次跟这么大规模的黑隐队，也是他自认第一条“被自己蠢死的黑隐”。船没了，他却还觉得好玩，收尾不忘写“收获很大，必可活用于下次”。别人交学费买知识，他这回还附送了一份学习心得。

观众问舰队里说的是什么语言，他解释是英语，又承认事后搜了一下，才知道FC念的“MJD”是跳刀的首字母缩写。有人替他抱怨语速，他却说其实能听清，还觉得那个口音可爱。这个反差很有小珈的脾气：没赶上的操作可以认，FC的口音也不必一起判刑。只是英文缩写学会得稍晚了些，太空英语这门课，先收船，再发词汇表。
:::

::: 黑料 修着装备，错过了下一班车
不到一个月，他又留下[《纪念一次死里逃生》](https://www.bilibili.com/video/BV1qTMp6LEvh/)，这次追着他跑的是FRT。按他自己的简介，操作一忙，第一次发现修装备时不能超载其他装备；这个失误让他没吃到下一轮带跳，只能和主舰队“隔海相望”。前一次是英文缩写没反应过来，这次是装备界面临时补课，课程换了，学费的收取方式倒很熟悉。

他原以为跳到ESS的轻拦要让自己英勇就义，结果对方没起泡泡。评论里有人解释，那条拦截正在装填，他回得很开心：“那太巧了哈哈哈哈哈。”自己的失误让他掉队，对面的空当又给他留了一口气，死里逃生遂成了一场双方操作共同参与的课堂。教训当然可以下次再用，只是这次活下来，多少也得谢谢对面替他按住了下课铃。

几天前的[《对同步器大人畏惧了》](https://www.bilibili.com/video/BV1poT46vEuN/)里，他还在简介说自己后来修了五分钟才把甲修满。评论区围着同步器吵得热闹，有人给他讲毁电该怎么分配，[白菜](../2116041057/)则劝大家少点戾气、安慰UP。大人们争谁更双标，小珈的课后作业仍是最具体的那两样：装备要怎么按，船要怎么活。
:::

::: 红料 本人作品
- [《纪念一下第一次fax救援》](https://www.bilibili.com/video/BV17AfRYiE3H/)：从作者的第一次救援，到评论区对停车、开模块和重拦能否受修的讨论，是一场有来有回的舰队课后答疑。
- [《如果你们觉得逼死一个跳刀马上转完的救世很好玩的话你们可以继续》](https://www.bilibili.com/video/BV1siEo6SEQT/)：本人解释玩梗标题、承认失误，又在回复里补上“MJD”的迟到释义，最能看出他怎么把翻车讲成自己的故事。
- [《纪念一次死里逃生》](https://www.bilibili.com/video/BV1qTMp6LEvh/)：简介把修装备、漏带跳和掉队的因果交代得具体，作者与观众又补上轻拦装填的巧合，适合连着前一篇对照读。
- [《对同步器大人畏惧了》](https://www.bilibili.com/video/BV1poT46vEuN/)：作者修甲五分钟的感叹，碰上评论区的阵营争论与操作建议；比起替谁判案，更适合看一条投稿怎样变成熟人的聊天现场。
- [《一种没什么用但是看着很好玩的无人机摇修链》](https://www.bilibili.com/video/BV1WZwyefEHn/)：标题的“好玩”与作者回复里第一波就被炸没的尴尬相互照应，熟人认队伍、UP乱答游戏名，也都很有日常气息。
:::

::: 评
小珈最像一个肯把作业本摊开的玩家：别人指出哪里没按对，他就回“收到”；自己没听懂什么，炸完也照样告诉大家。旗舰、黑隐和常规队，轮流教他一点新东西，B站则负责给这份学费留底。船能不能活，各有天意；错题本有没有认真记，熟人们倒是一眼便知。
:::
