叼爷，游戏名 MrDiao。早年混紫禁城、盘古，后来待过 Goonswarm，也进过 CODE.、Safety.，再到伏羲。欧服华人圈里，读过他教程的人不少，听过他恶名的人也不少。

新人翻资料，觉得这是位热心老师傅；高安驾驶员见他上本地，未必还想喊老师。至于关于骗术、录音和洗机库的旧事，帖子虽已散失，传闻留下的却是另一副面孔：不光要拿走你的东西，还要让你听见他的笑声。

写教程是本事，拿本事坑人也是他的名声。若只收前一半，叼爷这篇列传便成了教职工表彰大会。

::: 红料 教材确实帮过新人
[华人势力大事记](https://forum.pla-eve.com/topic/61-eve欧服华人势力大事记/)记载，紫禁城早年的新人教材，一部是 [H叔](../480362957/)的手册，另一部是叼爷的《EVE资料大全》。这份贡献不必因为后来的恶名一笔抹掉。

到 FRT 后，他还写了[欧塔五级任务攻略](https://forums.winterco.org/t/topic/11576)、[懒人 P2 行星教程](https://forums.winterco.org/t/topic/21180)、[行星开发常用模板](https://forums.winterco.org/t/topic/24906)和[跳货驾驶员生存手册](https://forums.winterco.org/t/topic/25034)。资料能让人少走弯路，运输建议也确实能让人少炸船。

这些是实打实的帮助。至于老师本人站在运输路线的哪一头，那是另一章。
:::

::: 红料 福利方案，至少肯摊开写
他写过[联盟物资采购透明方案](https://forums.winterco.org/t/topic/24485)，把报价、认领和组织者回避竞价的规则列出来；也写过[大鱼值守 FC 补贴草案](https://forums.winterco.org/t/topic/25050)，提出给值守和救援发补贴。

两篇都标着草案，不能当成已经兑现的政绩。不过愿意把分配办法公开写出来、让人讨论，总比只在麦里宣布自己英明强些。
:::

::: 红料 外网的长瓜，搬得回来
2022 年 Mittani 退位，他写了[事件始末](https://forums.winterco.org/t/topic/21496)，整理外网讨论、截图和内部聊天材料，让中文读者不必自己跑遍各处拼故事。

这种资料整理费工夫，也有用。叼爷既会写操作手册，也会给社区搬长瓜，这一面不假。
:::

::: 红料 B-R5RB，确实在场
2014 年 B-R5RB 大战，他作为 Goonswarm 一员开着 Naglfar 参战，[泰坦击杀记录](https://zkillboard.com/kill/36255172/)上留着他的名字。

大战参与者这块招牌，他挂得起。至于其他旧事，不能拿一张大战纪念照通通盖过去。
:::

::: 黑料 跳货老师，也在路上拆跳货
叼爷的高安强暴经历，不是嘴上扮坏人。他待过 CODE.、Safety.；[个人击杀记录](https://zkillboard.com/character/1387156123/)里，Catalyst 和 Uedama 都是熟面孔。

2021 年 8 月 15 日，他参与的强暴记录里，就有一条[游牧（Nomad）](https://zkillboard.com/kill/94527900/)和一条[装着近 19.4B 船货的小鱼（Rhea）](https://zkillboard.com/kill/94524114/)。后来他写跳货生存手册，提醒驾驶员别为了货舱牺牲生存能力，确实说到了痛处。

老师教得好，因为老师也做考官。补考的学费，按船和货一起收。
:::

::: 黑料 等你出深渊，再祝各位手红
他那篇[《极小队强暴攻略》](https://forums.winterco.org/t/topic/12185)，教人用 Coercer 小队蹲高等级深渊出口，把统合部引开，再打出来的高价船。不是泛泛聊配装，连目标出来后该怎么等、怎么抓，都写得明白。

目标还有无敌时间时，他的口吻是：

> 让他最后享受一下清醒的空气。

文末配了别人的受害战例，注明不是自己杀的，再祝读者手红。船还没锁上，苦主的悼词已经备好了。
:::

::: 黑料 诈骗也要编教材
旧闻一说，叼爷还写过诈骗教材：教人的不只有怎么刷钱、怎么运输，还有怎么骗走别人的游戏资产。一摞行星开发攻略，也遮不住这份课程表。

他对骗术的兴趣，倒还有一处公开痕迹：2021 年，他在官方论坛发帖讨论[总值 180B 的诈骗合同](https://forums.eveonline.com/t/very-interesting-scam-contracts-that-worth-180b/324473)，注意到有人反复上当、隔了几天还回来，追问这套办法怎么运作。写过诈骗教材的人，到了论坛还在研究别人的诈骗合同，看样子这门课一直没毕业，还在进修。

行星开发教你收菜，骗术教材教你收人。教材作者还是那一位，读者最好先看清自己是学生，还是教学素材。
:::

::: 黑料 骗完还要留录音
还有一说，他骗到别人的游戏资产后，还要把过程录下来。

这件事招人厌的地方，不止一个“骗”字。东西到手还不够，还要把这场骗局留下来反复品味。苦主损失的是资产，骗子收藏的是苦主上当的过程。

别人的战利品挂机库，他的旧闻里，连耳机都能挂战利品。
:::

::: 黑料 马甲进团，机库遭殃
据传，他四处安插间谍马甲，盯过小军团的机库；混进去、洗掉资产之后，还要炫耀、嘲讽。

洗机库在 EVE 不算稀奇，洗完还要拿苦主取乐，才是这桩旧事最刺人的地方。小军团本来就家底薄，信任给出去，资产被搬走，末了还得听人笑自己好骗。

马甲负责让人放心，本人负责让人长记性。连售后都包，只不过售后内容是嘲讽。
:::

::: 黑料 反间谍审查，他也会糊弄
2024 年搬运[蜜蜂执行军团被洗机库的消息](https://forums.winterco.org/t/topic/24480)时，叼爷顺口自述：蜜蜂的反间谍审查要求交现实身份资料，他也交过，填的却是借来的别人的信息。

那次洗蜜蜂机库的是 Jay Amazingness，算不到叼爷头上。不过，叼爷自己这句糊弄审查的回忆，已足够给他的间谍旧闻配一条脚注：审查者在核实身份，他在研究怎么把表填过去。
:::

::: 黑料 教材留下，人被请出去
[FlyingBee 的回忆](https://forums.winterco.org/t/topic/13924)提到，盘古成立早期，踢掉 MrDiao 就是一件出名的事。作者没说清为什么踢；不过一个写诈骗教材、填假资料过审查的人，被踢的理由大概不用想太远。

但回忆里的相处评价并不客气：说他的腔调令人不爽，又转述 [Wind](../1901851878/)的判断，认为他带来的麻烦可能超过对联盟的帮助。

能帮新人是一回事，让同团的人愿意继续容忍，是另一回事。手册可以存下来慢慢读，人就未必要一起留。
:::

::: 评
叼爷的教程有用，这份红料该留；但不能因为他会写教程，就把强暴和骗术也排进优秀教师事迹。尤其那些骗后留录音、洗机库还要炫耀的旧闻，刺人的从来不只是资产少了，而是他还要拿苦主的不痛快当乐子。

新人喊一声老师，苦主未必反对——只是两边交的学费，很不一样。
:::
