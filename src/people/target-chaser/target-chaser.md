少年，帝皇之镰的 Target Chaser。2022年北方打旗舰战时，他随DC参战，队伍在前面开火，他在频道里喊每一炮打谁。角色头衔写着“少年”，简介却摘了 Xiu Mu 的话：“故事最动人的部分始终在过去。”外号年轻，选来挂在门口的话倒很怀旧。

::: 红料 H-PA29带队
2022年12月3日，H-PA29打了一场各方损失约413B的[大型旗舰战](https://br.evetools.org/br/638be6e5e878fa0c98ffbfa8)。FRT、PH、PL一边，Goons、INIT、DC、Snuff另一边，少年以帝皇之镰／DC身份带队。19:09，他的队伍把FRT雪月城的一条[龙鸟](https://zkillboard.com/kill/105128316/)按在了城外；一个多小时后的交战记录里，队伍仍在他的频道里。

收录号累计参与击杀5419次，所涉目标总值约3.12T ISK。更要紧的是，他在帝皇之镰、DC一带是常年带队的那一类人，H-PA29这样的旗舰大仗里被点到名喊话，说明他在这套体系里不是临时凑数的。

那一晚的场面大概是这样：对面FRT、PH、PL三家人头攒动，己方Goons、INIT、DC、Snuff拼成一锅，几百号人挤在频道里，有人急着开火，有人还在问谁是主锁。少年的活就是在这锅乱粥里把话说短：锁谁、等谁、几时放炮。圈里猜他喊话的风格偏冷，不加戏、不解释，队员听不懂也只能先按着做。舰队的炮火由各条战船一起完成，但让几百条船打向同一个目标，靠的是频道里那一个声音。他没有留下战术名言，倒是留下了那一份队伍名单。
:::

::: 评
少年把“故事最动人的部分始终在过去”挂在简介里。H-PA29的过去，至少还留着一份带队的名单：帝皇之镰，DC，队伍由他喝令。别人的怀旧是翻照片，他的这一页要翻战报。
:::
