北暮，北岸军团 NSGY 的主事人，游戏角色 BeiMu。2025 年初，他碰到的麻烦不是敌人来拆家，而是自家人退了群、换了团，还把一肚子气带进了[贴吧](https://tieba.baidu.com/p/9427784051)。此生说管理乱禁言，CEO 偏袒内务大总管；北暮赶来答辩，先把对方的身份纠正了一遍：你自己也是管理，怎么就成了受气的小团员？

一个想谈被怎么对待，一个先谈你是什么身份。游戏公会的家务事，聊着聊着已经有了职务表和约谈记录。

::: 红料 这回管理确实降了级
北暮在争议楼里说，讲出“具体”二字的管理，当天已经被他约谈过，其他管理也在接受约束。他没有把事情一直拖成一句内部处理：两天后，他又回来补了一句，“我已经把这个管理降级了，管理不周，闹笑话了。”

这句承认，至少比继续争谁配叫小团员痛快。此前还在维护管理的体面，后来终于肯把“管理不周”摆出来，官位也跟着降了一级。群众围观半天，处理结果总算没有永远留在下一次约谈里。
:::

::: 红料 从群里管人，到战场上船
2025年10月18日，[K-IYNW的一条击杀记录](https://zkillboard.com/kill/130592787/)里，北暮在NSGY／Goons一方驾驶监视者参与指挥。同一个目标的攻击名单里，还有星华的[非物](../2120847133/)和红楼的[兔兔](../2123680197/)，也都坐着Monitor。

群里争禁言时，他得解释谁是管理、谁该降级；到了战场，北暮自己也坐进了指挥岗位的船。主事人的工作，一头连着小团的家务，一头连着出勤。
:::

::: 黑料 团员走了，先争他算不算团员
按此生的说法，北岸原本是个相处和谐的小团，后来管理动不动禁言水群的人；他退出群聊、换团，本想好聚好散，却又见到离团被解释为他自己的选择，于是把禁言和受气的经过公开。他承认团里多数人友好，也有人挽留，骂的重点始终是管理的官威，以及北暮究竟护谁。

北暮的回应同样硬：此生本来就是管理，不能把自己包装成普通小团员；如初正常聊天，被人扣上气走此生的罪名，他必须制止。他说自己对成员一视同仁，想走就好聚好散，想玩就敞开玩，不能捏造事实。

看样子北暮最怕的，大概是一个退团者把整套管理班子的信用一并带走，于是先保住身份和说法，再处理禁言的人。可对受气者而言，“你也有官位”并不会让那次禁言变得好受。嘴上是敞开玩，楼里却忙着辨职务、谈约束、讲约谈；来玩飞船的人，先撞上了一场小公会的干部会议。
:::

::: 评
北暮不是完全不处理问题的 CEO：涉事管理后来降了级，这笔要记。只是他最初忙着证明此生不算普通团员，正好把对方最烦的那股管理味又端了一遍。

军团留人靠一起玩，职务表只能告诉大家谁有权限，不能替谁把委屈咽下去。
:::
