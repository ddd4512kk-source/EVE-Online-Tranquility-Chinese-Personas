
阿巴怪，游戏角色Aba--Guai，伏羲圈里的LP回收争执人物。2025年夏天，神农新人[无火的余灰](../2123557648/)看见通告推LP交易群，问是不是可以私卖。阿巴怪先替新人解释统一回收，讲到市场、补损，最后讲出了三项取消警告：以后没你的补损，没你的建筑权限，也没你的运输。

别人回答问题用说明书，他回答问题顺手带了锁。新人还在问自己能不能做生意，阿巴怪已经开始解释，不接受这门生意要失去什么。

::: 红料 自己上前线，回头也管别人的账
阿巴怪讲补损，并非只在后方替别人算炸船钱。他自己的[战绩](https://zkillboard.com/character/2119615259/)已经攒到三千多次参与击杀，伏羲跟着FRT打的大场面，他也在队伍里。从X47的北方战线到后来的艾蒂斯，仗打起来，统一回收、机库和补损这些听着像后勤的词，最终都要落到有人肯把船开出去。

他也承担带队的活。[2026年2月的一次交火](https://zkillboard.com/kill/133393520/)里，阿巴怪就在指挥位上。平时得让人跟队、等口令、选目标，打完还得面对船钱从哪来的老问题；他在LP争执里反复提卫队补损，身后确实有一份自己的前线履历。把规矩讲成命令，对带队的人是熟悉的姿势，战场上的频道需要有人收住，回到交易群却很容易忘了，问价的人并不是等他广播的舰队。

这也是他身上最刺眼的反差：前线要把队伍带出去，后方却把建筑、运输、补损一扇扇门摆到新人面前。打过仗，当然知道补船要花钱；知道要花钱，也不妨碍他把一场交易解释，讲成一份不听话就取消资格的出勤纪律。
:::

::: 黑料 先讲市场崩盘，再问补损从哪来
[后来公开的LP争议帖](https://tieba.baidu.com/p/10430077310)里，阿巴怪说，新人那边的管理没讲清楚，那就由他来讲。LP必须统一管理，否则市场会崩；卫队补损也不是大风刮来的。这两条理由连起来，很有一套当家人的口气：卖东西不能只顾自己多拿一点，亏了还得有人替队伍收拾账本。

看样子，他大概是怕“能不能私卖”这一问，把一项默认必须交的东西问成了自愿。于是解释很快变成训话：“爱刷不刷，不刷滚蛋。”有人追问，FRT的人刷A卫队是不是都只能卖给他们，是不是联盟规定，他答是。旁边有人说是卫队兴趣小组的规定，也有人说已经和联盟谈好；阿巴怪要的显然不是把规矩讲出几个版本，而是让提问的人先把规矩接下来。统一回收说是为了稳住市场，接待新人的语气倒先来了个暴跌。
:::

::: 黑料 没私卖过，也能先收到三道门的警告
无火的余灰没有在对话里认私卖，反而说自己还没发表什么言论，也没有卖过。阿巴怪那边已经往后列清单：“以后srp没你的事情”“所有建筑也没你的权限”“运输也没你的份”。补损关系到船炸了以后能不能补回来，建筑和运输关系到玩家如何落脚、搬东西；拿这三样压一名刚问规则的新人，远比再背一遍公告省事。

这套话最荒唐的地方，是对方还在否认私卖，他已把“不听话以后怎么办”讲齐了。旁边的人接着起哄，说问题太蠢、提议踢团黑站，阿巴怪的清单也就成了现场最具体的一份答复。照这场对话看，LP回收本来该教人把产出交到哪里，最后却教会新人：有些问题问出口，福利、住处和运货都能被摆上谈判桌。市场还没崩，先让提问者想一想，自己的门会不会先被关上。
:::

::: 评
阿巴怪替统一回收讲了市场和补损，讲到最后，落款却是建筑、运输和一声滚蛋。他大概觉得，把后果列得够全，新人就能少问两句。可人家问的是LP能卖给谁，他回答的是自己能让你少些什么。回收制度有没有道理是一回事，这套把提问当成权限问题的威风，已经够他自己留名了。
:::
