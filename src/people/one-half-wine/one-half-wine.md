半盏醉颜红，游戏里叫 One Half wine，低安小船圈里的熟脸。别人开船出去打架，他还要把这一趟剪成“颜红的低安日记”：今天教风筝，明天试配装，观众照着出门，回来再问老师为什么自己的船不听话。贴吧有人要找低安纯 PVP 团，熟人干脆让他联系“颜红姐姐”，先翻 KB，再谈怎么一起玩。

他的名字听着像写小说的人，倒也没辜负这个印象：翻译过 EVE 短篇，也连载过自己的故事。只是小说读者要学会等，视频观众则等不了那么久——哪根网子该不该超载，哪套配置有钱没技能也开不动，评论区随时能把老师叫回来答题。

::: 红料 小船挑架，也往大场面里钻
颜红的老本行是低安单收和小队作战，审判者长期占着主力位置，驱逐、护卫与巡洋舰轮换着开。上万次参与击杀里，有上千次单杀，足够看出他喜欢亲手挑对位、卡距离的路数。比起单纯换更贵的船，他更在意这条船能不能让别人愿意接战：有人感慨折腾过航母、大鱼，最后还是小船好玩，他接话“船太大都没人跟你打架”。一条船再强，出门找不到肯陪你玩的对手，也只能自己绕圈。

他挂战果时，口气就没教程里那么客气。角色简介里摆着一串击杀，连[D Manson](../690534767/)的 Laelaps 损失也挂了进去，旁边直接骂“有fax和泰坦还被我打哭的嘴强，只会叫的狗”。评论区能耐心解释电容，遇到老对手又不肯让嘴；打完一场，战果挂着，骂人的话也挂着，唯恐下一位来翻简介的人错过。

这种玩法恰好长出了他的教学题材。速度、射程、网子、反跳，哪一样配得偏一点，接战的形状就会变；纸面上看着很漂亮，落到对手身上却未必肯按预想演。颜红的低安经验里既有把人留住的办法，也有看着人跑掉的无奈，所以他讲配置常常连着讲当地怎么打。那些看似古怪的装配，先得放回他的交战环境里，才知道是在冒险，还是另有算盘。

他也会往大会战里钻。低安的旗舰混战和 00 区的攻防都留过他的名字，不过他仍常带着熟悉的小船入场。[塔夫](../../battles/taff-2026/)无畏互砸那回，他开长尾鲛级舰队型参战，后来在场被击毁。主队在烧大船，小船也有自己能伸手的缝隙；平时挑一两个对手算距离，碰上大场面，就得在一群比自己贵得多的东西旁边找机会。低安日记里的老师也会被卷进这种热闹，出门找架，从来没有只准打课堂例题的规矩。
:::

::: 红料 把低安日子拍成连载
2020 年起，颜红做“[低安日记](https://www.bilibili.com/video/BV1SE41177em/)”，第一集就问观众想看什么船的配置。这样一来，下次出门开哪条船，观众也能跟着点菜：不光看结果，还能追着问为什么这么配、换一条船能不能照用。评论区有老玩家认亲，也有新手把自己的困惑搬来，单收视频便慢慢长成了一间随时有人插话的教室。

题材也越铺越开：护卫狗斗、中距离风筝、新人战巡，还有掠夺和战列。颜红既肯玩贵的、怪的，也得应付准备照抄的学生。万速加姆那回，他把高奎、速度插、药和推进器的条件列清，超载速度报的是 9909；观众看完这套装备先往后缩，他又说自己平时也白蛋开加姆。炫技的片名把人招进来，到了讨论配置，老师还得把豪华版和日常版分开讲。

有人照着配炮扰，发现电量只够一分钟，颜红让他先查导航里减微曲耗电的技能。同一张配装，老手开着满地跑，新手装上去却连电都不够；差的那截得回技能队列里找。教学最麻烦的地方就在这里，老师把车钥匙递出来，学生未必连油箱都备齐。他说做字幕最累，评论区的课后答疑显然也没少花工夫。

还有人在[招募讨论](https://tieba.baidu.com/p/7709437316)里把他的名字当作低安纯 PVP 的入口，建议想找团的人游戏内联系 One Half wine，再看 KB 判断是不是自己要的强度。做久了视频，别人找同好也会想到他；比起招牌上写自己多能打，让熟人拿来指路，更像在这个小圈子里混出了位置。
:::

::: 红料 开船之外，也给 EVE 写过故事
2017 年，贴吧转载[《EVE短篇小说——恐惧常伴》](https://tieba.baidu.com/p/5306988309)，译者署名“半盏醉颜红”。后来他的空间又挂上《EVE：德里克军事狂想》的连载。平时围着配装和射程讲游戏，他也肯换一副笔头，把游戏写成故事；低安的日记用船来更新，另一种日记得坐下来写。

这也解释了为什么他的视频评论区会混进小说读者。有人记着他怎么配船，有人记着他还欠哪一章，两拨人最后都能找到同一个作者。翻译署名留在旧帖子里，自己的连载则留下了催更现场；半盏这个名字，一半在外面找架，一半还被读者惦记着交稿。
:::

::: 红料 B站作品精选
- [《如何优雅地护卫拼刺刀：中风筝教学（上篇）》](https://www.bilibili.com/video/BV17T411M7Vz/)：把小船交锋里的距离选择做成教学。作者说大船容易没人接战，聊到遇上轻重拦，又开玩笑“只要你跑得比队友快就行”；适合从他的教学和回嘴里一起认识这位低安老熟人。
- [《真男人就要拉1400大栓！》](https://www.bilibili.com/video/BV1ZY411Q7J2/)：把镜头转向 1400 恶狼，答疑时又提醒自己的配置主要适合当地低安交战。想换着玩大炮，可以连同这条适用条件一起带走，别把一套配置当成到哪都灵的答案。
- [《来自深渊的凝视，最强的风筝驱逐：奇奇莫拉级PVP》](https://www.bilibili.com/video/BV1j5411W7Jd/)：从小船的速度与射程里找接战空间，评论讨论延伸到同吨位对手、配装和成本。适合喜欢驱逐风筝的人接着比较：船再小，也得先挑好让对手难受的距离。

- [《低安老gay逼，钓鱼大师龙卷风级》](https://www.bilibili.com/video/BV1sK411K7fy/)：第一次钓鱼半小时就有人上钩，第二次却等得遥遥无期。想学用装配制造错觉、引人接战，可以看看这种连“对方肯不肯来”都算进玩法里的低安耐心活。

::: 黑料 偏振海霍克，网子先交学费
在[偏振海霍克篇](https://www.bilibili.com/video/BV1iv411y7ow/)下面，学生把老师最后一波的毛病挑得很具体：网子本来够得着，何必一起超载；网子烧坏，等脱离扰频再走的机会也跟着没了。颜红承认“确实失误了”，隔着两个盾扩摆的网子，没想到也会坏得这么快。后来有人再提，他自嘲“学了个假的超载理论V”。技能表里点满的那一级，到了现场还得接受观众监考。

这套配置的另一处取舍，也让评论区盯上了：没反跳，便被笑成靠“意念反”留人。他自己接梗“我赌你的船上没有反跳”，又说有经验的对手半甲就走，素材有一半都跑了。输出挤得再漂亮，对面只要不肯陪你打到底，片名里那条价比凤凰的小船，就得望着人家脱战。

所以这门课最有颜红味道的地方，恰好是老师没把尴尬剪到评论区外面去。网子怎么烧的，他认；对手怎么跑的，他也说。片名先替配置抬身价，学生再替配置找漏洞，来回几轮，观众记住的便不只是谁打赢了：做教学的人，同样会在自己最熟的活上失手。
:::

::: 黑料 小说没鸽满一年，不算久
颜红的连续剧不止低安日记，还有《EVE：德里克军事狂想》。2022 年，他在[结构抗毁电多米篇](https://www.bilibili.com/video/BV1Z34y1C72h/)里聊配置，解释有后勤时用甲抗，小队单浪时结构抗又有另一套好处。正经的战列讨论还在继续，读者忽然从旁边杀出来，问小说多久没更新了。

他查了一眼，回复“看了下没满一年”。读者来讨更新，作者却先替停更划了个周年门槛：只要还没跨过去，这事似乎就没有想象中那么久。视频里的船已经换过好几套配置，小说还可以继续停着；低安打架讲距离，写作也把读者和下一章之间的距离拉得相当充分。

更妙的是，催更的人根本没去小说那边蹲守，直接在战列 PVP 视频底下把作者截住。颜红换哪条船出门都能留下评论入口，书里的故事不往前走，书外的读者照样有地方追他。别人来问结构抗能扛多久，小说读者想问的是自己还得再扛多久，他那句“没满一年”，算给两边都展示了一回抗性。
:::

::: 评
半盏把低安玩成了一门有来有回的手艺：自己出去试船，回来给别人讲，再等别人把问题扔回来。学生照抄配置跑不动，他查技能；观众发现网子烧坏，他认失误。做久了教程，评论区也就有了批改老师的资格。

只有小说读者没这么容易打发。打架的问题好歹能回一句哪里配错了，问下一章什么时候来，他先算还没满一年。船上的网子会烧坏，催稿的人倒一直没松手。
:::
