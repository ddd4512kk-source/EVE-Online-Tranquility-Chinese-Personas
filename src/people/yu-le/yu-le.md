
老魏，游戏角色 yu le，公开头衔直写“老魏，FC”，如今在[萝卜](../2122186397/)的宝宝巴士。名字叫得老成，简介却很热闹：前面一个问号，中间挂预警频道指南，后面自称“OGC冠军”，再把OGC连写三行。指挥身份、实用入口和个人奖牌，都被他塞进同一张名片。

::: 红料 预警频道之外，他也跟着舰队进场
老魏的[战斗记录](https://zkillboard.com/character/2122668203/)有三千多条击杀，常开的有捕蝇草、德劳格、海军型催化剂和咒灭。这些名字里既有拦截船，也有驱逐舰：名片上挂预警指南的人，自己并不只待在频道里看别人报点。

2025年4月，DarkSide把星城摆到[BWF-ZZ](../../battles/bwf-zz-2025/)，PH带着主场的大队人马来拆，对面明知人数吃亏还是接了战。老魏也在反PH一方的参战记录里，站在这座最终没能保住的星城旁边。到了同年6月，他又开海军型神示随几十人的舰队打下数艘昂贵的无畏：六分钟里，海军型莫洛和泽尼塔接连出现在击杀记录上。星城那一仗输赢由整支舰队承担，旗舰击杀也不是他一个人包办；从小船拦截到坐进无畏，老魏给自己那张FC名片添上的，是实实在在的舰队履历。
:::

::: 红料 FC的名片，先摆一份预警指南
老魏在[公开简介](https://esi.evetech.net/latest/characters/2122668203/)里挂着一份中英双语标题的链接：“如何正确使用预警频道 how to correctly use intel channel”。FC三个字在头衔上，下面先让来客看到预警指南，这张名片倒把带队之前的功课摆了出来。毕竟指挥席再响，哪里有危险、哪里值得留意，也得先有人把消息送到眼前。他给自己留的门面里，除了称号，也给这类不太威风的基础功课占了位置。宝宝巴士的车可以开得热闹，驾驶席旁边挂一份看路的说明，总比只贴一块司机名牌具体；预警频道的功课也就跟着一同上车。
:::

::: 黑料 OGC冠军，三个字还要再念三遍
同一张名片的后半，老魏自称“OGC冠军”，下面又单独排了三行“OGC”。前面刚用预警指南摆出实用派的架势，翻到这里，个人领奖台就搭起来了。一个冠军称呼还不够醒目，缩写又排了三遍；扫过名片的人，很难错过这行自我介绍。外号里的“老”字显得稳重，名片这一角却颇有拿了奖就要反复展示的兴致。带队身份靠FC两字交代，自我介绍的音量，则由后面四次出现的OGC负责。
:::

::: 评
老魏把FC、预警指南和“OGC冠军”挤在一起，既要留一份看路的功课，也要给自己的称号找个显眼座位。指南只挂一个链接，OGC却能占四行；在这张名片上，实用是一门功课，排面还得多复习几遍。
:::
