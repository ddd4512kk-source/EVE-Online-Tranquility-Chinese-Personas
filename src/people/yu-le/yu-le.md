老魏，游戏角色 yu le，公开头衔直写“老魏，FC”，如今在[萝卜](../2122186397/)的宝宝巴士。名字叫得老成，简介却很热闹：前面一个问号，中间挂预警频道指南，后面自称“OGC冠军”，再把OGC连写三行。指挥身份、实用入口和个人奖牌，都被他塞进同一张名片。

::: 红料 FC的名片，先摆一份预警指南
老魏在[公开简介](https://esi.evetech.net/latest/characters/2122668203/)里挂着一份中英双语标题的链接：“如何正确使用预警频道 how to correctly use intel channel”。FC三个字在头衔上，下面先让来客看到预警指南，这张名片倒把带队之前的功课摆了出来。毕竟指挥席再响，哪里有危险、哪里值得留意，也得先有人把消息送到眼前。看样子，他给自己留的门面里，除了称号，也愿意给这类不太威风的基础功课占个位置。宝宝巴士的车可以开得热闹，驾驶席旁边挂一份看路的说明，总比只贴一块司机名牌具体。
:::

::: 黑料 OGC冠军，三个字还要再念三遍
同一张名片的后半，老魏自称“OGC冠军”，下面又单独排了三行“OGC”。前面刚用预警指南摆出实用派的架势，翻到这里，个人领奖台就搭起来了。看样子，一个冠军称呼还不够醒目，缩写得再敲三遍，让扫过名片的人也很难漏看。外号里的“老”字显得稳重，名片这一角却颇有拿了奖就要反复展示的兴致。带队身份靠FC两字交代，自我介绍的音量，则由后面四次出现的OGC负责。
:::

::: 评
老魏把FC、预警指南和“OGC冠军”挤在一起，既要留一份看路的功课，也要给自己的称号找个显眼座位。指南只挂一个链接，OGC却能占四行；在这张名片上，实用是一门功课，排面还得多复习几遍。
:::
