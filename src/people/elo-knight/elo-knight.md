Elo Knight，Black Legion 的招牌指挥，后来成了 FRT 欧美时区的一把快刀。[N老板](../1618197191/)经营的是一座华人星际工厂，他来负责工厂下班之后的夜班保安。2007 年创号，早年靠 Origin. 和黑军团闯出名声，谈合作时倒很痛快：有朋友，也有报酬。到华人圈里，这套雇佣兵本事终于遇上了最需要补齐时区的客户。

::: 红料 名将也得值夜班
他的战绩横跨重突、战略巡洋舰和后勤舰，三万多次参与击杀里，既有往前压的火力，也有给整队续命的活。到了长期带队的位置，真正要紧的是让几百个人在同一刻转向、开火、收脚。华人主力能在自己的黄金时段挤满频道，欧洲、美洲玩家上线以后，地图却不会替他们暂停；Elo 的用处，恰恰是在这班人最少、敌人最方便动手的时候，还能把舰队领出去。

2019 年 Origin. 加入 FRT，给底特里德的防守添了一支能反打的队伍。他带来的缪宁体系能靠速度与射程向敌方腹地伸手，让守家的人不必永远站在自己门口挨敲。可名将的日子也没有宣传片里那么潇洒：敌人在 BOZ1-O 同时拉起三支重突队，Elo 和 N 老板就得提前备队，盯着那些代表出船的绿灯，守上几个小时。工业玩家看到的是还能安心生产，指挥看到的是今晚又别想早睡。一个靠四处找仗成名的人，最后替熊猫守起了生产秩序；他的含金量，有一部分就藏在那些没能发生的袭击里。([南方战争回顾](https://thegreybill.wordpress.com/2019/09/02/the-long-invasion-of-detorid/)、[Noraus访谈](https://evenews24.com/2021/06/04/interview-with-noraus/))
:::

::: 红料 赢不赢另说，不能让大家白来
2013 年，Reddit 上有人问：Elo 打了那么多漂亮仗，为什么还有人讨厌他？问题挂出去，跟他飞过的人先来了一串好评，连 CFC 的驾驶员、在绝地挨过他装甲火炮洛基的对手也来凑热闹。问的是黑历史，评论区却开成了舰队售后回访。

跟队一年半的 JRoxas 把缘故讲得最具体：Elo 带队是为了让大家玩得高兴，出门一趟没意思，他会当成自己的失败。普通指挥空跑一晚，能说敌人没出门、情报不给力、队员来得太晚；他把这一晚算到自己头上。队员把几个小时交给 FC，交的不是一张随叫随到的出勤表，指挥得拿一场值得来的行动还回去。赢了当然更好，可把人叫上线，再让人对着星门干坐，也是在消耗组织的本钱。

这才解释了他为什么能把一批人带着到处走。有人在楼里用 BL 敢当少数派、敢对大集团下手来解释他的名声，也有人把这种声势看成精英小团的自我吹捧；愿意跟他的人，先记住的是晚上有没有白来。后来 FRT 请他守欧美时区，买到的不只是一套缪宁配置，还有一群相信这个人能把夜班变成节目的人。名将吸引舰队，靠的是队员下线以后，还想知道他下一次什么时候开麦。（[讨论及跟队者回复](https://www.reddit.com/r/Eve/comments/1hikon/why_does_everyone_love_to_hate_on_elo_knight/)）
:::

::: 黑料 联盟抢到手，先让自己点没了
早年的黑军团故事，Elo 自己讲得比敌人还省事：先被原来的老板踢出去，后来拉来更多军团，让 Origin. 坐上执行军团的位置，把联盟拿了回来。夺权的关键是一群肯跟他走的人；别人掌着名义上的招牌，他把能投票、能打仗的队伍攒到了自己这边。

照常理，接下来该轮到新领袖发表一篇永不解散的讲话。他偏偏把后半句接成了[自己不小心解散了联盟](https://evenews24.com/2013/11/23/seraph-ix-basarab-elo-knight-interviewed/)。挖人、结盟、夺权，一道工序都没省，最后在管理界面上替前任完成了复仇。FC 可以把敌人的阵形拆开，也可以把自己的组织拆开；前一种要算距离、算速度、算齐射，后一种只消权限够高。这段自供给后来华人老板们的提醒相当实际：请他来指挥，可以把整队交过去；联盟按钮最好另找个人看着。
:::

::: 评
他的角色档案还留着一段中文赠船铭文，感谢他和欧美时区战士保卫主权。雇佣兵收到这种东西，比收到一笔款更有趣：客户已经开始替他写共同的青春了。

但战场上的友谊也有换班的时候。2020 年他加入 GoonWaffe，在 FWST-8 站到了 FRT 所属联军的对面；后来又回到 Origin. 和 FRT。熊猫请来的刀确实锋利，握刀的人也始终保留着自己的手。说他是华人圈的外援毫无问题，要把他写成谁家的永久装备，就得先问问下一场仗在哪边。
:::
