小沙狐，游戏名Snow Kidfox，又叫上九天，熟人还给他备了个更不好听的称呼：老赖。他是龙焰AT22亚军队的老打手，简介里引用“远交而近攻”，决赛却得跟着整队不断换距离、换船、换打法。总决赛第三局他开海军先知全灭，第四局换一条小小的磨难活着拿下一胜，最后又开伊什塔进了决胜局。银牌是后来打出来的，老赖这块招牌，则牵着一条自动导航的帕拉丁和一笔最后由别人代还的借款。

::: 红料 KB：上万次参与，最后还得一局局算
他的[公开战绩](https://zkillboard.com/character/96137114/)从2016年留下记录，过百个有记录的月份，一万多次参与击杀，单杀上百。大部分战果都在和别人共同作战时积累，损失相对少；长年跟队的人，知道什么时候该跟上，也得知道自己能不能全身而退。上万条记录最后压进十人比赛，旧成绩只能当底子，不能替任何一局先记一分。

2024年[1N-FJ8](../../battles/1n-fj8-2024/)，他先丢[莫洛](https://zkillboard.com/kill/122868966/)，接着又留下剑齿虎的损失；到了2025年[希瑟伊德](../../battles/siseide-2025/)，在Snuff的AVDOT，他丢了[狂暴级舰队型](https://zkillboard.com/kill/128025323/)，又换[复仇者](https://zkillboard.com/kill/128025500/)参与后面的交火。无畏、轻拦、战列不是摆在简介里的收藏，上一条没了，下一条照样出门。赛场上从海军先知换小护卫的那一下，也就有了平日机库里的老习惯作底。

AT22总决赛第三局，海军先知跟队一起丢了；第四局他换成磨难，从大火力位挪到支援小船，活到结束。大船有大船的份量，小船也有小船必须占住的位置，选手的价值落在能不能跟着全队调整。前一场全灭，后一场生还，他用两种大小差得很远的船，接住了队伍重新把比分追平的那一轮。
:::

::: 红料 “远交近攻”之后，是五局银牌
[DC的官方名册](https://www.eveonline.com/alliance-tournament/dracarys)把Snow Kidfox与[Sayler](../2113271910/)、[斑鸠](../2113386745/)等人排在一起。这支队伍的来路横跨几个比赛圈，平时的朋友、旧队和联盟旗号，都在这次阵容里重新碰头。他的[简介](https://esi.evetech.net/latest/characters/96137114/)倒很有旧式兵书的口气：“得寸则王之寸，得尺亦王之尺也。”

决赛里，寸与尺被换成了五局。DC拿下第一局，连失两局，再追回第四局；第五局他坐伊什塔，最终与多数队友一起丢船，冠军就停在最后那一步之外。兵书里可以一寸寸吞地，比赛却在时间走完时立刻算账，多争来的一局也必须写进履历。

他把总览和旧建筑名字挂在个人名片里，长年的游戏生活留着不少门牌；AT22又给这张名片添了一块银牌。做过多少旧战场的熟人，到了这里仍得坐回十个人中的一个座位，跟大家一起把最后一场输赢承下来。
:::

::: 红料 几个小箱子，把新星城卡在地基上
2026年，FRT 在 4-HWWF 要立一座新星城。选址是工程组连夜量出来的，哪个位置能罩住矿区，哪个位置离对面的跳点远，图上一格一格画过；舰队在外围排好队形，舰桥频道里指挥已经报了倒计时，就等拖船把星城往那个点上一放，锚一抛，建筑就算站住了。星城在联盟里不是普通建筑，是整个主基地的脸面，从落地到站稳，中间那段窗口谁都能来踹一脚，所以这一步必须干净利落。

小沙狐没打算让它干净利落。他开着货舱塞满移动式仓库的船，比拖船先一步溜到了那个点上。移动式仓库是新手教程里就送的小玩意儿，一只只往太空里一丢，不值钱，也没人当回事。他挑的恰恰是“合适的位置”：这只放在锚点边上，那只摆在拖船必经的角度，再补两只压住周围的空隙，间隔量得比工程组画图还仔细。放到第四只，他发现了那个缝隙：星城要落的那块地被这几只箱子的判定圈占住了，系统一边说“这里不能放”，一边又不肯把箱子判定成障碍，bug 就这么卡出来了。

工程组到场后，起先都当是自己手滑。拖船对了一遍位置，放不下去；往旁边挪半格，还是放不下去；换个角度再试，系统照样弹回来。折腾了几轮，才有人想起该看一眼锚点周围，这一看，满屏幕十来只移动式仓库，名字全是默认的，小得谁也没往心里去。挨个点开查所有者，查出来全是同一个人：Snow Kidfox。频道里的倒计时就此报不下去，指挥改了口，让全队先把这人找出来。可小沙狐早就收了船，躲在隔壁星系，一边嚼着东西，一边看着这一整支舰队为几只箱子团团转。

清箱子成了新的活儿。仓库是别人的资产，得先打掉才能挪，一只只打，一只只重新对位，每清掉一只又发现下一只后面还藏着一只。星城锚定的时间表被迫往后推，推了一回又一回；守城的舰队不能散，只能干站在原地等，对面看见这一边的阵型停了半天，闻着味儿就来了，民用的小船在外围转着圈，把队形戳了又戳。一座千亿级的大家伙悬在半空，拖船不敢放、箱子不敢留，进退两难，全联盟的节奏被几只教程小箱子按住了。

当年他连一条帕拉丁都供不起，借钱刷怪，翻车后还靠别人代还；如今拿几只仓库，就让对面一座星城迟迟落不了地。老赖这块招牌，在 4-HWWF 总算换了个叫法：钉子户。星城站不站得住另说，那几只箱子，倒是比哪座建筑都更先在那片空间里扎了根。
:::

::: 黑料 帕拉丁自动导航，欠款原地装死
刚来欧服时，小沙狐一穷二白，找AVDOT的诸葛亮借钱去刷怪。先借一笔启动资金，再靠刷怪挣回来，本来是个能把日子过起来的打算；他接着买了条帕拉丁，还把这么一份家当交给自动导航。诸葛亮事先把话说到了：“我和他说他必死，他不信。”钱借到了，船也买到了，老玩家的劝告反倒成了最省得听的一项。

结果小号AIIahu Akbar真在高安出了事：帕拉丁走到犹大码，被CODE.的人强暴，留下价值约17亿ISK的损失。刷怪的本钱还没来得及长成家业，先成了别人的战果。诸葛亮再翻这桩旧事，给他的下一步下了句更损的评语：“然后死了就装死不还钱。”船炸了，借款可不会跟着爆炸；这趟自动导航替他把船送到了海盗面前，却没替债主把钱送回来。

这件事最后还有人收场：有人替老赖把钱还上了。旁人问，要是没还会怎样，诸葛亮答得干脆：“那老赖肯定被我踢了啊。”一笔借款于是连着两道关口，前面是高安路上的强暴，后面是留不留得下来的交情；船没过第一关，人靠别人代还过了第二关。诸葛亮接着留了一句“AVDOT好心人”，也把这段旧账的余味点透了：后来小沙狐还能继续上船，早先那条帕拉丁沉下去时，有人连他的退路一块捞了起来。
:::

::: 评
小沙狐的“近攻”打了十年，AT22又一路打到第五局。上万次参与击杀没有把比赛变简单，却让这块银牌背后站着一个早已习惯继续上船的人。只是从帕拉丁到银牌，他自己挣回来的成绩可以挂在名片上，别人替他结过的旧账，也还挂在熟人的嘴上。
:::
