
流年，游戏角色 caijiliunian，2024 年在东方利剑做过新人教官。有人抱怨入团说好技能合格送雷裔，后来又要语音活跃、跟团长搞好关系，他马上替军团答辩：税收已经分给团员，福利都是团长个人掏腰包，发不发得看团长愿不愿意。

这场[福利争执](https://tieba.baidu.com/p/9218435760)从一条雷裔吵到群聊活跃，又吵到蜜蜂的便宜船能不能卖去吉他。流年原本想证明新人不合群，讲到最后，已经在替公共市场划阵营。

::: 红料 领过福利，也做过教官
流年在[自己的回应帖](https://tieba.baidu.com/p/9220680410)里说，上月底入团后，他分到四亿税收，未满七天又拿到两亿 ISK 和二十亿雷裔的钱；开狂怒参与反收割，三千万的船损拿到两千万补损。于是他认为，这种税分给团员、团长另外掏钱的军团，不能一口叫成税猪团。

他也接过新人教官的活，反复提醒新成员上语音、参加活动。只是到发帖时，他已卸任，解释是这位新人“没能力带好”。福利自己领得顺，别人为什么领不顺，却成了他得公开回答的问题。教官这份差事，最后从带人进游戏变成带着截图进贴吧。
:::

::: 黑料 军团的福利，团长的心情
新人说，群公告写技能合格送雷裔，自己达标却被告知不够活跃；流年则说，入团前就解释过个人承包制，军团不留税、不发福利，全部是团长个人赞助。对方不上语音，不参加会议、反收割与集结，想拿船才出现，不能把团长当提款机。他还质疑这人已有一千多万技能点、会倒货，哪有那么纯的新。

新人逐项顶回来：活跃究竟按什么算，为什么公告没写清，为什么给了条件又换说法？流年把话压到最直白：“团长个人发福利，不发你去问团长。”在他的版本里，连退团也是新人自己退，群里仍留着人，不存在军团扣着资产不放；新人则坚持，后来遭到了踢出和拉黑。

围观者又翻出流年与“两仪”的旧争执，反问别人答应他的钱没发，他会追究，怎么这回又能把最终解释权交给团长？流年回应，那次是对方主动要求他报 ID、明确答应给钱，后来又改口举报，这与自己军团事先说个人赞助不同。

看样子这笔福利账最难核的不是技能，而是承诺到底算谁的话。新人把公告当兑付条件，流年把老板掏钱当决定权；他们越努力解释，雷裔就越像一份先有广告、后谈审批的赠品。
:::

::: 黑料 便宜船运到吉他，怎么就资敌了
争吵里，流年又提起新人从 1DQ 买便宜船，运到吉他倒卖，认为这说明对方既不是真不会运货，也没有好好融入军团。新人说，有人愿意买、有人愿意卖，自己一趟几十分钟赚个辛苦钱，为什么不行？

流年的解释把买卖拉到了阵营上：要的是把船运到 TCAG 卖，不是运到吉他“资敌”；帝国的便宜船低价放到吉他，买家在他看来会是对面。他又指责对方趁蜜蜂搬家倒卖军火。新人干脆替这套说法下了结论：赚的东西只能本地卖，运回高安就是通敌。

双方还吵了一条龙卷风的差价。流年称对方两千万买、四千五百万卖给自己，号称 1DQ 中间价，自己去看却约三千万；新人则拿流年在中文频道收卖脑浆的报价反击，流年答：“我正常收货卖货咋的了？”

看样子流年并不反对买卖，他反对的是这笔买卖没按自己认可的方式做。给自己卖贵了是忽悠，卖到吉他是资敌，自己收货转卖则是正常生意。一条雷裔还没交付，连市场里的船都先被拉去验阵营了。
:::

::: 评
流年说自己拿过真金白银，也确实替军团解释得够认真。只是替老板省一条船的功夫，顺手把新人是不是萌新、够不够活跃、卖货算不算通敌全审了一遍。

福利本来想拉近团员关系，吵到最后，领船像讨赏，赚钱像过审，教官的解释倒比配船表还复杂。
:::
