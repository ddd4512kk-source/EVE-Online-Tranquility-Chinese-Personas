麦克EVE，2025 年二月入坑，五月就办起了古斯塔斯舰队。别人刚学会找军团，他已经开始研究怎么当 CEO，顺手把创业过程连载成了[建团日记](https://tieba.baidu.com/p/9697528989)。招新、收税、后勤、融资、外交，一样一样现学现用，碰上问题还会回头给早期的自己写批注。几个月看下来，军团经营得怎么样尚且可以争，CEO 的纠错记录倒是一天比一天厚。

::: 红料 先在杆子里学会打架
麦克的起家本事是低安小船战。MacEVE 在四月至六月反复出战，单杀也占了一块，常见对局是几个人围着小船互相找机会；创团号 MacPlus 到七八月才有更集中的战斗记录。他招新人时说刷怪和刷人一起玩，自己也确实在这个环境里挨过打、还过手。后来 Maco1x 去了零安，跟着队伍打起更大的战斗，这位不愿上班的 CEO，终究把自己的游戏版图也越铺越远。
:::

::: 红料 把军团养到不用自己喂饭
五月起步时，麦克的招新群设成了不可搜索，广告已经发出去了，人却进不来。新人终于进门，又遇上军团项目已经付出三千万、LP 还没到账，研究一番才发现税没调好。CEO 和新人一起探索游戏玩法，这句广告从第一天起就兑现得十分彻底。

但他也真在做事。快递交给联盟，巡洋舰战备改找人外包，累人的活能转出去就转出去。到了七月，团里有了总监，有人能组织活动，成员也开始协作推进星系。七月二十一日，他终于记下军团可以脱离自己运作。很多 CEO 把事事经手当权威，他忙活几个月，最盼着的却是大家终于可以少找自己一点。这支团真正长大的一刻，是老板发现自己有机会歇口气。
:::

::: 黑料 零利润保鲜两天
五月二十三日，麦克宣布 LP 按商人价自动收购，军团零利润，福利靠大家募资。新人负责绕杆子，CEO 负责操心，钱从热心团员那里来，听着像一间刚开张的慈善铺子。

两天后，收购价变成一千一百五，出售价一千二，差价拿来发福利。理由也讲得直白，募捐太麻烦。零利润这个招牌只挂了两天，老板就发现慈善最累的部分是挨个伸手。差价去向公开交代了，倒也实诚，就是第一版商业计划还没捂热，第二版已经开始营业。

六月他又试着小规模融资，还发过一次分红。到了七月复盘，自己嫌这套股票系统没价值，退坑的人照样能领钱。前脚为了省募捐的麻烦开起收购生意，后脚又为了筹钱请进一批不用上线的股东，麦克研究了几个月，终于明白军团里最稳定的岗位可能是收分红。
:::

::: 黑料 不去零安，直到必须去
五月十二日，麦克说不去零安。六月一日又把理由讲得很透，太累，累了就会退坑。这是一位新人 CEO 对自己精力的准确估价，本来很适合贴在桌前，提醒自己少揽点事。

可同一天，他又补了一句“话说太死了，00是必然会去的”，还要保住军团番号。六月十八日的[招新帖](https://tieba.baidu.com/p/9801303099)依然写着不进零安，七月四日，评论区里就开始解释这几天正在进零安。广告负责安抚想轻松玩的新人，CEO 负责追赶已经变化的计划，两边隔着半个月，各自都还在上班。

他也试过先让骨干各自找零安团。五月的六名骨干，一人去了联盟大团，三人去了租地团的另一家，一人失踪，最后只剩一人留团。算盘原想打成大家出去找资源、回来带新人，实际先把自己的教官班底送散了。麦克后来承认，自己时间变少是主要原因，第一套方案也失败了。折腾到最后，答案又绕回亲自建零安团。原先怕累不去，后来为了让军团继续活下去，自己把更累的差事领了回来。
:::

::: 评
麦克给军团定的最终目标是不退坑、持续活下去。八月底，日记写到了自己快退坑，后来团员在楼里说 CEO 已经不玩，另组了新团。几个月前还在规划大家怎么留下来的人，最终先碰到了自己的精力上限。

这篇创业日记最有意思的地方，是他经常亲手把自己的招牌拆下来，换上一个暂时更管用的。零利润、不去零安、骨干分流、股票融资，每次都带着解决问题的诚意，每次都能再长出几个问题。军团经营的学费，他交得勤，批改得也勤。
:::
