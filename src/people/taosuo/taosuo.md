
套司令，游戏名 taosuo，头衔就两个字“套索”。创世倾域从国服带出来的老人之一，2020年进欧服时进的就是 ChuangShi，在 FRT 里一待三年；2023年1月自己拉起矸石山（Gangue hill），当了 CEO，至今还留在 FRT。

他在 eve欧服吧露面不多，被人提起时多半带着“司令”二字：要么和[胡司令](../2115924739/)并称创世的国服元老，要么被翻出一张拖了十几年的欠条。

::: 红料 人如其名：专门负责把人套住
套索这个名字起得不虚。翻他的 zKillboard，用得最多的船是 Sabre 截击舰，记了227次击杀；后面跟着 Lachesis、Huginn 两种侦察舰，再是 Stiletto 拦截舰和 Arazu。这一串船都不是用来打伤害的：截击舰扔泡泡把人拦在原地，拦截舰冲上去点住，侦察舰远远拴住、减速、断跃迁——干的全是“套”的活。

这种位置在舰队里不显眼。KM 上名字排在一长串输出后面，可没有人先把目标拴住，后面的大炮连开火的机会都没有。这位国服老人把位置摆得很清楚：不抢最后一击，先把目标拴住，让后面的火力有机会落下去。

账面也说明他不是挂名：在 ChuangShi 的三年里参与击杀八百多次，总价值约6066亿；2021年9月单月一下记了三千七百多亿的参与击杀，那是全账号最肥的一个月。损失总共不到180亿——拴人的船便宜，丢了也不心疼，这算盘打得比谁都精。那年9月的[A1-AUH](../../battles/a1-auh-2021/)会战，他开军刀跟着大队围攻夜神；自己也折了船，连太空舱都上了另一艘夜神的战报。
:::

::: 红料 Ganguehill套索：一年里拍了二十一条套人录像
2022年9月到2023年2月，他用“Ganguehill套索”的名字在 B站 投了二十一条视频，矸石山军团简介里挂的就是这个空间。片子大多一两分钟，标题直白得像战报：《FRT轻松斩冥府，完成对蜜蜂超旗4族大航4连斩》《1DQ蜜蜂老巢隔壁2分钟速斩飞龙》《赏金系数回归首日，蜜蜂万古祭旗。》，后来还整理成“FRT超旗斩！斩！斩！”合集；日常反收割另编了一套“EVE欧服静寂谷生存日记”。

那几个月正是 FRT 在静寂谷天天跟找上门的客人结账的时候，他的镜头就对着这些场面：直钩钓洛基、制裁 MTU 战士、ESS 里抓偷钱的神装洛基。连标题都透着一股老猎人的得意——“直钩钓鱼”，意思是鱼自己上的钩。

最损的是两条以人名打头的片子：《胡司令的高清夜战》和《纱布的高清歇斯底里》，标题直接把创世两位指挥拉出来示众，一个“高清夜战”，一个“高清歇斯底里”，给谁看的面子大，一目了然。播放最多的反倒是一条26秒的《EVE欧服FRT联盟最强补给官创世豆腐400人补损操作》，六千多次——在 EVE，打赢不稀奇，补损发得快才是真本事。
:::

::: 黑料 小马欠了十几年
2022年4月，[墨绮](../2113239951/)在 eve欧服吧公开了一封创世军团邮件，楼里吵成一锅粥。吵到一半，有人插了一句“mumble找套司令给你造”，看来套司令在圈里还兼着造船的名声。紧接着另一位老朋友就翻出了旧账：

> 写的挺好的，支持一下。PS：妈淡，套司令帮我制造的小马啥时候给我，都拖了十几年了

十几年，往回推已经是国服的事了。按这封旧账的说法，一笔小马订单拖成了十几年的期货，套司令的生产线排期已经比 CCP 的平衡补丁还长。照这个工期，订单人只能盼着他哪天想起来——或者干脆把这张欠条传给下一代。

人如其名，套司令套住的东西向来不放：敌人的船套住了跑不掉，朋友的小马套住了也到不了手。
:::

::: 黑料 国服旧账：把人逼出了 TGA
套司令在国服的往事，也有人记着。2024年3月，一位已 A 的老玩家在 eve欧服吧写[回忆录](https://tieba.baidu.com/p/8921766760)，说2013、2014年前后在国服，他是“被魔神重生和套索逼的被迫离开TGA”，带着军团去了埃玛马克的低安海盗联盟，人口从日均在线五十掉到二十，过了好几个月苦日子才回到 TGA。

这段发生在国服，回忆录写到套索，只用了“逼的”两个字，一笔带过，怨气倒是十年都没散。按这位老玩家的回忆，套索和魔神重生一起把他的军团逼出联盟；这段经历后来还被他写进回忆录。2020年8月套索刚进欧服那阵，吧里有人发帖起哄“昔日TGA巨头重聚欧服”，回复里点的正是魔域冰人和套索——两位司令一前一后过来，旧部看了都以为要密谋什么大事。十年后回头看，被逼走的人写回忆录，逼人的人开了个养老团；江湖恩怨最后都成了吧里一段闲话。这段回忆只留下“逼”字，没有交代当年的具体冲突；对方后来回到 TGA，套司令则在欧服重新拉起了自己的军团。
:::

::: 黑料 养老团写着长期 PVP，CEO 自己歇了
2023年1月15日，他离开 ChuangShi，当天就建起矸石山，自任 CEO。军团简介写得很坦白：“我们这都是些年纪大的老年人”，业务两项，“长期组织PVP”和“养老”。

后来创世内部闹翻，2026年2月军团跟着[两千](../2114301554/)与[加一](../2113399287/)出走绝地，吧里有人把他和胡司令并列成“国服出来的创世老人”，说他们一起出走；立刻又有人纠正：两位司令因为倦怠不愿离开，继续留在 FRT；再有人补一刀：“套司令好几年前就离开创世了”。三层楼各说各的，至少证明他走得早，走得也安静。

至于“长期组织PVP”，他名下在矸石山的击杀记录只有十几次，跟当年在创世拴人的八百多次一比，基本是退居二线了。如今这个团有一百七十多人，简介说得明白：只有主动联系才通过，不要直接申请。招新广告写 PVP，CEO 本人更像是在实践第二项。
:::

::: 评
套司令的一生，用一个名字就讲完了：国服时把人从 TGA 套走，欧服时开着截击舰把敌人套在泡泡里，顺手把朋友的小马也套了十几年。

如今他开了个养老团，镜头对准别人，语音录下胡司令和纱布，自己躲在拴人的船里不出声。时人谓之：不抢击杀，不交小马，只管套住。
:::
