DOUCHU000号在B站给自己的签名写“DOUCHU000一号机”，真赶上PH散架，一号机最关心的事却是把家当开出去。2025年11月，他发了一条R-A星城撤离记录，标题直接向哥布林结账：“我不欠你什么了。”旁人看联盟兴亡，里面的人得先看星城门口的泡泡有没有缝。

::: 红料 联盟倒得太快，军团先把人叫醒
据他在[《绝密RA星城监狱 百亿撤离 哥布林我不欠你什么了》](https://www.bilibili.com/video/BV1QW2PBLEcr/)评论区的讲述，军团当时“夺命连环call了所有人”，集中整合资产越狱。有人提醒他跑得及时：蜜蜂嫌封锁效率低，半夜调整阵型，泡泡比前一天更密了。他也承认，早些时候还能跑出不少泰坦，大航和无畏相对好走；等到停机维护之后，大东西就难出去了。联盟平日讲的是前线和战略，临到散场，大家最有用的一次集结，大概就是接电话回来搬家。

观众问，被泡泡围着怎么还有船能走，他回答“有缝隙的”；问起拿跳驱挪重拦值不值，他的账算得干脆：“十条跳驱换一个大航也是赚啊。”还有人心疼留在里面的资产，他换了个角度劝：“在低安很富有。”听着像安慰，细想却颇有逃难者的经验：先把自己能带走的带走，剩下的财产换个地方继续富有。后来有人在楼里招呼他变蓝、带他离开，他回复“我们已经跑完了”。门口的泡泡还在，军团的搬家单已经结了。

只是搬完家，气还没消。他说一大早起来直接被气出“心脏病”，又说“从来没想过ph能死得这么难看”。标题里那句不欠哥布林，大概也就有了着落：战时的账可以争，最后一程得自己带着船从缝里挤出去，感情账自然也要重算。
:::

::: 红料 越完狱，也进过更新节目的制作名单
他后来不只在自己的撤离记录下回答问题，也参与了欧服中文社区的合作节目。[《吉他星系独立！海四空间站20年没改的克隆体服务终于实装！》](https://www.bilibili.com/video/BV1MY5C66EtJ/)由[76](../2117010442/)上传，公开创作团队里，[眠眠渡春](../2115958161/)署“合舞”，[死枪](../2114324057/)和[NoNo](../2113426221/)等人署“手工制作”，DOUCHU000号也列在“手工制作”这一栏。

一边是军团连环电话催着上线搬家，一边是更新节目里一本正经的制作署名，这位一号机在社区里的活法倒没有随着一次联盟散场停下来。游戏里的大厦倒了，游戏外的节目还得继续有人凑；昨天研究泡泡的缝，今天又和熟人一起研究新版能讲什么。看样子，联盟可以把玩家变成难民，倒还没能把难民变成闭嘴的观众。
:::

::: 黑料 问新人群，他先聊别人家的本地
在[表妹](../2113228175/)的[《WC众》](https://www.bilibili.com/video/BV1GE411q7uD/)评论区，拾光电脑质疑AOM爆破新人群，DOUCHU000号则拿另一家联盟在本地频道骂人的事反驳。别人问的是新人群，他回答的是别人家本地，话题刚上桌，先被挪了个位置。看样子，碰到这种阵营争执，先证明对面也不干净，比顺着眼前的问题往下谈要省事得多。两边说的各有各的难看，放在一处，倒像拿两笔烂账互相抵扣。后来R-A撤离时他骂起PH也很直白，替一边回嘴和对另一边心寒，这张嘴倒是从来不肯只负责客气。
:::

::: 评
DOUCHU000号用一份撤离后的实用答疑给这次散场留了纪念：泡泡有缝，跳驱能换，大东西别拖，资产到了低安照样可以很富有。对联盟的最后一点信任，大概就消耗在那通催人上线搬家的电话里；对游戏的兴致倒还在，越完狱，仍能到别人的节目里报到。
:::
