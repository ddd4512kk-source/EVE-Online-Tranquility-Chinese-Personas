
飞奔的核弹，游戏角色N-bomber，宇宙流浪者Cosmic-Wanderers成员，贴吧叫day沈学连。2025年9月，团里打了蓝加，外面有人挂帖，他出来替军团说话：核查、赔偿、道歉，确认是spy便踢，处理“直接且果断”。话本来是要证明自家办事利落，对手却不肯顺着这份结案陈词走，回头就喊他先别把自己电鱼电死。

一边要讲军团如何守规矩，一边专挑辩护者自己的旧梗起哄。核弹还在替全团挡火，楼里的笑点已经先绕到了他身上。

::: 红料 核弹跟队出门，不只在酒馆里炸鱼
核弹自己也有[五百多次参与击杀](https://zkillboard.com/character/2120263809/)，从[1N-FJ8](../../battles/1n-fj8-2024/)的大会战，到后来随CO.WA开舰队型刺客参与[航母击杀](https://zkillboard.com/kill/127380135/)，战斗履历并不只剩帖主编的电鱼酒馆。驱逐舰、海军巡洋舰、隐轰和侦察舰都在他的舰队生活里出现过，队伍换船、换目标，他就跟着换位置；账上的战果是大家一起打出来的，不是核弹一个人炸出来的。

2024年黑色星期五，1N-FJ8从抓长须鲸升级成泰坦会战，核弹也在场。救援与围猎接连加码，昂贵旗舰接二连三地出现在战报上；对一个跟队的人来说，宏大叙事最后还是落到舰队频道里，要听命令、换目标、继续留在队伍里。半年后他在B-9C24随新军团参与航母击杀，敌人的大船再度摆在面前，这次身边站着的是宇宙流浪者。

可到了辩护帖里，他拿得出怎样的出勤，对方仍只肯给他留一条炸鱼船。太空里换个目标还能继续打，评论区一旦认准一个梗，再多的参战记录也换不来对手替他改剧本。
:::

::: 黑料 “第一时间处理”，却没抢到回帖的主动权
狗肉汤隔热条在[《远离init联盟军团》](https://tieba.baidu.com/p/10012132148)里挂CO.WA打蓝加YST连蛋一起打掉的事。[米奇](../2123055352/)先统一回复赔钱道歉，后来又公布“已被鉴定为spy”；核弹也下场，强调军团第一时间核查、赔偿、道歉，确认spy便直接踢团。他要讲的是军团已经查过、赔过、处理过；帖子却把结案陈词推回争论里，认定对方继续挂帖是在找茬。

但他没有停在处理经过上，又反过来骂FRT小号在东风刷怪，是“鸠占鹊巢的寄生虫”，说对方因为他们不愿同流合污，才来抹黑、栽赃；末了还把spy的智商素质和帖主并在一起损了一遍。这样一来，原本该解释谁打了蓝加，话题却先拐成谁更恶心。FRT宣传办在楼里质疑，被当作spy依据的只是个2021年后没上线的刷燃烧小号；CO.WA管理则说，朋友上号的解释说不通，再加上FRT小号，留下隐患太大。军团认定处理得果断，对面盯着认定的理由不放，核弹这一轮开火，又把两边的火药味替他们接了起来。

狗肉汤没跟他逐条对账，直接回“你当务之急该干的是炸鱼别把自己炸死核弹”，还叫他别再复读[小黄人](../2119497024/)的话。帖主前面已经拿孔乙己酒馆体编排过他：小二问又来买炸鱼船，核弹涨红脸讲“鳄梨特”，再拿“电鱼船死了那是正常开销”撑场面。这里的酒馆是对手搭的戏台，坐上台的却是来替军团说话的人；他想把楼里带回处理流程，对方偏把他写成一个先得处理好自己电鱼的笑话。整段辩护最吃亏的地方，恰好是他越强调军团已经处理，评论区越不肯把结论交给他来念。双方的争执焦点因此分成两层：军团是否处理，以及这份spy认定究竟凭什么成立。
:::

::: 评
核弹的口气很硬：查过、赔过、踢过，直接果断；顺便还要把对手的动机与素质一起判了。可公开对线不是军团公告，写完结论，下面的人还会接着回。别人拿电鱼梗来拱火，他又替军团把整场阵营仗扛上肩，名字叫核弹，回帖倒真容易先把周围的火药都聚过来。
:::
