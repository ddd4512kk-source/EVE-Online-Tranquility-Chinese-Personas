# 公共数据代理约定

适用于本目录及子目录，继承上级指令。共同标准见[仓库统一标准](../../docs/repository-standards.md)。

- 这里提供构建期全站数据，不保存第二份人工身份、战役归方或调查进度。
- `entityNames.json` 是联盟／军团名称与 ticker 的权威表，按 ID 关联；名称由正式抓取工具维护，人工只补已核实的华人军团 `chinese: true` 标记。不能用当前归属覆盖历史参战关系。
- 星系中文名在 `systemNames.js`；不自行音译。板块导航在 `sections.js`；站点常量在 `site.js`，避免模板中重复硬编码。
- 档案解析复用 `scripts/`；缺数与缺档案显式报错或按已有约定处理，不静默补造字段。更改导出字段时查所有模板、集合和测试调用点。
- 人物／战役字段的含义分别以[人物身份数据](../../docs/person-identity.md)和[战役模板](../../docs/battle-template.md)为准。
- 验收检查受影响目录与详情生成页，结构或脚本逻辑改动另跑 `npm test`。
