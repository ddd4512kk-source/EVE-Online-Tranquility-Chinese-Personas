# 共享模板代理约定

适用于本目录及子目录，继承上级指令。共同标准见[仓库统一标准](../../docs/repository-standards.md)，视觉规则见[网站设计](../../docs/site-design.md)。

- 使用 Nunjucks，HTML 属性用双引号，两空格缩进；沿用已有组件和 CSS 类，不另造平行的布局系统。
- 模板只呈现已计算的数据；统计、档案解析和身份匹配放公共脚本或计算字段。
- 链接、资源路径使用 `url` 过滤器；正文已有 `safe` 边界按原渲染链处理，新增外部文本不随意标记 `safe`。
- 交互用语义元素；开关核对 `aria-controls`、`aria-expanded` 与目标 ID，无 JavaScript 时正文和名单仍可读。
- 修改共享组件时核对全部调用方。按网站设计检查窄屏／宽屏、深浅色、无 JS 行为与控制台；构建后通读目录与详情的实际 HTML。
