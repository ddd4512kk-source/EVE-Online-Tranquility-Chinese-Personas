# 站点源码代理约定

适用于本目录及子目录，继承根目录指令。代码共同标准见[仓库统一标准](../docs/repository-standards.md)。

- 本目录是 Eleventy 输入；`_site/` 是生成物，不直接修改。内容、公共数据、模板与前端资源分别遵守目标目录的下级指令。
- 修改布局、样式、交互或可见字段前读[网站设计](../docs/site-design.md)。内容任务不必加载设计细则。
- 公共字段经 `_data/` 与 `*.11tydata.js` 提供，模板只做呈现；沿用 `scripts/` 的正式读取器，不重新解释档案格式。
- 不改变已有公开路径；链接用既有 `url` 过滤器兼容部署子路径。新增本地 CSS/JS 引用带 `?v={{ site.build }}`；Markdown 正文不经模板引擎。
- 全站板块只在 `_data/sections.js` 登记；新增板块沿用现有布局与导航机制。
- 代理指令和素材不能成为页面或搜索结果；增加内部 Markdown 时核对 `eleventy.config.js` 的忽略规则。`assets/` 是透传目录，不把内部文件复制到读者端。
- 验收执行根目录命令，并通读受影响的生成页；改路由、集合或共享模板时同时核对目录、详情与互链。
