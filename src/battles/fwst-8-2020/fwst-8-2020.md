2020 年 10 月 5 日，PAPI 把第一座星城钉进 FWST-8，帝国四分钟后便赶来拆房。五小时后城倒了，N老板没有收工：帝国舰队刚散，他就在同一星系放下备用的第二座。第二天帝国又来阻止它上线，双方熬了近十二小时，最后还是拆成废墟。CCP 记下第二轮超过七千零五十亿 ISK 的损失、八千八百二十五名角色；这场连打两轮的攻防里，联军把房子补得快，帝国也把拆迁班排得更快。

## 帝国

::: 红料 拿无畏排队，把城一点点磨掉
第一夜，帝国依托本地铁壁，不断补入远炮无畏，从不同方向维持对星城的火力。联军刚清掉一批，出站口又有下一批；连去堵增援的噩梦队，也遭到反打。守家守到这一步，最硬的不是一句“决一死战”，而是明知道下一条船也可能回不来，仍有人肯把它开进场。蜜蜂、INIT、RR 与 DC 的队伍各换各的舰制，目标却很一致：其他账可以回去再算，今天这座星城先不能活。
:::

::: 红料 阿舍把死战讲成真账单
[N老板的事后回顾](https://forums.winterco.org/t/topic/9163)说，联军低估了帝国愿意掏出来的储备，也低估了对手继续打的决心。[阿舍](../../p/1687651723/)战前说要死战，场上便不断有无畏、战列和隐轰接上火力，哪怕只够开一小会儿，也要让建筑停下来。这种指挥最让对手难受：你把他的船一批批清掉，他却把损失当成还在推进的攻城进度。联军以为前一夜已经打得够贵，帝国用下一夜回答，贵归贵，拆房子的预算还没花完。
:::

## PAPI

::: 黑料 老板自己先认舰制选错
[N老板](../../p/1618197191/)在第一轮复盘里承认，自己选的加力重突队很糟糕，靠其他联盟帮忙撑住场面；FRT 没带超航，带铁骑的建制也不够。一边想为长期战争保住后方刷怪能力，一边又要在当下的堡战里争每一点输出，老板的两本账当场打起了架。战略上省下来的便利，战术上总得有人补作业。仗还没打完，第二轮该换什么船，他已经在复盘后半段重新布置了。
:::

::: 红料 神使只剩六个点，老板差点发补损
按老板自述，帝国抓到一条 FRT 掉线神使，PH 的旗舰指挥先把诱导落下，后勤与加成赶来救场，最后在装甲只剩百分之六时接上俄洛巴斯天象，把甲量抬回约三成。老板一度已经准备发补损，结果救援硬把付款按钮往后推了。平时说谁是可靠盟友很抽象，等自家泰坦只剩一层纸，对方那盏诱导就比十篇外交声明都具体。船救了回来，星城却没保住，两个结果在同一晚各算各的账。
:::

::: 红料 一号刚倒，二号马上续上
老板事先就备了第二座星城，等帝国打完收队、本地人数降下来，又把备份放在同一星系。对守方来说，五小时终于拆掉威胁；对他来说，不过是把备用方案拿出来继续用。废墟还没凉，旁边又多一座新的。帝国赢下这一轮，第二天却仍得回来回答同一个问题：这次还拆不拆？
:::

::: 黑料 一千七百条重突，老板战后说浪费
按[N老板](../../p/1618197191/)的回顾，联军准备了大量重突和寒鸦，帝国却用远距离、分散跃迁与隐轰不断磨城。重突难追，寒鸦的导弹又被膨胀拖慢，预先准备的工具没能把眼前的活干利索。纸面上再厚的舰队，也不能保证每一种敌人都站到自己够得着的位置。老板战后把一千七百条重突称作浪费，承认泰坦该更早进场；船请来了，何时让哪一批真正干活，才是这夜交的学费。
:::

::: 红料 大会战打到最后，先得承认人会困
N老板在战后列出的教训里，不只有舰制和时机，还有人：两天打了二十来小时，这种作息维持不下去，指挥与成员都要睡觉。他和哥布林主张暂停继续放星城，另一些盟友却要保持压力、尽快换装接着打。大联合最难的后勤，已不是能不能再找一座星城，而是还能从几家联盟里凑出多少没熬倒的人。大家都想把战线推向绝地深处，谁先去睡、什么时候再叫醒，却不能只靠一条联合口号解决。
:::

::: 评
FWST 一号给双方各留一份胜利：帝国拿到废墟，联军拿到漂亮的船体交换账。二号又把同一个问题拖到第二天，帝国拿到战略目标，联军学到工具和作息都得换。N老板最像老板的地方，是两边还在算谁赚了，他已经把第二套房放下去了；可工业线能连夜补货，驾驶员没有一键补觉的蓝图。
:::
