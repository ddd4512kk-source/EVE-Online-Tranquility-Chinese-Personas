2026年11月6日，柯尔斯星域的ZZ-ZWC打了一场只有一个钟头的无畏混战。这块地方和[图万·奥斯神殿](../../corps/tuvan/)守了六年的OSY-UD同在一个星座，是欧服华人最早扎根的那片老地界。六百个飞行员里，五百七十多个挂着华人军团的名号：一边是FRT、G.O.T领头的反蜜蜂联军，混沌、特别执法部、神殿、盐鱼都来了；另一边是Goons旗下的华人分舰队，PLA一个军团就出了一百三十多人，红楼、昆仑跟在后面。同乡打同乡，打在同一片老地界上。

账单落得很不匀。UTC 14点前后到15点出头，四百七十九份击毁记录加起来三千三百五十亿，蜜蜂一方独自交出两千五百多亿，二百七十来条船；联军这边全部加起来八百三十亿。蜜蜂赔了联军三倍，这一晚的战利品却被两边都说成了自己的：一份投稿把标题写成“FRT&OSY两千五百亿击杀略显颓势”，意思是杀得再多，对面还是把那座“空堡”修好了，战略目标到手；贴吧的评论只有一句话：“空保守住了，荣耀win”。另一头的评论是“frt win！”，两边各自把同一份战报读成了自己赢。吧里有人给这场仗的战报安了个头衔，叫“全宇宙最公平最公正的br”。

## FRT、GoT等反Goons联军

::: 红料 七分钟转场，混沌的鱼雷乌鸦队
联军这一边最出风头的是混沌（CACX）的乌鸦队。B站上[歪歪](../../p/2115635957/)把这趟投送剪成视频，标题叫《CACX乌鸦队声东击西！7分钟转场突袭科尔斯！》。他的主号Witty Yy这晚留在军团名册里，只挂着“小歪”的头衔；坐进乌鸦的是小号Saucy Yy，打了八十二次击毁，一条船没赔。

乌鸦队怎么赶过来的，贴吧里有人当场追问“CACX怎么跑过去的”。回帖给了两个答案：一说开蛋过去，在附近的NPC空间站上船；一说其实是四个小时一路投过去的。哪个是真的，对面不会知道，对面只知道星系里忽然多出一整队吐鱼雷的乌鸦。[MCtimes](../../p/2119942097/)那晚五十三次击毁，[清水](../../p/2122271544/)七十七次，[哈威](../../p/2123311408/)七十二次，[石头](../../p/2121840947/)六十六次，四个人都坐在乌鸦里，整支队伍的伤亡只有[ACE-008](../../p/2121669020/)一条两亿多的乌鸦。吧里有人看完视频，评了一句：塌洞兽的鱼雷乌鸦队太牲口了。
:::

::: 红料 冷剑自己杀得最起劲，标题却替对面庆功
[冷剑](../../p/2114027991/)的秋名山露营者（CAMP.）也在联军一边。他坐一条狂热，七十九次击毁，在联军阵里算前几名。可这晚他往B站投的视频，标题却是《FRT&OSY两千五百亿击杀略显颓势，地滑社区修好空堡完成战略目标尽显风采》：他自己在前线凿穿了蜜蜂两千五百亿，回来的第一句话是夸对面战略目标完成得漂亮。

视频简介里除了一条战报链接什么也没有。这份战报把黑曜军械、Headwind排在了蜜蜂一队，和按旗舰伤害看到的方向正好相反。杀得多不算赢，赢的是把空堡修好的人，这笔账冷剑自己算得很清楚。
:::

::: 红料 特别执法部的FC、一条涅斯托和一座神殿
特别执法部（SARD）四十个人来了，CEO兼FC[嗜血](../../p/2113483277/)带队出战；[筱橘](../../p/2121532056/)开狂热，七十五次；[丝提西亚](../../p/2115264327/)的涅斯托这一晚一百二十八次击毁，是这页收录的华人里最高的一位；他的明日方舟（Arknights.）出了十四个人，旁边盐鱼、Family Guy这些华人小团也各自带人入场。[死枪](../../p/2114324057/)的黑曜军械和[乔伊](../../p/2113281289/)、[艾若](../../p/2116531837/)、[漫步](../../p/2116726862/)、[扎枪](../../p/2118780937/)各开各的船，把前排站满。

图万·奥斯神殿六十七个人上场。神殿的信条是“图万·奥斯即是门”，[舵主](../../p/91254848/)立的规矩是入团的大号死亡克隆要放在同一星座的OSY-UD。这回架打到了院墙外一个星系，神殿挂在G.O.T名下一口气来了六十七个人；G.O.T一家交出四百七十八亿，是联军里赔得最多的一家，“门”字写得很足，门板也跟着碎了不少。
:::

## Goons及龙焰

::: 黑料 全员华人的蜜蜂舰队，十七条泽尼塔下了水
蜜蜂这边来的二百二十二个人没有一个不是华人军团的：PLA一百三十六个，红楼四十个，昆仑二十七个，再加PLA Fleet、民兵卫队等几家小的。他们开的是无畏：这一晚交出十七条泽尼塔和八条凤凰系无畏，每条几十亿。头十分钟就掉了八百二十亿，第三、第四个十分钟又各是七百亿上下，一个钟头之后战场基本打空，全是Goons国库里的预算。

蜜蜂这边也不是没有人撑着。PLA这边的FC[青春](../../p/2114969276/)座舰被集火打掉，四亿七千多万，对那位在教程视频底下给PLA招人的老师来说是个不大不小的教训；[阿咪](../../p/94385114/)开台风，二十一次击毁；[夜色](../../p/2113975199/)是北风之刃的CEO，同样一条台风，二亿多，落了水。
:::

::: 红料 米拉的凤凰：全场最贵的一条船
全场最贵的击毁是14:49:30的一条凤凰海军型，八十二亿，车主是[米拉](../../p/2112406877/)。这位老玩家的名字原先写在神殿的老住户名单上，后来才转进蜜蜂的华人军团。他曾住过的那座神殿，这一晚有六十七个人站在对面，看着他的无畏炸掉。

这也不是他第一次拿无畏当鱼饵。2024年10月，他在GOT打泰坦的投稿评论里解释，原本是用无畏出去钓大航，结果钓上来一条泰坦；这回他在自家阵里当饵，上钩的是对面整队的火力。
:::

::: 黑料 小洋：一条泽尼塔六十五亿，再加十五亿的头
[小洋](../../p/2114834014/)在14:20:39被打掉一条泽尼塔，六十五亿六千万；再加一颗十五亿的太空舱，一个晚上合计八十亿出头。这位当年往FRT里不停安插带路号的人，如今躺在FRT的火力底下，不知道是替从前的老东家记了一笔账，还是替自己的带路党生涯交了一回学费。
:::

::: 评
这一仗两边都是华人，两边都在说自己赢。联军凿穿了两千五百亿，也没能阻止蜜蜂把空堡修好；蜜蜂守住了空堡，却用十七条泽尼塔、八条凤凰系无畏和一张全员华人的名单付了账。唯一没有争议的是柯尔斯这块地界：华人最早在OSY扎下根，如今同一个圈子的人分成两队，在隔壁星系互相打光了彼此的无畏。吧里那句“全宇宙最公平最公正的br”，两边倒都愿意认。
:::
