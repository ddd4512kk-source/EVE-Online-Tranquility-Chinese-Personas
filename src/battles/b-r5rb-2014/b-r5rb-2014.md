2014 年 1 月 27 日，万圣节战争还没打完，PL 的前线集结地先被一张账单掀了屋顶。主权刚转到 H A V O C 手里，自动缴费却没勾上，B-R5RB 的控制权当场掉落。俄罗斯联军与 CFC 看见空当就来抢，N3／PL 赶来救：这地方停着 PL 大批作战资产，丢掉空间站，机库里的船就会变成进得去、拿不出的家当。原本能用一笔小钱解决的事，终于变成全宇宙搬泰坦来结账。

战斗一路烧了约二十一个小时，连同外围交火，七千多名角色卷入，毁掉七十五条泰坦，各方损失约十一万亿 ISK。双方都把压箱底的船开出来，可账单越打越偏：CFC／俄方交了十六条，N3／PL 交了五十九条。忘记交费的是一个军团，最后交学费的是整片联盟圈。

## CFC、俄罗斯联军及友军

::: 红料 上次挨打，这次先把门堵住
几天前的 HED-GP，CFC 与俄方刚吃过 N3／PL“毁灭球”的亏；到了 B-R，对面还想把航母、超航抱成一团，靠维修和火力守住空间站。这次 CFC／俄方抓住周一突发交战、守方尚未集齐的空当，主动把整支旗舰力量压上，先争场上的数量优势。常规舰也有自己的活：去 N3 的集结点截援，让想救场的人先在路上打一仗。泰坦在主战场比谁更扛得住，外围小船则在替它们决定，对面下一轮还能多来多少条；大船的胜负，先从路口收起了过路费。
:::

::: 红料 小船、大船，都赶上了历史
[阿舍](../../p/1687651723/)那时还没有坐到帝国领袖的位置，开黑鸦跟着舰队上场；[叼爷](../../p/1387156123/)则在蜜蜂的 SUNDERING，开纳迦法参与旗舰会战。同一边的参战名单里，后来掌舵的人与华人老玩家并排留下名字，坐的却不是同一种船。历史并不要求人人坐泰坦头等舱，小船与无畏也在替这一侧出力；肯把船开到场，就可能赶上全宇宙最贵的一次欠费催缴。
:::

## N3／PL

::: 红料 FRT也在场，站的是这一边
[令狐聪](../../p/624049117/)和[内森](../../p/133854609/)当时同在 FRT 的 Light of the moon，跟着 N3／PL 参加这场会战。前者开黑鸦，后者上执政官，华人老玩家的名字就这样挤进了后来被反复翻阅的大战名单。几十条泰坦的结局把整场战斗钉在了败仗那一栏，小船与航母的身影却也留在其中：有人后来翻的是联盟兴亡，有人翻到的是自己当年开进火场的那条船。泰坦烧出的光足够照亮整个新伊甸，站在光里的华人，也并非都在赢家那一侧。
:::

::: 黑料 盯着一条杀，自己的账越滚越大
CCP 记述，N3／PL 的指挥权从 Manfred Sideous 转到 Vince Draken 手中，随后把火力压向俄方指挥 Sort Dragon 的泰坦。打指挥当然有道理，问题是目标扛住了集火，对面却趁这一段时间接连打掉五条泰坦。俄方把维修往 Sort Dragon 身上堆，N3／PL 则把时间和火力继续往同一个目标里填。指挥的名字当然诱人，可点名越响，越像给对面指定了一条必须保住的船；大家盼着它再抖两下就炸，自家的损失却先越滚越厚。等到战局倾斜，撤退也要交钱；五十九比十六，已不是一句“打得很热闹”就能抹平的差距。
:::

::: 黑料 退场的门，比进场的门窄
打到约十二个小时，N3／PL 终于下令撤退，场上的泡泡却不会跟着命令一起消失。来时是增援，走时便成了被留住的目标，更多泰坦、超航和旗舰在撤离中被打掉，交火一直拖到次日维护。真正让这场惨败难以下咽的，是它发生在自家的前线集结地：本来想保住空间站里的船，最后连已经开到站外的船也得抢着救。[CCP 的战后总结](https://www.eveonline.com/news/view/the-bloodbath-of-b-r5rb)把这笔账连同外围截援一起列出来；战场上的每一次“再来一轮”，最后都成了机库里缺掉的一排位置。
:::

::: 评
B-R 给新伊甸上了一堂昂贵的财务课：自动缴费的勾选框很小，能装进去的泰坦却很多。后来的人谈指挥、谈后勤、谈联盟兴亡，最好也留点敬意给那个不起眼的复选框——它没有一门炮，却挑起了十一万亿的账。
:::
