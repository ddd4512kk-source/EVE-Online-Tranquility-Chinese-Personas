
2023年12月21日，哈拉斯摆开两桌，桌上却没有哪一桌吃得轻松。FRT、PH、Snuff、Shadow Cartel及友军站在一边，深水和龙骑等队伍站在另一边；一边人多、旗号也多，另一边由深水顶着最沉的账单。低安的热闹从来不缺海盗，这次海盗把贵船也一起端了上来，准备收别人的船，先得答应自己的船也能留在这里。

最贵的交换集中在15时。旗舰后勤先出事，海军无畏接连倒下，深水和Snuff的昂贵损失交错着往外跳；PH的无畏也没能绕过这张收费站。六百多名角色卷入，烧掉五千多亿ISK。两边的损失都跨过两千亿，人多的一边反而付出更多。舰队规模给人底气，战后的船库给人清醒，哈拉斯把两样东西安排在同一个晚上交接。

## FRT、PH、Snuff及友军

::: 红料 大队伍撑场面，贵船轮流交学费
这一边的队形铺得开：FRT和PH带来大批角色，Snuff与Shadow Cartel也在同一侧，银雾龙骑、东风、帝国龙骑军团和星尘守护等队伍挤进战场。旗号从零安大联盟排到低安海盗，看上去像把附近几种常见的危险都装进了一支舰队。面对深水与龙骑，他们在这一场有了共同的对手；各家的船库却还得各家自己照看，共同作战不包共同报销。

[慕容](../../p/2114279817/)和[嗜血](../../p/2113483277/)参与FRT一侧的行动，[黑米](../../p/2117153585/)与[多米](../../p/2118339639/)在PH队伍里。FRT常规舰的损失金额相对轻，PH却有无畏接连折损。站在同一边，战后拿到的账单能差出好几个量级：有人回去补一条常规船，有人得重新掂量旗舰资产。战报把他们涂成同一种颜色，钱包依然各有各的颜色。

15时14分到17分，PH的多条莫洛级无畏在短短几分钟内倒下。常规舰队还可以靠数量把场面撑住，无畏的损失却不肯跟着场面变便宜；一条旗舰从太空里消失，留下的空位很小，留在账本上的缺口很大。大舰队的本事，是有人挨打时其他人还能继续开炮；大舰队的烦恼，是继续开炮也不能把已经炸掉的船再打回来。
:::

::: 红料 Snuff收割深水，深水也在收割Snuff
Snuff是这一边最显眼的昂贵损失承担者。15时06分起，普通无畏、海军无畏和旗舰后勤接连折损，损失与深水的贵船交错出现。两家在同一片火场里把旗舰往对方身上压，谁都在认真做生意，谁也没有只收钱不进货的好命。Snuff的低安凶名能替集结添气势，不能替每一条被点名的旗舰多长一层装甲。

[十六](../../p/2113841083/)、[ACR](../../p/2115611133/)与[sayler](../../p/2113271910/)参与这支队伍的交战。身旁有FRT、PH和其他友军，并不等于旗舰能安稳站在后排看热闹；压得越近，越容易把对面的贵船留住，也越容易成为对面最后几轮火力的去处。低安海盗最熟悉的买卖，就是让对方为了脱身付钱；这一晚轮到自己离场时，同样有人守着出口算价。

Snuff自身烧掉一千多亿，撑出了本方损失里沉甸甸的一块。它打深水打得勤，深水也把足够多的火力还了回来。联军人数占优，不能直接换成每家都占便宜；战场上能共享目标广播，船炸的时候，保险通知还是一封封发给本人。
:::

## 深水、龙骑及友军

::: 红料 深水顶住最贵一摊，龙骑坐在同一桌
深水这一晚承担了全场单个主要联盟里最重的损失。15时刚过，旗舰后勤倒下，接着海军无畏在几分钟内接连失去；常规战列也没闲着，一边承受联军火力，一边继续向对面还击。贵船损失挤在同一时段，最难看的地方就在这里：上一条的击杀报告还没来得及看完，下一条已经开始替它续页。

[汉堡](../../p/2117524558/)与[胡汉三](../../p/2119107966/)参与深水一侧的交战。深水面对的是好几家旗号组成的联军，却有龙骑等队伍站在自己这一边；火力来源多，账单也容易显得格外热闹。对面每一家都能从这片火场里分走一份战果，深水的船库却得把落在自己头上的损失整份接住。船是分批炸的，难受不用分批领。

龙骑的[兔总](../../p/91874271/)和[一捆烂胶带](../../p/2114508645/)也卷入这场交战，混沌仲裁等华人军团的角色在同一侧迎敌。龙骑损失比深水轻得多，仍有常规与支援舰折损。一个阵营里有人顶住重锤，有人付出较轻代价，战后却都得面对同一个问题：这一晚到底换回了多少值得花这笔钱的东西。深水付得最疼，龙骑也没能把自己从火场里摘成看客。

这一边合起来损失两千多亿，仍低于对面联军。深水单独看是全场最贵的一摊，合到阵营上，贵船的另一半故事便露了出来：打它的人同样在流血，Snuff和PH也往这场交换里添了大笔成本。哈拉斯的炮火很公平，谁把旗舰送进射程，谁就得留出一份回去重新攒船的耐心。
:::

::: 评
人多的一边烧掉更多钱，单个联盟赔得最重的深水，却站在损失较少的那一边。哈拉斯把“我打了多少”和“我们赔了多少”摊在一起，足够让战后的每张嘴各挑各的说法。

联军能把各路旗号排成一队，排不掉贵船挨打的风险；深水和龙骑能把对面的船打下来，也不能替自己已经炸掉的旗舰免单。开战时大家一起认目标，散场时，船库各自认领缺口。
:::
