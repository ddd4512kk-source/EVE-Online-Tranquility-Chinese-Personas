2026年11月初，帝国系把舰队开进了低安。B站情报节目把这次出门叫作“部署进攻低安自由港”，帝国这边的玩家自己剪视频，标题直接写成“帝国系低安抗议FC战役”：起因是一项跳桥电容改动，帝国认定这是低安的CSM递上去的主意，于是决定亲自来低安走一趟，看看提议的人还玩不玩得下去。低安各家平日里互相拆星城、互相蹲门口，这回被同一支舰队上门，才发现彼此之间还能有话说。

11月2日一天之内打了两桌。下午在[萨托加斯](../sahtogas-2026/)，帝国的台风舰队去打低安的建筑装甲，FRT、龙骑团、深水、影子卡特尔各自赶来，帝国九条无畏和两条战力辅助舰交在了这里。入夜后战场挪到埃玛马克和希瑟伊德，帝国拉出三百多条航母，INIT、Snuff、米玛塔尔舰队联盟和一长串低安本地联盟迎上去，FRT、北方联盟与TEST也从侧面朝帝国开火。两份战报合起来六千一百亿出头，帝国一方独自担去三千四百亿，是两张账单上最厚的那一份。

三十五条航母赔出去，换来的是埃玛马克一座打进增强的塔塔拉。三天后，11月5日晚，增强到期，帝国按着钟点回来收尾。胶带给上一轮的录像写的是“装甲战”，这一轮换成“结构战”，一字之差，赌桌上的筹码翻了六倍多。塔塔拉挂在 HYDRA RELOADED 名下，算低安自由港的门面，[Bluemelon](../../p/889732885/)把它比作《指环王》里守不住的欧斯吉力亚斯，把帝国比作兽人，低安那头的人听了都懂，这座城今晚是要拿命来填的。

这一夜5614人挤进同一片星系，两边几乎一比一：帝国及友军2774人，低安各路与INIT 2820人。从UTC 18点打到21点前后，五百多条无畏炸在一座七十亿的塔塔拉跟前，三千四百多份击毁记录加起来四万亿出头。低安一方赔掉两万五千多亿，无畏一口气交出三百四十多条；帝国赔掉一万四千六百亿，无畏一百五十多条，航母八十多条。帝国上一轮是账单更厚的那一边，这一轮把账单连本带利退了回去。

## 帝国及友军

::: 红料 三百条航母开进低安
晚上这一桌，帝国用的是航母。三百多名飞行员同时坐进航母，在埃玛马克把舰载机放满整片网格，Brave、Sigma Grindset、SONS of BANE和Out of the Blue的常规舰队也跟着进了同一片星系。这种规模的航母舰队在00区是平常配置，开进低安就成了示威：低安的大部分联盟凑不出这么多旗舰，帝国就是要让对面亲眼看见差距有多大。

帝国的老牌指挥[Asher Elias](../../p/1687651723/)这晚自己也坐在一条尼铎格尔里。平日他在频道里骂别人是懦夫，这回把自己的旗舰也押在低安的门口，算是给“抗议”这两个字作了表率。战果很快来了，五条低安的无畏和一条长枪无畏被航母群打掉；代价也来得一样快，帝国在这一晚陆续交出三十五条航母。[荣耀](../../p/1664583033/)的一条绝念也在里面，四十多亿，算是PLA在这一晚交的门票。这条船死得也有讲究：最激烈的时候他睡着了，大部队撤了，他一个人停在原地一动不动，被对面发现后集火打死。胶带的视频底下有人赞叹“死的何其壮哉”，还有人说荣耀在蜜蜂的政治地位又上升了。三十五条航母换对面五条无畏和一条长枪，帝国的账本上是一夜之间多出一千多亿的窟窿，低安这边算下来，这一晚没白熬。
:::

::: 红料 华人军团排进台风队
下午萨托加斯那一场，帝国的华人军团几乎都在台风级舰队里。新北风的[北风之刃](../../p/2113975199/)、PLA的[胶带](../../p/2114508645/)、红楼的[Dema1](../../p/2115768319/)和[MSG-Mashimaro](../../p/2122590961/)都开着台风级跟着大队去打装甲。PLA的[Jason Yusi](../../p/2114969276/)在这一场带队，同团的[TweakCuke](../../p/2122236855/)也在指挥位上，打到一半，他自己的船先被对面打了下来。

Dracarys也站在帝国这边。[多米](../../p/2118339639/)、[AUG SE](../../p/2114273804/)、[北宅](../../p/2115325695/)和[NanJin](../../p/2122496778/)都上了场，其中NanJin夜里在埃玛马克开着台风级丢了船。夜场的战报把Dracarys和TNT分进了低安那一队，两家整晚的火力却全都打在低安各家身上：战报排队按的是谁和谁一起出现，开火的方向才说明谁站在哪边。
:::

::: 红料 九条无畏换一圈增强
萨托加斯的仗是在15:00之后一口气打起来的。帝国把无畏放下来砸建筑装甲，FRT的希尔博拉斯与灾难舰队、龙骑团、影子卡特尔都朝这批无畏开火，不到一个小时，帝国九条无畏和两条战力辅助舰先后炸掉。装甲还是砸完了，帝国这一下午打过的建筑全部进了增强，活干完了，只是工钱比活还贵。昆仑的[Fauux](../../p/2122263187/)开着一条泽尼塔下场，五十多亿就交在这里；他平常每添一条超旗都要拿自家旗舰装满烟花来剪彩，这回不用自己点火，对面已经替他放完了。

胶带第二天把录像传上B站，简介写的是一串帝国内部的口号：“FC圣明，只是被低安CSM成员中的奸人蒙蔽了！”“800就800，800人我能打死跳脚的低安佬！”“帝国系玩家拼死对抗十八国联军！”最后一句是“你饿不饿，我诱导几个台风队给你打？”。无畏交了，装甲也进了增强，帝国这边的人自己先把这一下午编成段子，替对面省了嘲讽的力气。
:::

::: 红料 小航先死，给无畏当防火墙
18点刚过，先进场的是帝国的航母。低安的无畏已经摆好，帝国自己的无畏却还没落地，这四十五分钟里，绝念和尼铎格尔一茬一茬地往下掉，一刻钟八条，下一刻钟二十三条，再下一刻钟二十七条。上一轮三十五条航母换来的骂声还没散，这一轮开场又先送了五十多条，看战报的人已经准备好再笑帝国一回。

18点45分，帝国的无畏才砸下来，两边开始对射。头四个刻钟双方几乎一条换一条，每刻钟的损失从十几条一路涨到三四十条。到19点45分形势一下翻了：帝国这一刻钟掉二十三条，低安掉五十四条，接下来四个刻钟，帝国只掉十四、六、六、四，低安还在掉四十七、四十一、四十二、二十五。20点这一个小时，低安赔掉一万亿，帝国只赔两千三百亿，一场势均力敌的对射打成了单方面收账。

胶带的标题写的是“小航队神力扳赢战损”，评论区也认这个说法：“看来小航就是无畏的防火墙。”也有人补了一句，舰载机不吃服务器延迟，怎么堆都能堆掉。帝国的航母先进场替无畏挨了第一轮炮，又在时间膨胀里靠舰载机继续往外打伤害。八十多条航母，比上一轮死得多一倍还不止，却是这一夜账本翻过来的那只手。
:::

::: 红料 华人军团又排进台风队
帝国这边的华人军团，这一夜人数最多的是PLA四十一人、红楼三十七人，昆仑、Country House、北风之刃也各自带了人。大多数人和上一轮一样坐进台风级，跟着大队在塔塔拉边上转。[胶带](../../p/2114508645/)的台风19:12就炸了，[曲馨](../../p/2122590961/)的台风晚一分钟跟着下去，两位一个负责录像、一个负责教新人，这下都提前收工，可以专心看别人受苦。[夜色](../../p/2113975199/)、[德玛](../../p/2115768319/)、[小洋](../../p/2114834014/)和[随风](../../p/2115325695/)也在台风队里，[阿咪](../../p/94385114/)开一条忏悔者跟着PLA的队伍走。

旗舰位上，红楼的[米拉](../../p/2112406877/)坐了一条神示级海军型。这位平日在B站教扫描、出门抓大船的主儿，这回不用抓，对面的大船摆满整片网格，炮口转过去就是。[阿舍](../../p/1687651723/)照旧坐在尼铎格尔里，全场只赔了一些舰载机。上一轮他是“抗议”的表率，这一轮帝国的账本转了向，他那条尼铎格尔算是把抗议从头坐到了尾。
:::

::: 红料 开一炮能去冲杯咖啡
这一夜真正的主角是服务器。延迟极端的时段拖了四五个小时，有人拿它跟艾蒂斯那一场比；有人一连崩了十一个小时；有人说自己的炮七分钟才转一轮，转完发现旁边一个INIT的人正在打自己，也不知道他是什么时候来的。B站评论区替帝国道出了心声：“让低安爷们也享受一下开一炮能去冲杯咖啡回来坐着等的快乐时光。”帝国在00区泡了这么多年，把时间膨胀当家常便饭，这回算是请低安上门尝了尝家宴。

胶带这轮的标题叫“反FC战役”，评论区有人认真问：“为啥叫反fc战役 目标是把服务器炸了？”这个目标差一点就完成了：帝国打扫战场的时候节点又崩了一次，一地残骸三百亿，长须鲸排着队去捞。有人抢在崩溃前捞到几个舞女，高高兴兴上来汇报；也有帝国玩家晒自己分到十个舞女，说这是海盗公约规定的分赃；还有人说领导发给大家的只有纸糊的海盗帽，还是阿舍亲手折的，所以战利品理应归他，算是手工费。
:::

## 低安各路、FRT与INIT

::: 红料 去年拆过的首都，今年联手守门
龙骑团在萨托加斯的首都星城，今年1月刚被帝国和深水一起拆掉。[Awakeallnight](../../p/2114626303/)当时先发预告“保卫首都”，第二天上传首都被拆的全程。十个月后帝国又来了，他的新视频标题换成了“低安大和解，反Goons联军成立，第二次萨托加斯会战”：当初跟着帝国一起来拆龙骑团的深水，这回站到了FRT那一队里。

龙骑团的[红名](../../p/2114820390/)这一场在指挥位上，[烈冰玄武](../../p/2120988347/)也随队出了门。龙骑团的两条战力辅助舰在15:20前后被帝国打掉，一条八十亿，算是给这次大和解交的头期款。Awakeallnight开着灾难级海军型跟在舰队里，评论区有人问“混沌是FRT的军团，单独列出什么意思”，马上有人答：“因为混沌自己组了一个舰队。”低安和解得再好，FRT内部的军团还是要各开各的车。
:::

::: 红料 FRT分两队出门
萨托加斯一场，FRT一边由[Trumps](../../p/2113483277/)和[Jack098991](../../p/2122861740/)坐在指挥位上，[D manson](../../p/690534767/)、[Audacon Eyrou](../../p/2121687358/)、[j0y Chong](../../p/2113281289/)、[JJ](../../p/2115597604/)、[翔子](../../p/2123451407/)、[绿特](../../p/2112612580/)和[Even Rose](../../p/2112949937/)都排在里面；另一边是混沌的灾难舰队，[an yeu](../../p/2122293915/)、[哈威s](../../p/2123311408/)和[石总](../../p/2121840947/)都在船上。帝国的九条无畏，大半的伤害出自FRT。

Trumps的简介说热爱和平，B站还有人专门做视频教人怎么处决他的船；这一场他把指挥坐稳了，丢掉的只有一条拦截舰和一个太空舱。入夜后FRT又拉出一百九十人，带着北方联盟和TEST从侧面朝帝国的航母开火，下午打完无畏，晚上接着来收航母。
:::

::: 红料 INIT专挑最忙的时候来
夜里埃玛马克的主力是INIT。近五百名INIT飞行员压在帝国的航母舰队上，打出的伤害是第二名Snuff的两倍多。INIT的[Dark Shines](../../p/1869573834/)坐在指挥位上，他的绰号是“宇宙老三，专挑老二最忙的时候来”；帝国这晚忙着在低安抗议，INIT就挑这个空档来收航母。

Snuff的[Bluemelon](../../p/889732885/)开着灾难跟着打，米玛塔尔舰队联盟、Escalate、Can i bring my Drake…也都朝航母开火。低安自家五条无畏和一条长枪无畏交在了帝国的航母群里，Escalate一条长枪就是一百四十亿；能把三十五条航母留在埃玛马克，这些本地联盟付的学费也不便宜。CabbageTimil赛前的标题问的是“INIT或将联合低安势力对抗蜜蜂？”，当晚就有了答案；赛后他又补一期，标题叫“昔日盟友INIT暴力抽打帝国小航队”。胶带在自己视频的评论里提醒，INIT和BBC还各攥着一支整编旗舰舰队，这轮没动大招。这座塔塔拉的结构增强三天后到期，大招就留到了那一夜。
:::

::: 红料 把别人的主力当主力
上一轮INIT来了近五百人，这一轮直接翻倍，944人站在低安这一边，比蜜蜂之外任何一家都厚。胶带三天前在评论里就提醒过，INIT和BBC手里攒着两支整编旗舰舰队，上一轮没动大招；这一轮INIT的旗舰真开来了，赔了七千三百亿，人数和账单都压过所有低安本地联盟。

[黑暗闪耀](../../p/1869573834/)自己也开了一条泽尼塔，19:46炸在翻盘开始的那一刻钟里，六十多亿。这位“宇宙老三”平日专挑老二最忙的时候来，这回老二一点都不忙，就等着他。战后Reddit上有人开帖问低安这回怎么圆，他自己下场答得干脆：有赢有输，打得不错。B站评论的话没这么客气：“dark膨胀了，是该敲打敲打了。”帝国那边的总结更扎低安的心：把舰队主力交给外人，本身就是个馊主意。低安一方的人数是够了，可那两千八百人里，三分之一是从00区请来的客人。
:::

::: 红料 欧斯吉力亚斯陷落
[Bluemelon](../../p/889732885/)这场开了一条神示级海军型，20:22炸了，六十五亿；他没走，换了条龙卷风又回来接着打。战后他在Reddit发了一篇檄文，题目就叫《欧斯吉力亚斯的陷落》，落款自封“五届AT败将、自由港守护者”，开头便是沉痛的消息：兽人破城了。他写低安一波接一波地冲向那支上千条的旗舰舰队，打了，死了，最后只能把这座城丢给它的命运；这段悲壮文字后面紧跟一个括号，笑对面只捞到三百亿，废物。

帖子后半段转成了誓师，说这不是自由港的结局，而是新的开始，感谢低安各路联军、从00区赶来的INIT和四面八方的NPSI舰队。他说这一切是个了不起的故事，放在“EVE Online，那款太空船电子游戏”里也一样了不起。至于托尔金那边，欧斯吉力亚斯丢了以后还有一场大翻盘，就要看低安下回拉得出几条无畏了。
:::

::: 红料 塔塔拉死了两小时才肯死
这座塔塔拉被一千零九十九个人打过，光蜜蜂就上了七百八十八个。结构打到底以后，它却还稳稳挂在总览上，爆炸迟迟不来，服务器还在慢慢算这一夜的账。Reddit上立刻开了一帖，标题喊的是：塔塔拉还活着！低安的人抓着这根稻草喊了一阵，帝国的人回一句“死了”，那边回一句“没死”，大家管它叫薛定谔的塔塔拉。

21:43，击毁记录才终于落下来，距它“死”的时候过了两个小时。有人说肯定是停靠在里面的那哥们拿胶带把它粘住了，当事人真的出来应声了：是我，我跟着建筑一起沉了，还放着《泰坦尼克号》的主题曲。记录里还有三十九亿的氮燃料块，建筑到死都没缺油。七十亿的城，四万亿的葬礼，排场上已经对得起欧斯吉力亚斯了。
:::

::: 红料 低安华人也上了桌
低安这边的华人坐的位置比帝国那边杂。[小沙狐](../../p/96137114/)和[Sayler](../../p/2113271910/)都把小号塞进了神示级海军型，Sayler索性两个号一起上，主力号也不留作后手；小沙狐本人坐一条鹏鲲，一个人同时在前排赔钱、后排开炮。[狂天](../../p/2116350757/)、[天鹰](../../p/2120306116/)和[兔斯基](../../p/2112441816/)也都开鹏鲲下场。天鹰平日做视频教人认射程、认舰船职责，这一夜不必讲课，射程之内全是旗舰。

[Awakeallnight](../../p/2114626303/)的运气差一点。他开一条神示，19:51炸了，四十四亿，七分钟后太空舱也跟着没了。在这种时间膨胀里，七分钟不过是炮转一轮的工夫。龙骑团上一轮刚喊完“低安大和解”，这一轮他亲身验证了和解的成本。
:::

::: 红料 FRT赶到时，账快结完了
上一轮FRT拉出一百九十人，从侧面收帝国的航母，这一轮只来了八十一人，全场只赔七十亿。[W佬](../../p/93331025/)坐在指挥位上，B站号dzkell的录像第二天就搬运上线，给低安这边打了一波气，标题写的是“Init联军：我要代表正义消灭你”，评论区只有一个要求：时间膨胀能不能降一点。

评论区没打算替FRT留面子，有人直接交底：“frt一共才去了几十个人还打的快结束了才到。”七十亿这个数字，放在四万亿的桌上连零头都算不上。低安这边的亲情还得看胶带的简介：“那些个低安势力，是我芬里尔的挚爱亲朋，手足兄弟啊。”这话写得情深义重，只是作者坐在帝国的台风里，表达手足之情的方式是开炮。
:::

::: 黑料 联军外面在打仗，里面在清理门户
这一夜低安打得最贵的不是人数最多的那些。Escalate九十六人赔了三千一百亿，人均三十多亿，上一轮刚交掉一条一百四十亿的长枪，这一轮又交一条一百三十三亿的；Snuff二百八十九人赔了近六千亿，两家加起来比INIT还多。低安的本地老板拿真金白银撑住了场面，所以当有人没来的时候，骂得也格外响。

Sedition就是那个“有人”。战报把这家放在蜜蜂一队，Reddit上帖子一个接一个地问他们的youngpuke2去哪了，有人说这位正在写论文，证明跳桥削弱才害得人来不了，有人说这位的铁壁刚丢了。Sedition的人出来解释：我们九成成员在美服时区，这个时段没理由集合，把无畏全压上去送死。全场五十八人，只赔一百二十亿。

Seker Matar等不及了。这家二十一人赔了七百四十亿，打完之后一条龙卷风把一个Sedition的人堵下来，三十六亿的船就此报销，然后发帖庆功，标题叫“低安勇士手刃低安叛徒”。评论区跟着添柴：Sedition带十二条龙卷风能干什么？还有人翻旧账，说这家本来投票要加入联军，被youngpuke一句话否了。低安大军的旗号还没收起来，叛徒的名单已经开始拟了。
:::

::: 评
帝国来低安是为了抗议，抗议的方式是先送九条无畏，再送三十五条航母。低安被打出了一个“大和解”，龙骑团把去年拆家的深水当成了队友，FRT和INIT在同一张战报里朝同一个方向开火。头一轮打完，低安的人只盼帝国再来抗议一回，帝国三天后就真来了。

那一夜人数打平，低安的无畏却比帝国多死了一倍多。低安拉来了INIT，拉来了自家能拉的所有人，也确实做到了一比一堂堂正正站上桌，只是桌上的庄家还是帝国。胶带的标题说敌方严重失误，Bluemelon说兽人破了城，评论区替FC念的台词最省事：“真是没人能治得了蜜蜂了，继续大削帝国！”塔塔拉已经炸完，又有人在问啥时候打埃玛马克的星城了。
:::
