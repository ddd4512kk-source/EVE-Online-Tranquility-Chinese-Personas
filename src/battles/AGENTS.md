# 战役代理约定

适用于本目录及子目录，继承上级指令。共同标准见[仓库统一标准](../../docs/repository-standards.md)。

- 改动本目录任何文件前，先读 `add-battle` 技能，包括素材、快照、计算字段和本指令的修订；流程源为 `.agents/skills/add-battle/SKILL.md`，Claude 用对应副本。
- 收录、战报窗口、实际分方与统计口径按[战役规则](../../docs/rules-battle.md)和[战役模板](../../docs/battle-template.md)；人物归因、文风与素材也在战役规则，成稿按[战役验收](../../docs/battle-review.md)，不套列传的规则和验收。
- 正文按战役规则写成时间线故事，各方人物随事件出场，亮点用 `::: 高潮` 块，不用统计清单代替故事。
- 配置与快照在同名 JSON 的 `battle`、`br`；人工组织归方、主标、名称各按模板维护。抓取只更新快照，不覆盖人工判断；不手改 `br`，不恢复旧格式。
- 分方调整同步统计、人物、军团、正文与素材；渲染必须复用共享统计函数，不在模板或浏览器里重算一套。素材按归档规则保留本场事实和出处，长期规则放专题文档。
- 改分方功能或跨篇查漏用[增量复查](../../docs/review-workflow.md)保存核对结论。
- 验收按战役验收通读；改计算字段或统计逻辑还须跑脚本回归测试。
