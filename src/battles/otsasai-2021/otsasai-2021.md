2021 年 8 月 11 日，欧塔萨塞的一场对撞打得很有账面感：[FRT](https://br.evetools.org/related/30001446/202108111400) 一侧在十来分钟里陆续丢了俄洛巴斯、神使、拉格纳洛克三尊泰坦和两艘冥府，Snuffed Out 一侧则把七十多艘无畏和旗舰后勤舰排上去，被一艘艘打爆。[战报](https://br.evetools.org/related/30001446/202108111400)记下约九千二百七十亿 ISK 的损失，其中 FRT 方三千八百七十亿，对面五千四百亿。谁亏谁赚，要看你怎么给泰坦估价。

当晚的视频作者 sitixiya 把标题直接写成“386b：510b”，算是给这场仗盖了个现成的戳；他本人也在 FRT 一侧开冥府，伤害排到第三，自己人对自己人的功劳簿，翻起来格外顺手。

## FRT 及友军

::: 红料 天空纸条带队，纸条上写的是“打”
[天空纸条](../../p/2115651960/)这天坐在指挥位上，在这场仗里一口气参与了九次击杀。他平时的简介常教人如何散伙，这一天教的是怎样把七百多号人叠成一支能开火的舰队。FRT 一侧声势浩大，指挥一多，号令就杂，能让队伍在泰坦一尊尊倒下时不散，已经比账面上的击杀数更能说明他的分量。大概散伙的学问，只有在不散伙的那天才用得上。
:::

::: 红料 令狐聪开着缪宁，一场仗里挂了一百多个名字
[令狐聪](../../p/624049117/)这天驾驶缪宁，在一场仗里挂名一百二十九次击杀，是整份名单里最勤于出勤的名字之一。别人的账单上写的是损失，他的账单上写的是“到场”。“小蜜蜂”这个外号放在这里很合适：不起眼，嗡嗡嗡地围着，哪个目标都蜇一口，一场仗下来蜇出三位数。
:::

::: 红料 光头的莫洛和叼爷的纳迦法，都是真刀真枪地丢
[光头](../../p/855247117/)在 Nuwa Foundation，开莫洛参与十九次击杀，自己那艘莫洛却也在战报里化成五点六十亿的损失；[叼爷](../../p/1387156123/)在 Fuxi Legion 开纳迦法，同样丢了一艘六点零八十亿的纳迦法，另有几艘惩罚者排着队往下掉。大船小船一并折损，说明他们不是在后排看戏。三万杀的老兵和教程达人，在同一晚学了同一课：EVE 里最贵的永远是最后那艘还没丢的船。
:::

::: 红料 Zero 煌的俄洛巴斯，别人家的神使
[Zero煌](../../p/2113438156/)驾驶俄洛巴斯参与十二次击杀，他所在的 Special law enforcement department 同时丢了一艘价值八百三十三亿的神使。同军团的泰坦一尊上场一尊离场，攒了十年的势力泰坦走到了这个场面，他自己的那一艘却还在。大概播放量输给枪皮的人，在泰坦存亡上还算赢了一次。
:::

::: 红料 橘子的神示、旧人揪心的夜神，华人老字号的合影
[橘子](../../p/2114324589/)在 STARCHASER Inc 开神示，参与三十三次击杀；[旧人揪心](../../p/2115677996/)在 ChuangShi 开夜神，参与三十四次击杀；[慕容](../../p/2114279817/)则以几个号轮流上阵，神使、夜神、重剑一并出场，名片里的联赛冠军这天换了赛制。三个名字凑在一个 FRT 的阵里，等于把华人军团的家底在一张战报里铺开。输赢先放一边，这支队伍里能认出这么多熟面孔，本身就是一种分量。
:::

::: 黑料 三尊泰坦、两艘冥府，三千一百亿的清单
这场仗里 FRT 一侧损失 387.7B，其中泰坦与超旗就占去三千一百亿上下：十四点十四分前后起，先是两艘冥府，随后十四点十八分俄洛巴斯、二十三分神使、二十八分拉格纳洛克接连报销，不到一刻钟，三尊泰坦换了主人。账面上对面那七十几艘神示加起来更多，可泰坦这种东西，丢一尊就足够写进圈子里的茶余饭后。时人谓之：我方主力皆在，惟泰坦易手。
:::

::: 黑料 阙的伊比斯，千亿大仗里最便宜的两行
[阙](../../p/2117312483/)在 Chaos arbiter，和 FRT 同阵营，战报里留下的是两艘伊比斯的损失。队还没出发问题先排满的人，这天连船都没换成像样的；一场旗舰对撞里，他的名字写在最便宜的两行上。大概旗舰战的门槛太高，伊比斯只能在门口跟着凑个热闹。
:::

## Snuff 及友军

::: 红料 神示成排，十六先上去
[十六](../../p/2113841083/)在 Infinity Avenger，换了两个号上场，一个开狂暴舰队型，一个开神示，而且他那艘神示在三十七分被炸成七点一十亿的损失。[ACR](../../p/2115611133/)和 [sayler](../../p/2113271910/) 同在 Infinity Avenger，分别开狂暴舰队型九次和十二次参与击杀。简介先放狠话的人，这天把狠话换成了舰队型号，Snuff 联军摆出的阵势，叫做人多船多，炮口全指向一处。
:::

::: 红料 低调、76，各占一个角落
[低调](../../p/2115988005/)、[76](../../p/2117010442/)分别在 Kuan.Dai.Shan、Fuente Vacio 这些小团里，只在战报上留下了自己的损失记录。爱拍团灭的记者，这次被拍的是自己。小团在大仗里的位置，大概就是替阵势添上几行名字。
:::

::: 黑料 七十艘无畏的清单，七百亿的重量
Snuff 一侧在这场仗里损失 539.8B，共 417 条损失记录，其中七十一艘无畏、六艘旗舰后勤舰、十四艘战列舰，绝大多数是神示，每艘在七十亿上下，Lowlife.、Infinity Avenger、Guardians of Parallel World 的神示排着队被炸。无畏潮一波波叠上去，换回三尊泰坦，账面上看是实打实的亏，圈里看却是个能拿去吹的数字。若说这是一场“以量换质”的买卖，对面大概还得再补一句：成本核算是别人的事。
:::

::: 评
欧塔萨塞这一战的叙事很简单：泰坦是名片，神示是预算。FRT 一边丢三尊泰坦，Snuff 一边丢七十艘神示，两边都在各自的账本上写着“赢”。真要比，还是得回到那句老话：别人的泰坦倒下，响声最大；自己的无畏成排倒下，大概只有会计听得见。
:::
