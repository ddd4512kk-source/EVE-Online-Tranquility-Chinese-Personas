
2023年八月，欧米斯特的旧盟友开始为停靠和生产地翻脸。TD先被深水打散过，剩下的华人管理与墨者重新聚人，准备把日子撑下去；YTDS这边也守着自己的地盘、规矩和一批刚住进来的团。原先能共用的地，到底是谁的地；原先能停的堡，到底凭什么不能停——同一份盟友情分，翻到两边手里，已经成了两份互相指控的账本。

[2GG](../../p/2119781938/)说，是YEET反复关停靠、取消共享，还联络别人来打TD，己方才决定开战；宇宙魔药的一言在[复盘](https://tieba.baidu.com/p/8703265345)里回嘴：明明是TD、墨者先送来宣战，怎么反倒成了我们撕盟约。宣战书里的“拉白”还被直译成“Pull White”，送到对面，先把对方盟主考住了。往日争地靠谈判，这回连谈判失败、准备开火，都得先请人翻译。

8月16日至20日，AXDX-F的铁壁、66-PMM的莱塔卢、撤援道路与46DP-O的接战连成了一轮攻防。战火在几处建筑之间来回转，支援舰队撤回去的路上也没能歇着；这几段已核交火与拆堡，累计损失至少一千二百多亿。战争还打到了各自的回忆录里：一边记下重组、反攻和最后的投降，另一边则从守堡写到熬夜、缺战备，最后把自己的退场解释成休养生息。

## TD、墨者及友军

::: 红料 首都重组，先把人从散场边上喊回来
[老雷](../../p/2119781938/)带着成立才几个月的YSS，赶上了联盟最不适合创业的时候：旧地盘被推，人往外走，管理也有人退场。给新人安排生产、发船、讲前途，本来就已经够忙；现在连承载这些前途的联盟，都得重新拼。TD剩下的华人管理以7L9为首都重新聚人，墨者加入，把已经散开的队伍又拉回了集结频道。

他们抓住的机会，是时区。建筑的增强时间设在国内晚上，对方美洲、欧洲时区的盟友再多，也得先过一遍闹钟这一关。兵力还没有大到可以随时碾过地图，就把必须到场的时刻留在自己最方便上线的时候。对于新团而言，这也是一门战争课：能打的船当然要造，能把活人准时叫来的计时，更得捏在手里。
:::

::: 黑料 打掉无畏，房子还是没拆成
8月17日，TD与墨者带着伊什塔去打AXDX-F铁壁，迎面接上YTDS的渎圣，又撞上小绿人投来的帕拉丁。攻堡的一边把无畏跳进去，要留下对方的掠夺舰；守堡的一边也把旗舰后勤和无畏添上去，先保住来救场的人。网格上的船越来越贵，最初那座铁壁的维修计时却还在走。

结果便很适合两边各写一篇战报：进攻方打掉了两条无畏，守方把堡修好了。老雷在[日记](https://tieba.baidu.com/p/8364932821)里承认，战略目标没有实现，吃了无畏还是“索然无味”。这句比夸战损比实在：无畏的残骸可以拿来发帖，铁壁还立在原地，下一次出门仍得对着它集结。打了半天，最初想办的事还在待办名单上。
:::

第二天，给守方帮忙的小绿人要把帕拉丁队带回去。前一晚打得晚，船留在YTDS铁壁过夜；如今沿路返航，刚好要穿过对手活动的地方。老雷本想休息，发现又有仗可打，便临时组织狙击。支援方付出一轮撤援损失，进攻方也终于把守堡时没吃够的滋味，在路上补了一口。昨日援军救下了堡，今日回家的路便成了对手的加餐。

到了20日，墨者又叫来OSY和源泉猎人，联军的火力队伍一度聚到百余人。46DP-O接上常规舰队交火，YTDS赶来支援小绿人，最终这一侧被打散；联军随后转向AXDX-F，拆掉一座莱塔卢。打回来的地方、叫得来的盟友，都在替这支重组队伍续命。只是领土能靠舰队打，联盟权限还捏在别人手里；这场胜利之后，TD自己的内斗又会把地盘掀一次，老雷也还得带着YSS搬家。

## YTDS、小绿人及友军

::: 红料 大白救人，计时救堡
YTDS想把建筑计时改回美洲时区，新的时间却要等冷却生效，眼前这轮国内晚上的攻防还得有人扛。8月16日，国内玩家十来个人先用小船与建筑火力拖时间；次日真正的出增强，联盟喊了全员集结，人数仍不够，便靠小绿人的帕拉丁来把场子接住。

这一边也没有只让援军替自己挨打。进攻方无畏进场，YTDS把大白跳进来给帕拉丁续命，又上无畏反制。两条无畏最后没回来，铁壁却修好了。账面吃亏，建筑过关，这才是守堡最让报表难受的地方：谁炸得更贵和谁完成目标，有时候偏偏不写在同一栏里。

18日撤援遭伏击，一言记下另一份收获：对方伊什塔依赖岗哨无人机，叉叉便调整渎圣队配置，压低信号半径。19日到66-PMM接战，YTDS抓着援军即将抵达的时机在门上交火，最终与小绿人合军，拆掉TD的莱塔卢。前一天交的学费，第二天拿去改配置；两边都要写自己赢了，至少这一边把改作业的过程也写进了战记。
:::

::: 黑料 全联盟的时区抗，落在一个人的闹钟上
到了20日，叉叉先因连日征战疲惫，没有提前安排护航，勒沙克队被轻拦一路拖住，赶到7L9时，目标铁壁已经修好。晚上本想分头拆目标，再合队接战，情报却没传顺：小绿人先在46DP-O撞上对方暴风队，YTDS放下手里的跳桥赶去救，最终一起受挫。随后丢了AXDX莱塔卢，小绿人重新换出T3巡洋舰，又去拆了5OJ-G2无人防守的TD莱塔卢。一天的忙碌，从错过计时开始，到两边各少一座房子结束。

一言替叉叉解释得很具体：带队是他，运输战备也是他，平时的小仗和非集结时段的压力也都要接。联盟想等计时转到美洲，国内玩家就能休息，真到开会盘点，才发现其他军团有时加起来还没有魔药一家人多。所谓换时区，是把地图上的数字改了；真正干活的人没换，轮休便还是同一群人轮流熬。

魔药决定先离开战场休养，24日退出YTDS。战备尚能再补几轮，人的精神却没有一张补损单就能换新的。把守土计划写成一个月的时区抗很容易，把这一个月每一晚填上活人，才是账本上最贵的一项。
:::

接下来的收场，干脆把战场外的权限也用上了。曹操辞去联盟CEO，接任的Ryo先答应不投降、不贱卖建筑，随后却踢出原来的值守军团、关了停靠，把AXDX-F铁壁作为赔款交给墨者，又打包卖掉大片建筑。老雷宣布YEET投降，旧盟友这边记下的却是接班人把联盟连房子一起处理了。魔药离开休整，后来还会回到南方继续打；这一轮的终点，是旧联盟先没能留住自己的人。

::: 评
开战之前，大家争的是谁先关停靠；打到最后，新盟主用关停靠把旧盟主请出了门。双方在前线烧船，权限在后方换手，宣战时最难翻译的“拉白”，收场时倒不用再解释了。

两本战记都能列出自己打赢的仗，几座堡也各有归属；真正没法只凭战报分清的，是这些人原先凑在一起，究竟打算一起过多久。战损补得回来，盟友情分这一项，没人负责补单。
:::
