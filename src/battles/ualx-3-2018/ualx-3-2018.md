2018 年 7 月，Legacy 在 UALX-3 部署星城，北方与凛冬方面赶来拆台，帝国则来帮 Legacy 守场。[当日战况](https://evenews24.com/2018/07/19/breaking-battle-rages-for-test-alliance-keepstar-ualx-3/)从常规舰一路升级，超旗、泰坦接连进场，星城的开业礼终于办成了旗舰展销会。只是这场展会卖出去的船，不发提货单，直接发击杀邮件。

星城最终被毁，战斗又撞上服务器故障，后面的滞留与脱身成了另一层麻烦。本场已核高值损失样本就超过一万三千亿 ISK；建筑可以拆掉，已经跳进来的超旗，却没法像关店招牌一样说收就收。

## Legacy 与帝国

::: 黑料 无畏往里填，招牌还是没保住
星城还在锚定，正是最适合拆的那一刻：让它正式上线、加好燃料，往后就要一层层磨盾、磨甲、磨船体。Legacy 要保的是往后立足的门面，PL 与东方盟友要抢的则是眼前这一锤子买卖，双方都没法拿“下回再来”轻轻放下。TEST 反复投下无畏，去轰对面的泰坦和支援旗舰，用一批批近身开炮的船换更大的目标。到直播帖的阶段账单里，守方已经交了三百多条无畏，拆出了对面更多泰坦的残骸，自己的星城却也已经炸掉。大船换到了，门面没保住；开业礼最热闹的节目，成了自家无畏排队买单。
:::

::: 红料 建军在另一边
[建军](../../p/96280212/)当时在蜜蜂的 Never Let You Down，开万王宝座参加了这场会战。后来读者熟悉的是他在 FRT 带队、与凛冬人物一同出现在战报里；把日历翻回这一天，他却站在帝国这边，朝另一头的旗舰开火，与后来的同盟隔场相见。这就是欧服老人的共同履历：人还是那个人，频道与蓝加却未必还是原来那套。UALX 留下来的，是他当年真开船来过的签名，后来谁和谁坐一桌，还得往后看。
:::

## 凛冬与北方联军

::: 红料 拆完星城，仗还没打完
PL、凛冬与北方盟友把星城拆了，Legacy 这边的招牌也就没能挂起来。可建筑爆炸没有让旗舰战自动散场，双方仍在继续换船，后续无畏照样往里跳。凛冬自己也付出了代价，当日直播点到了 FRT 的神使被毁；攻方赢了建筑目标，也不是坐在远处看一场免费的烟花。拆星城和保住大船，在这里是两份得分别做完的差事，前一份交了卷，后一份还在炮口底下接着考。
:::

::: 红料 老板也得亲自坐船
[D哥哥](../../p/690534767/)驾驶神使参与交火；[N老板](../../p/1618197191/)的小号 Randolph Yuan 则开使徒上场，并留下了[旗舰损失](https://zkillboard.com/kill/71332828/)。后来大家读到 N老板，常是动员、复盘和联盟讲话；这一夜他也只是那片旗舰海里要把船开进去、还要想办法活着出来的驾驶员。坐在管理席上时能把损失叫作战略投入，轮到自己的使徒变成残骸，那个词就会具体不少。星城拆得掉，后勤也照样得交，老板亲自体验了一次报表里那一列的重量，联盟账本上的支出，也有自己坐过的那条船。
:::

::: 黑料 赢了拆迁，留下等退房
7 月 19 日约 09:00 UTC，节点崩溃，来拆星城的旗舰没能一同撤出去。Legacy 把泡泡铺向对手掉线的位置，守着人重新上线，准备将一场失去建筑的防守战，接成一场不让客人离席的围困。新星城和铁壁又往附近摆，旧店已经拆了，房东却在原地继续营业；攻方的胜利宣言还没凉，登录按钮先成了一道要商量着按的选择题。

围困后来还惊动了 GM。7 月 21 日，[CCP 公开说明](https://www.eveonline.com/news/view/ualx-3-fleet-fights-misfiling-of-stuck-tickets)：有联盟领导号召成员提交“卡住”工单，要求把旗舰挪出 UALX，官方拒绝替大规模交战中的船搬家，并警告组织刷工单可能构成滥用。带跳跃引擎的船得自己找办法走，泰坦也没有客服专用逃生门。星城没活过开业礼，拆它的人却被留下来研究退房手续，这才是 UALX 最拧巴的下半场。
:::

::: 评
一座刚部署的星城，把远方的盟友和仇家全请到了门口。守方没保住招牌，攻方也碰上了退场难题：新伊甸的开业大酬宾，向来是房东、客人和服务器一起买单。
:::
