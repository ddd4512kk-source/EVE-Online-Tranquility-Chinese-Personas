# 前端资源代理约定

适用于本目录及子目录，继承上级指令。共同标准见[仓库统一标准](../../docs/repository-standards.md)，视觉与交互以[网站设计](../../docs/site-design.md)为准。

- JavaScript 用原生 DOM API 渐进增强；复用 `directory-utils.js`、`battle-lists.js` 等既有模块。页面缺少对应元素时可安全退出，不影响其他脚本。
- CSS 两空格缩进，属性与选择器沿用所在组件组织；优先已有变量与类。深浅色变量同步，公共组件统一调整，不用局部硬编码覆盖另一种主题。
- 保留键盘操作、语义按钮和无 JS 可读性；URL 查询参数、筛选与排序行为沿用现有约定。
- 字体切片与战徽由正式脚本生成或获取，不手改二进制和生成样式。站点资源本地提供，外部例外只按设计文档。
- 本目录整体透传到站点；`AGENTS.md`、`CLAUDE.md` 必须在构建配置中排除，其他内部说明不要放在资源目录。
- 按设计文档检查 390px／1366px、深浅色、键盘与控制台；构建后核资源路径及版本参数。改公共 JS 逻辑须做针对行为的验证。
