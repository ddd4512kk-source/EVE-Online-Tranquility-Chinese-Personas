肃正军主团，Absolute Order，简称 ABSOD，2019 年 3 月 18 日立团，隶属 Absolute Honor 联盟，CEO 是 [李将军](../../p/2116026221/)，ESI 里登记近七千个角色，zKillboard 上累计三万五千多次击杀，今年十一月仍有击杀。军团头衔直接写“AO Currently has 27621 Officers/Soldiers”。

## 肃杀的秩序，十分之一的华人

2019 年春，李将军还在用一个叫 Governor Mrlee 的号在斐德替的租地联盟里招人，被吧友追问到底是租地团还是主权团，答的是“目前租地，目标主权”（[帖子](https://tieba.baidu.com/p/6065284894)）。几天后，他的小号 Governor Alt Mrlee 开了一个军团，叫 Absolute Order，这就是后来的肃正军。同年 12 月他建了 Governor Lee，第二天进团当 CEO，一直待到现在。

名字是他自己起的，意思是“肃杀的秩序”；后来为了好记，借了《群星》里那个灭世天灾的名字，管自己叫“肃正军”（[澄清帖](https://tieba.baidu.com/p/7802961479)）。他在澄清帖里特意说明：欧服肃正和国服那边的“肃正协议”没有关系，也没有国服分支，当时九成五是老外。2020 年他对吧友介绍的是：“你可以理解为10%华人管理90%老外”，老外的税收几乎全拿来给华人谋福利。

## 一团分成两种过法

[2020 年夏天的招新帖](https://tieba.baidu.com/p/6778120809)把军团的分工讲得很清楚。Absolute Order 是“第一意志军团”，专管高安 PVE、月矿和燃烧任务，入团三天后发五千万福利，来去自由，永久避战。Absolute Order VI 是“第六毁灭军团”，低安 PVP，堵门加纤维日常小队，语音里十来个人的精英作战队，驻地在奥罗胡嫩一带，和韩国人天天作战，星门口有盟友送的星堡，守着星门的控制权。帖里的口气是军团本身没有出勤要求，PVP 以娱乐为主，没有 00 那些官味。同年 8 月，李将军又单独为第六军团开了一帖[低安海盗团招新](https://tieba.baidu.com/p/6867528759)。

兵力当时已经能看：他在帖里贴的战争公告写着，肃正全军团总人口突破九百，周末极限集结可以上到一百二十人的舰队，月底起把每周一两次的军事行动提到四五次。公告写得像一份战时号令，通篇引的都是肃杀与秩序，七月初要对丹图米星系下灭绝指令，随后是乌呼拉能。

## 越编越多的番号

军团后来一路编号到三十几，联盟也有 Absolute Honor、Absolute Will、Absolute Glory 好几块牌子；Absolute Will 在 2024 年 1 月落了地。[Awakeallnight](../../p/2114626303/) 2021 到 2024 年在 Absolute Order VI，后来转进龙骑，把龙骑和 FRT 打过的会战一场场录下来，配上中文字幕和解说。

2025 年 8 月的 [Y-MPWL](../../battles/y-mpwl-2025/) 大战，肃正在守方出了一百多个角色，Absolute Order XIV 也上了十几个。[TC](../../p/2122236855/) 挂在 Absolute Order XIV 下，24 日的结构计时在守方带队；星城属于 Absolute Order XI。三千七百人挤在一个星系里，时间膨胀压到一成，一句话喊出去要等好几秒才落地，TC 和李将军两个华人 FC 在这样的战场上带着肃正的人往前走。
