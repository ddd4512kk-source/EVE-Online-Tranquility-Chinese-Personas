### 致全世界的克隆飞行员,

随着EVE 20周年典藏版预购上线，我们发现由于各地的运费、关税及其他税费差异很大，导致各新伊甸居民实际支出的费用并不一致。

很遗憾，现实世界中的运费、关税及其他税费并非我们所能够控制的。然而，我们依然想要回馈所有遭遇不公却仍下单支持我们的玩家。于是我们决定，通过赠送伊甸币的方式作出补偿。

对于每一位预购20周年典藏版的玩家，我们将根据其额外支付的金额赠送相应的伊甸币。伊甸币赠送数量如下表所示：

| **用户花费超过$174.99以上** | **获赠伊甸币数量** |
| --- | --- |
| $0.01 - $10.00 | 200 |
| $10.01 - $20.00 | 400 |
| $20.01 - $30.00 | 600 |
| $30.01 - $40.00 | 800 |
| $40.01 - $50.00 | 1000 |
| $50.01 - $60.00 | 1200 |
| $60.01 - $70.00 | 1400 |
| $70.01 - $80.00 | 1600 |
| $80.01 - $90.00 | 1800 |
| $90.01 - $100.00 | 2000 |

值得说明的是，所有新下的订单也将获得这份赠礼。

2023年9月10日预购停止后，玩家将会收到如何兑换伊甸币的通知，伊甸币将在典藏版订单完成后同步发放。

希望这能一定程度上解决大家所关心的问题。另请注意，20周年典藏版的预购截止日期为2023年9月10日，我们无法保证往后还会上架这一纪念版本。为避免发生意外，请确保9月10日前完成[预购](https://limitedrungames.com/products/eve-20-th-anniversary-collectors-edition)。
