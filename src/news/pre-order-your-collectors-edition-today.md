### 忠诚的克隆飞行员，

全新20周年典藏版套盒，即日起在 [Limited Run Games](https://limitedrungames.com/products/eve-20-th-anniversary-collectors-edition) 开放预购，请抓住这一良机，庆祝你与EVE Online社区和辉煌历史结下的奇妙缘分！

套盒限量发售，内含独家实体和数字内容，让EVE宇宙的飞行员有机会永久珍藏新伊甸人民、文化、科技和社区的诚意献礼。机会难得，不容错过，共同见证EVE Online的辉煌历史！

[▶ 视频：Collector's Edition video](https://web.ccpgamescdn.com/aws/eveonline/videos/news/ce/collectors_edition_video_230706_hd_60fps.mp4)

作为EVE 20周年里程碑的庆典贺礼，典藏版套盒对于最忠诚的克隆飞行员而言有着难以估量的价值。内含让人赞叹的8英寸万王宝座级舰船模型、令人无法抗拒的6英寸费多毛绒玩具、艺术家Lloyd George的EVE原创水彩画、收录有未发布曲目的独家新伊甸原声音乐CD（附有数字版本下载序号），再加上一张18” x 24”规格的精美舰船蓝图海报，可谓是诸位死忠克隆飞行员当之无愧的终极收藏。

除了这些之外，还有不容错过的分别印有四大帝国标志和20周年纪念标志的徽章套装，以及一张经CCP开发者签署并且带有编号的防伪证明书。这表示你可能会在自己的证书上面发现CCP Hellmar、CCP Fozzie、CCP Aurora或其他团队成员的签名。套盒还包含各式数字物品，包括龙卷风级和流浪级舰船的两款全新专属涂装、一张变形船体蓝图拷贝、一整组格鲁汀集团核心加强器(CA)植入体四件套，以及五艘理性思维社团舰船。

![](https://images.ctfassets.net/7lhcm73ukv5p/3hfNqSGPSGnCrTDNHtRJbo/b10424b14195d9a2db3554e114f520fe/Banner1080_NoCopy.jpg)

携手收藏品专家 [Limited Run Games](https://limitedrungames.com/) 合力打造，通过套盒中的物品向EVE Online及其玩家社区的光辉历史致敬。抓住机会，彰显作为最伟大社区成员的荣光。
 
20周年典藏版套盒售价174.99美元，现已在 [Limited Run Games](https://limitedrungames.com/products/eve-20-th-anniversary-collectors-edition) 开放预购。 
衷心感谢每一位成就EVE Online的飞行员。我们即将并肩飞向第三个十年 – 也许还会人手一只费多毛绒玩具。
