**网址**：https://ddd4512kk-source.github.io/EVE-Online-Tranquility-Chinese-Personas/

## 这个仓库是做什么的

本仓库是一个**测试 AI 代理（AI Agent）信息收集工作流**的实验项目。

列传的取材、整理与撰写主要由 AI 代理完成：按[取材方法](docs/research-method.md)用中文关键词检索公开网页（贴吧、论坛、搜索引擎快照等），把找到的说法归档进[人物素材库](docs/materials.md)，再按[写作规范](AGENTS.md)写成列传。游戏数据（头像、创号时间、军团联盟）取自 EveWho 与 CCP ESI 的公开接口。

网站本身只是这套工作流的产出，用来检验 AI 代理能否：

- 用中文渠道找到分散在互联网上的社区资料；
- 给每条资料标明出处与可信边界；
- 按统一格式和文风整理成可读的文章。

# Unofficial History of New Eden

A satirical collection of biographies of notable Chinese-speaking players on EVE Online's Tranquility server: roasts, embarrassing histories and sharp-tongued verdicts. The site content is written in Chinese.

**Website**: https://ddd4512kk-source.github.io/EVE-Online-Tranquility-Chinese-Personas/

## What this repository is for

This repository is an **experimental project for testing an AI agent information-gathering workflow**.

Research, curation and writing of the biographies are done mainly by AI agents. Following the [research method](docs/research-method.md), they search public web pages in Chinese (Baidu Tieba, forums, search-engine caches and archives), file what they find in the [materials archive](docs/materials.md), and then write it up according to the [writing guidelines](AGENTS.md). Game data (portraits, character creation dates, corporations and alliances) comes from the public EveWho and CCP ESI APIs.

The website is simply the output of this workflow, used to test whether an AI agent can:

- find community material scattered across the Chinese-language internet;
- record the source and reliability limits of every claim;
- turn it into readable articles with a consistent format and voice.

## Disclaimer

- **Content comes from the internet.** Events, quotes and opinions in the biographies are compiled from public online sources and community hearsay. Most are unverified and reflect only what the original sources say, not the views of the author.
- **The author accepts no responsibility for the content.** The author of this repository makes no guarantee of its truth, accuracy or completeness, and is not liable for any consequence of reading or using it.
- **Folklore, not history.** The tone is deliberately mocking. Please don't take it seriously, and don't use it to make real-world judgements about any player.
- **Corrections and removal.** If you are featured and believe something is wrong or inappropriate, please open an Issue and the maintainer will deal with it.

EVE Online and all related names and images are the property of CCP Games. This project is not affiliated with CCP Games.

## Features

- Biographies sorted by character creation date, with tag filters, full-text search and a random-page button
- Each biography combines 红料 (credits), 黑料 (dirt) and a closing verdict
- Fully static site that works on both phones and desktops
