# 术语用法

列传、战役、军团唯一共用的规则文件，只管用词和专名，不含写作要求。

- [docs/glossary.json](glossary.json) 是术语、释义、确认状态和蓝字匹配配置的唯一来源，网站术语页、正文蓝字与弹窗由它生成。参数与字段用 `npm run glossary -- --help` 查看，不另抄词表。
- **已确认**的词按社区说法写；**待复核**的释义帮读者理解上下文，不强制据此改写正文。档案没有的词先保留原词，或按确有的正文用例补一条带上下文的待复核释义；不直译、机翻或猜造译名，不据此全站替换用语。游戏内专名不适用“保留原词”，按下方专名一条写。
- 新词按对应英文字母顺序插入。同形多义词（F1、T2、KOS、EFT 等）按语境判断，不全局替换；船名兼作人物外号、普通词或组织名时保留具体语境。
- **游戏内专名写中文**：舰船、建筑、星系、星域名在正文、标题和链接文字里一律写中文名，不留英文、不自行音译，也不写“中文（英文）”。舰船沿 [CCP SDE](https://developers.eveonline.com/docs/guides/staticdata/)，必要时补“级”；舰船、建筑用 `npm run glossary -- "词语"` 查；星系查 `src/_data/systemNames.js`，缺名时查 CCP ESI 中文资料补入；星域查 `src/_data/regionNames.js`，站内已有通行叫法的沿用，其余用官方名。00 区字母数字星系名照原名。引用块、引号内原话、书名号内标题、链接地址和素材保留原文。格式迁移不改变译名或确认状态。
- **专名校验**：`npm run names:check` 逐篇查正文和 `epithet`，`check`、`build` 失败即停，并报出行号和中文名。词形相同而实为人名、组织名、版本名的，登记到 `docs/game-name-exceptions.json` 并写明原因，只按文件放过；不为省事把真专名登记成例外。
- 蓝字只标易卡住新读者且语义明确的词。确认状态、舰船类别、是否自动加蓝分别记录，不相互推定；匹配配置只改 JSON，不凭备注措辞猜规则。
