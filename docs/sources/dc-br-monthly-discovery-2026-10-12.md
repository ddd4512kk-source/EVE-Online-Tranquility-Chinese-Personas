## 月榜路径核对：403 不等于榜单限制

本轮核对 PLA 的标准入口 `https://zkillboard.com/corporation/98190062/top/`，网页读取工具同样返回 HTTP 403。此前仅凭 BOP 历史月份路径的一次程序请求失败，把缺口称作“月榜受限”，表述不准确；目前证据只证明这些抓取方式失败，403 的具体原因尚未查明。没有证明军团月榜需要特殊权限或不可正常访问。

已读取 zKillboard 官方仓库的 [`view/overview.php`](https://github.com/zKillboard/zKillboard/blob/936f778b5a92faa8dff37e42bb4b251895aa12e4/view/overview.php#L199) 与 [`classes/Util.php`](https://github.com/zKillboard/zKillboard/blob/936f778b5a92faa8dff37e42bb4b251895aa12e4/classes/Util.php#L277)：`top` 是有效页面类型，未指定年份和月份时使用当前年、月；URI 解析支持显式 `year`、`month`。因此 `/corporation/<ID>/top/` 是本月榜入口，`/corporation/<ID>/top/year/2026/month/9/` 是九月榜入口。网页月榜路径与 `api/stats` 的参数能力应分别判断，不能由 API 文档没列月份参数推断网页路径无效。

后续从标准 `/top/` 入口读本月角色榜，再按需要指定历史月份；榜单数据未取得这一缺口仍保留，但不称作军团月榜功能有限制，也不把本地 30 分钟冷却说成网站自身的限制。
