# 玉麒麟首号处分：浪骨与小十亿

来源：玉麒麟《玉宣〔2024〕1号》处罚通告，2024年3月5日，外宣部、人事部、执行委员会落款；与[《ICG旗下华人军团先击毙后踢团》](https://tieba.baidu.com/p/8924360773)中的通告风波同一事。完整通告补齐了旧帖残图缺失的身份和具体指控。

## 两人的处分

- **浪骨**：前朱雀成员；通告直接将zhang Askiras、LangGu FS、LangGu 3、LangGu 4、LangGu SF列为本人角色。指控多次向其他军团成员泄露朱雀重要信息，具体包括“友军位置及作战部署情况”；另有“不遵守朱雀收购相关规章制度”，没有说明是哪次收购、怎样违规。
- **小十亿**：前玄武成员，角色Xiao Shi YiVI；指控多次向其他军团成员泄露玄武、朱雀内部重要信息。没有给他列收购违规，也没有逐项说明泄露内容，不能挪用浪骨的细节。
- 通告说外交部审查并多次提醒后，两人仍未改正，3月5日又把零安信息发到高安相关群组“大规模传播”，经联盟内部反复决议，分别开除出原军团。

## 当时语境

朱雀刚在零安站稳脚跟，尚未公开招募，只从玄武内部小范围引导，成员须考核；技能、装配与后勤方案仍在建设。通告强调成员间的信任，称不能容忍“今日把酒言欢明日背后捅刀”，态度为“零容忍”，希望这份独立后的首号正式处罚通告也是最后一份。

这是处分方的具体指控和处理决定，未附实际泄密记录、调查材料或本人答辩。不推断收钱卖情报、造成多少损失，也不将法尔在贴吧的“肃正管理所以是spy”替代为通告给出的泄密理由。
