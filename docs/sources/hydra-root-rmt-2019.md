## 结论与游戏身份

这组材料足以将Hydra Root涉及RMT作为本帖的明确事件归档，不能继续停留在“仅标题涉及指控、未取得正文”的旧判断。理由是卖方连续谈价、收款及交货安排，主动发送游戏角色和入团入口，截图中的军团属性又直接列出同一角色为CEO；随后出现RR管理的清退回应及游戏系统退盟通知。它不只是异常行为或旁观者扣帽子。

- 第10楼聊天中的卖方发送`Emmadag Saraki`角色卡，并说“你加这个团就行了”。第10楼名片的群昵称为`HydraRoot-Emmadag/歌不好…`，与同一聊天账号、角色卡衔接；不保存私人账号号码、收款码等现实联系资料。
- 第11楼角色卡为`Emmadag Saraki`，头衔“歌不好听，总监”，军团Hydra Root，ticker `H.R.O`，联盟Ranger Regiment。军团属性图明确列CEO `Emmadag Saraki`、创建者`Hydra Tawate`、27个角色、税率100%；图中游戏日期2019-10-23，时钟01:52，不能把27个角色换算成27名独立玩家。
- 角色名已由ESI解析为`2114915480`，Hydra Root军团ID为`98594668`。CEO归属来自事发时原图，不由现任资料倒推；创建者不因名列属性图被认定参与交易，也不直接判为CEO小号。
- 服务器由原帖吧名、RR组织归属、游戏截图及宁静服ESI角色解析相互对应；不是仅凭同名军团认服。

## 交易截图中的直接内容

截图显示聊天日期为2019-06-16、06-18、06-20。日期沿用图中显示，不伪造时区和UTC时刻。

- 第2—4楼：卖方说直接挂物资合同，再用其他号收回物资；提出制造商可以买矿，或从军团内部机库拿货，自称有自己的军团。买方问安全性，卖方称这种方式安全、小批量不会被封。
- 第3楼举例：一件估值50亿ISK的物品，用30亿挂私人合同给买方，买方再用50亿卖给卖方小号，然后卖方从小号取回，再挂30亿合同。卖方把循环解释成将游戏币交给买方的办法；不是军团正常福利的孤立一句话。
- 第5楼：出现收款码，买方问多少钱，卖方答“原价100你这个4个抗一亿算3块，一共收你97”，买方回“好饿”“下回再合作”，卖方答“好的，合作愉快”。这是明确的现实货币报价与收款安排；图中没有独立的支付成功凭证，不把该报价擅自换算成全帖交易总额。
- 第7楼：卖方称用同步器能多开出门打架，买方追问会不会被封，卖方答“很难被封”，并说朋友在FR租地团长期挂机、也被封过。这能归到卖方本人的同步器谈话，不能凭其转述给另一个租地团定性。
- 第8—10楼：买方问50B怎么交付，卖方直说直接给ISK会封号，先提转移资产或账号，再改谈物资合同差价，并让买方小号加入自己的军团。卖方发送Emmadag Saraki角色卡作为入团指引。这里是50B／500亿ISK交付的谈判，未展示对应完整完成记录，不与首楼300亿没收额相加。
- 第10楼另图：卖方声称其他制造商在军团里收矿造东西，并谈AOM发展、矿工和超旗需求。这是卖方对其他组织的泛泛说法，没有对方身份、交易或管理发言，不能据此把Hydra Root证据扩成AOM全盟RMT结论。

## 举报、处置与未公开的记录

首楼说举报者先因百税、抢异常、私聊不答及半夜连串刷怪船损失而盯上该团，随后朋友交来购买游戏币的证据；其朋友主动联系GM，300亿ISK被没收。异常行为只是调查起点，不能用来单独证明脚本。

第1楼附图是英文GM片段，要求提交参与现实货币交易的角色名、收到的ISK总量、交易网站或交易发生地点、游戏内如何接触卖方及交易过程。**图本身没有写没收300亿、卖方处罚期限或具体封号原因**；300亿来自首楼叙述，不冒充处罚原件已经逐项确认。第6楼后续回复中，楼主又说GM于10月25日答复已处理相关材料，仍是楼主转述，不等同完整处罚信。

第18楼台风（UID42065891，原名夺米台风）贴图并回复“踢了”。附图是CONCORD系统邮件，题为`War update: Hydra Root has left Ranger Regiment`，发送时间`2019.10.23 12:55`（游戏时间UTC），确认该团已经离开RR。系统邮件证实离盟；踢除的执行性质由台风同楼回应补足。第29楼台风又答：“有，你满意了？发现了我处理掉了。还不依不饶？”因此本事件也保留其当时处理脚本／RMT举报的行为，不写成RR完全没有反应。

第45楼楼中楼，楼主说台风一方查过SEAT，确认是RMT和脚本团；自己还持有转账记录及买方从军团机库拿货的截图，因为怕暴露朋友角色而未发。**未公开的这两组记录不列作本次亲眼核过的图证**。可以据公开交易聊天、身份衔接和清退结果明确写Hydra Root涉及RMT，不能把未见的转账流水或处罚信补写出来。
