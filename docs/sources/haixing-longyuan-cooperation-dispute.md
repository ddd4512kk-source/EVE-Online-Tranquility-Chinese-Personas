# 海星与龙渊：合作开工与退款争议

## 事件与对应

来源为社交媒体上10月7日晚的公开争执及FUXI-HY／Gary CHGS所发事件总结；年份未显示，不以文件取得日期补成事件年份。内容明确涉及EVE欧服，双方使用的社区称呼为海星、龙渊；龙渊的交易广告涉及超导、DED LP与三神T2船，社区账户另见longyuan1的写法。海星已以 WXSS5／2124337800 收录，WXSS及WXSS2—WXSS8共8号归为同人；龙渊的游戏角色仍待对应，不能仅凭中文外号与BOP同名“龙渊”双号合并。海星与龙渊均非resoap／rewrite JOE，作为独立事件保留；海星已立传，角色依据与代售游戏币增量见[本人素材](../../src/people/haixing/materials-haixing.md)。

## 海星的账号使用与赚钱打算

关于海星平时的游戏经历，社区说法是他没有自己的账号，一直借朋友的号玩。后来他想在EVE靠RMT赚钱，主动联系别人，打算租服务器挂脚本，再把产出的游戏币卖掉。合作不顺后，他又自称被骗，公开催工、追款。租服务器、挂脚本、卖金属于其赚钱计划，不由此推定项目已成功开工、已有卖金收入或形成何种规模。

借号经历与脚本合作是两个层次：不能把朋友借给他玩的号直接认作他本人的主小号，也不能推断这些朋友或账号参与了后来的脚本／RMT项目。现有总结所称“海星的账号被封”，只保留为来源方对处罚的说法，不据此反推他拥有被封账号，也不替他确认究竟封了谁的号。

## 海星的指控

海星连续点名交易广告账户，称对方以合伙开脚本的名义收钱，却到开工时联系不上，“电话不接消息不回了”。他在贴出的私聊里说租机器没看到号、对方说已经全提起来也看不到，自己付过租机款；称拖了近两个月，要求退3137.87元，并威胁报警。他说转账截图和聊天记录仍在，又说已有其他人向他反映受害；这些是其单方指控，不据此认定现实诈骗、案件成立或存在可独立核实的其他受害交易。

旁人nice舵主回忆对方以前号称刷三神材料一小时几十亿，接着讥讽吹了这么多年才弄到三千。这个数字是围观者概括，不替代3137.87元的索赔说法；“一小时几十亿”也只是他人转述的宣传，不作已核收入。

## 龙渊的回应与反指控

龙渊随后现身，先反问海星是不是“rmt头头”，展示与另一账号的私聊，追问海星是否联系对方、要求解释相关爆料。海星追问钱退了没有，龙渊又贴出双方私聊：可见2629元转账被退回，以及对方道歉称“都是我的问题”“你也不用崩”；紧接着另一个2629元转账显示已收款。截取上下文不足以确定每笔款项的完整用途、起止与退款总额，不把它当3137.87元索赔已经全部结清。

同段私聊里一方还索要脚本，说等自己打几个月工攒钱后想自己试；这支持争执确实涉及脚本合作，而非只有双方互相扣帽子。龙渊在争执中喊“rmt认准这个dc的就行了”，海星回“说的好像你不rmt一样”“你开脚本喷我rmt”，又以“大哥说二哥”讥讽。最后龙渊嘲笑对方定位不了自己的号，海星回自己根本没上EVE。双方互控照录为来源方说法，不推定实际举报、CCP处罚或后台账号定位结果。

## 旁人总结，不能冒充当事人原话

Gary CHGS的总结把事情描述为欧服RMT／脚本合作翻车：海星出资金及服务器费，龙渊负责操作，男大负责技术／远控；远控不到位、开工拖延，海星等了10天后认为被忽悠，继而公开争执并威胁向CCP举报。总结还称海星账号被封、向设备商索赔，龙渊解释男大失联、自己也没拿到远控，海星则骂对方只会RMT不干活。

其中“等10天”与海星私聊的“拖近两个月”口径不同，可能指不同阶段，但现有材料未展开，分别保留。封号、设备商索赔、向CCP举报及男大分工目前来自这份总结，原长对话未逐项展示直接依据，不写成CCP官方认定。设备商名称、个人账号号码、现实姓名与照片均不留存；现实违法定性不进入列传。
