## 样本边界

zKillboard API 以星系、年月取样，再筛选上述日期。B-R、UALX、X47、M2、A1、黑色星期五与 Atioth 取单条损失 ≥50B；Lantorn、Siseide 取 ≥5B。已翻到的第二页与第一页去重合并。Obe 使用 WarBeacon 保存的公开列表。抽样不能当作完整战报，也不能据此统计各方全体成员或全场个人功劳。个人材料保存角色 ID、船型、时间、KM 和当时联盟 ID；联盟 ID 是战时记录，不随当前归属改写。

驾驶 Monitor 的战场记录用于“参与指挥”；不指定全场总指挥或某舰队主 FC。未知船型、仅胶囊的攻击者只写在场名单，不补造驾驶旗舰。卡戎在 Obe 仅见战后新手船损失，本轮不据此增加大战段落。

API 参考：[zKillboard API](https://zkillboard.com/api/docs/)。部分旧 br.evetools.org 链接读取失败，未把失败记为零结果。B 站本轮遇到 412，视频正文及评论未读取成功。
