# 军团验收

只管军团页，落实[军团规则](rules-corp.md)与[军团志模板](corp-template.md)。列传、战役的验收都不适用。

先跑 `npm run corps -- audit` 与 `npm run corps:check`，本团不能再有问题；再通读 `_site/corps/<短名>/index.html` 和 `/corps/` 目录，逐项核对：

- **门槛**：招新帖、现任列传人物、活跃三条至少占一条。
- **浮夸商业风**：口吻高调、商业感强、理直气壮地自吹自擂，像集团招商路演与宣传册，绝不是干瘪程序员式的资料罗列；所有吹嘘的事迹与数字都有线索支撑，没有凭空编造事实。
- **绝口不提丑事**：没有料块、朱批、讥讽和阴阳怪气，没有转述列传里的黑历史；负面浓度只由公司卡上的“含神量”横条呈现反差。
- **这家自己的牌面**：`##` 标题高调且写这家的事，不用通用词；换一家军团名就能套用的空洞套话要重写。
- **不是名单**：没有“甲哪年进团、乙哪年进团”的履历流水账。点到谁，就吹他给集团立了什么功，并链到列传。
- **长度随材料**：材料少就写成精悍响亮的品牌宣传页；材料多的铺陈到位，列传和素材里这家的事没有漏。
- **招新**：核对军团简介、招新帖近期回复及 B 站 EVE 视频简介／回复中的群号归属；一年内发布或有人回复的招新帖即算正在招新，不要求另有 QQ 群号。`recruitment.last_seen` 记最近可核实的招新活动日期，`source` 链到原帖或视频，`qq` 只记核实归属的招新群号。引用的福利和自述链到原帖。
- **档案与评级**：`cn_name`、商业口号式 `epithet`、视觉风格 `style`（六选一）及三项 0–100 整数评级 `ratings`（`pvp` 武德［快照按最近排名换算］、`shenren` 含神量、`influence` 声望）已填妥，其中 `shenren` 严格只计现任成员并按列传“神人”高标准打分（前成员不计、常规争议不虚高）；素材含军团简介原文和线索出处，名称表已标 `chinese: true`。
- **边界与专名**：没有现实隐私、歧视内容和未成年人；舰船、建筑、星系、星域名按[术语用法](terminology.md)写中文。
