# RR早期军团人物与未对应角色

来源：[《RR游骑兵简史》](https://tieba.baidu.com/p/5688249663)#96、#98、#103附图，2018年台风的亲历回忆。图中军团资料日期2018-05-11，不当当前规模/CEO快照。

- **紫瞳（粉红鱼雷）**：国服与台风不同阵营，曾在贴吧争吵；欧服由种马邀请，双方合作。负责Pink Torpedo Inc.（98537522）的旗舰制造，从缺蓝图/资金到几个月后搭成生产线、接受订单，再与九帮十八会合并成SARD。已有具体工业故事；对应号后可立短篇，不需另等第二来源。旧DOTLAN截图CEO空白。2026-10-11 ESI创建者Super Ad（2113374545），当前CEO M ameng（2112688950，title“烟花”）；两者都尚无“紫瞳”的对应链，不将烟花直接写成紫瞳。网页精确“EVE 紫瞳 鱼雷”未有可靠名字命中。
- **七秒**：星华指挥，台风称擅长剧本与小队战，从其身上学到很多；当时FR46成员操作未达要求，多次剧本失败，七秒后AFK，作者又说明与现实忙碌有关，不写成已经被气退的确定动机。[台风2017视频索引](https://forums.winterco.org/t/topic/14278)直接列《七秒精英小队作战视频》av16264425，是同人的游戏经历线索，原视频尚未观看，无角色名。网页精确查询命中这个原作者索引，其余无可靠角色对应。
- **慕利亚诺兰（神韵）**：台风在#103点名神韵CEO；神韵开快递遇两次高安损失，一度停止后恢复。未有具体KM/号，不能将损失推为故意坑成员，也不由现CEO名单回填2018任职。网页中文名检索无可靠EVE命中。

已对应的嗜血（2113483277）使用#96旧CEO截图入素材。BOP、QV在同段被提到的发展选择没有具体主事者事件，不硬归现有军团成员。所有现实地域、联系方式与个人资料均不留存。
