# 陌然回忆录中的低安人物

来源：[《一个无名小卒的回忆录》](https://tieba.baidu.com/p/8738371316)，陌然第一人称回忆。当前可见226主楼、119楼中楼文字通读，附图待核，缺失内容不补造。已对应的陌然、梦雨、胡汉三材料归各人物目录；华义征服者损失见[fuyue.md](fuyue.md)。

- **刀哥 / woaidao**：#159明说游戏名woaidao，与Fel一起带陌然打高宣、堵门；#165提出伏击黑旗并用针对ECM毒蝎压制敌恶狼，回忆者称对面损失20+B、己方一恶狼。这是团队战果，不把全部击杀算刀哥独得。搜索命中[2025年7月1日woaidao 2的吉他KM](https://zkillboard.com/kill/128261977/)，2026年10月另有阿巴宗活动；角色查询得到woaidao 2（2119125805）。名字与活动吻合，ESI历史补查显示2022年已在Late night poets，符合回忆录时期，已收录[刀哥](../../src/people/woaidao-2/materials-woaidao-2.md)。
- **Fel / 费力**：#159擅长三审判深渊、多开恶狼及无畏，曾参加AT训练为团友回忆；#165六恶狼参与黑旗伏击；#179、#183与陌然和咫尺合作制造天使泰坦蓝图；#207无远克，从吉他跑穿梭机赶回上无畏。尚无游戏角色全名，不因Fel词根直接并到Felony Men。
- **咫尺**：#179、#183蓝图合作三人之一，负责制造计算与双掠夺击杀工业，误炸Fel强运后被警察击杀小克；护送蓝图驾驶救世。具体号待对应。
- **扎枪**：#199自述者记其曾在BOP带暴风队，团里传闻搓好船才起队；2023被炽天招进LN1P，后与式姐组公开队对战Y老板，暂无该战详情；#243随陌然新建BGNM。不能把“FC从入门到入土”标题当已讲出的翻车事件。
- **卡卡 / 卡急**：#205老管理与内容发动者，急于找战斗为陌然评价；#210在Lowkey Ops对抗中冥府反复回场，最终被15+泽尼塔与前场无畏击毁。现有具体超旗损失足够短篇，一旦对上号即收录，原KM与号待查，不要求第二来源。
- **黑瓶子**：#32浮岳新人FC带截击弯刀几次，因老成员期望高压力大弃任，具体角色待对应。
- **风哥哥、老狗蓝风**：#6风哥哥救新人并追击复仇；#76把冷月和老狗蓝风并列活跃骨干，#93又并列风哥哥和老狗。因此不能仅凭“风”把风哥哥归蓝风或随风，两人关系待查。
- **DQ、洋、魔心、非鱼、葛温**：#58—#59合住5-3洞；DQ是欧服星月总监之一，自报处理工业资产促成与梦雨交易；洋无畏停无油POS被开走，DQ不带钢板刷五级洞、换装出错损失，仅为回忆者说法；暂无具体游戏角色，不扩大为现实身份。
- **式姐**：#135安利片麻挖矿、#179尝试海盗叛乱第一天遭blob，未给损失；有PVP/深渊/挖坟身份讨论，不因性别外号判角色。
