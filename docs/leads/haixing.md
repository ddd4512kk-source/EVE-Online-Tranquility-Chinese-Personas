# 海星：脚本合作翻车与互揭RMT

欧服社区人物，独立于resoap／rewrite JOE，也不是对话中的龙渊。游戏角色尚未对上；现有来源中的“海星”为社区显示名，不能直接拿同名角色认人。龙渊在争执中称海星是“dc的”，可作历史阵营查找入口，不直接当作当前军团／联盟。

## 已有故事

海星平时没有自己的账号，借朋友的号玩；后来想靠RMT赚钱，主动找人合作，打算租服务器挂脚本、卖游戏币，合作不顺后又自称被骗。借号背景、赚钱计划、公开催工与退款争议，以及龙渊反指其RMT、双方互相揭短的说法，统一归[共同素材](../sources/haixing-longyuan-cooperation-dispute.md)。

这是一件具体合作争议，对上可收录角色后足以立传，不必再靠KB补门槛。写作主线围绕“平时借号当玩家，想挣钱时便筹划租服务器当老板；卖金的生意还在催开工，追款的架已经吵起来”展开。借号到筹划脚本卖金，是人物的处境与动机；合作不顺后自称被骗，再被对方反揭RMT，是冲突与反差。保留其主动参与和逐利打算，不写成无端卷入的单纯受害者；“被骗”写成海星自己的说法，不定性现实诈骗。项目成功开工、卖金收入及封号详情不补造，数字和爆料人名字留在共同素材，正文以人物故事展开。
