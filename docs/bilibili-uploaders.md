# B站UP检索名单

欧服（宁静服）相关 B站 UP 的唯一总表。B站风控按 IP 计，逐人搜索会触发 412，所以人物的 B站 线索一律先查本表，不再按人名、外号或角色名搜 B站。

## 用法

- **新收录或修订人物**：在本表和人物素材里查外号、角色名、头衔、UP名与UID。命中就复用已登记UID／BV，按[取材手册](research-method.md#4-b-站与贴吧同等重要)先核空间最新发布／最多播放与合集，再读候选作品；未命中就在本人素材写“B站：名单无对应，待板块扫描”，继续其他入口。
- **已知确切UP名、只缺UID**：直接用B站用户搜索查这一个名字，一次即可，不算逐人搜索；外号、角色名这类猜测性名字仍不搜。
- **本人主动给出的链接照常读**：角色简介、本人贴吧帖或其他已对应账号里贴出的 B站 主页／视频／短链，是确定入口，可以直接读；读后把UID补进本表。
- **新增UP只从批量扫描来**：按下文“扫描队列”汇总 EVE 欧服话题下的 UP，按UID去重后登记，再反查人物。一个UID一行，同一人多个账号分行写。
- **多账号逐个核**：同一人物名下已对应的个人号、节目号均按取材手册查空间；跨账号作品合并去重，总共最多精选5个。候选表中仅有出镜／点名关联的账号不自动归本人。
- **状态变化就改行**：候选确认后移入“已对应”；同名无关的移入“已排除”，留排除依据，避免下次重查。人物素材只记与本人有关的增量，本表只记账号对应。
