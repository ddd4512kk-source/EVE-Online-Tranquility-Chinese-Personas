# 列传六维品评

雷达图是独立的趣味展示组件，用战斗力、统御力、魅力、政治力、财力、神力六维勾勒人物反差。分数是编辑印象，不是能力测量或历史考证：根据已有故事大胆评价，不为评分编造新事件，不另开历史调查或联网核证。

## 组件边界

- 只通过稳定人物 ID 关联；评分数据和维度配置独立维护，不写入主列传正文、身份或游戏快照。评分高低不决定列传质量或收录资格；新收录的交付要求见下节。
- 组件可独立添加、修改或移除。调分、增减维度、换样式、隐藏或删除组件都不影响主列传，不触发 `combat`、`writing-depth`、正文补写、历史回查或列传评审子代理。
- 只验组件本身；样例先交付可见效果。成本与停止边界见[开发与验证](development.md#展示组件与样例的执行边界)。
- 现有试作把数据放在人物档案的 `person.radar`，由 `scripts/person-radar.mjs` 校验。这是待拆分的旧实现，不是正式架构；不能因此把组件修改送入列传复审，修改本文件也不附带实施迁移。

## 新收录完成要求

- 新收录人物必须完成六维品评后才能报告创建完成：六个维度、逐维理由、已评维度的出处、史官评语与核读时间均须符合下文规则；不得省略整个评分字段。
- 确实无从判断的维度按“待考”规则填写，不为补齐面板编造经历，也不得用六维全待考代替逐维判断。
- 正文复审与组件校验分别通过；`combat`、`writing-depth` 通过不能代替六维完成，六维通过也不能代替正文复审。
- 既有人物缺评分时保留页面，按后续任务补齐；通用读取器和页面渲染继续兼容缺省，不把“能生成页面”当作新收录完成的依据。独立调分、隐藏或移除组件仍按组件边界验收，不触发正文复审。

## 评分流程

1. **核对既有标记的底线**（首次设分或重核任一维度都要做）：用 `personCombat(identity, birthday)`（`scripts/activity.mjs`）按主号与全部已确认小号核算战神标准，并查 `src/_data/tycoonPeople.js` 的大亨名单。有战神 → 战斗力至少 A；在大亨名单 → 财力至少 A。页面徽记、旧理由或印象不能替代快照与名单；两者冲突时先核身份归并、快照时间和标记依据，再改评分，不得保留低于底线的档位。
2. **逐维定档**：按下文“各维规则”先套硬底线，再按天梯锚点和加分项定档。六维独立评，能合理推断就给档。
3. **横向校准**：先和同一维度上的相近人物比，再看六边形整体（见“横向校准”）。
4. **写理由与评语**：每维一句理由，史官评语一句。
5. **校验**：只跑组件相关的定向校验与页面核读。

## 数据字段

```json
{
  "version": 1,
  "reviewedAt": "2026-01-01T00:00:00Z",
  "verdict": "≤60 字史官评语",
  "axes": {
    "shenren":  { "tier": "B", "reason": "≤240 字理由", "sources": [{ "label": "出处名", "url": "https://…" }] },
    "combat":   { "tier": "A", "reason": "…", "sources": [ … ] },
    "command":  { "tier": "D", "reason": "…", "sources": [ … ] },
    "charisma": { "tier": "C", "reason": "…", "sources": [ … ] },
    "politics": { "tier": null, "reason": "待考原因", "sources": [] },
    "wealth":   { "tier": "B", "reason": "…", "sources": [ … ] }
  }
}
```

- `tier` 取 `EX / S / A / B / C / D / E` 或 `null`（显示“待考”）。六个键都必须出现，待考也要写 `tier: null` 和原因。
- 已评维度至少附一个公开 HTTPS 出处，复用正文、材料里的现成链接即可；链接只供读者延伸阅读，不是分数的证明，不要求逐项举证或追加归档。
- `reviewedAt` 是编辑核读时间（UTC，精确到秒，`Z` 结尾），不是事件或数据抓取时间。
- `verdict` 一句话点出最鲜明的反差，可以戏谑；不新增事件，不做人身攻击或现实心理诊断。
- 既有未评人物可省略整个字段，页面不显示空面板；新收录不得以此作为完成状态。

## 通用尺度

- **七档天梯**：E 垫底或白板，D 常人基准，C 熟练或骨干，B 资深／主官／CEO，A 卓越／核心主力／高层，S 全服顶尖，EX 顶尖中仍压倒性的极少数。除各维明确列出的硬底线外，档位是比较锚点，不按击杀量、ISK、人数或帖子数设一刀切阈值；同类事实必须用同一尺度。
- **六维独立**：不求平均、不要求有高有低；不算综合分、面积分、榜单或排名；神力不抵消战斗与组织表现。
- **按生涯评**：依据已核读的生涯事迹，不声称代表当前游戏状态，不用一次巅峰覆盖全部经历；理由写清用的是哪件事、哪个时期。
- **同一自然人才合并**：已确认小号的经历计入本人；售号、代管后新持有人的战果不计给原主人。区分本人实际参与、履职，与仅持有资产、挂名或被动卷入。
- **失败不扣分**：被踢团、被污蔑、被盗号、迁徙失败或大战失利，都不自动降低任何能力分。
- **待考**：只有确实无从判断才用 `null`，尽量形成闭合六边形；不为补齐图形编造经历。**统御力不用待考**。
- **理由**：至少点出一个实际加分或基准依据；高一档说清强在哪，低一档说清差在哪。好懂、有趣即可，不写审计报告。

## 各维规则

每维按“硬底线 → 天梯锚点 → 加分 → 不算”的顺序读。硬底线是最低档，不是上限；加分多少看强度、持续性和同档人物表现，不机械相加。

### 战斗力

看已证实的战斗能力与潜力：多开、舰型、击杀、单杀及实战经历。

- **硬底线**：有战神标记 → 至少 A。AT 实际上场选手 → 至少 A，不论胜场、名次、KB 或 solo 比例；仅报名或列入名单未上场不适用。
- **天梯**：E 已知实战能力明显薄弱或确无战斗经验｜D 普通随队作战｜C 熟练战斗职责、有稳定实战积累｜B 在多开、旗舰实战或击杀／单杀上表现突出的资深战斗员｜A 一项显著强项或多项优势支撑的精锐｜S 全服顶尖的多开、旗舰战斗员或单杀高手｜EX 顶尖中仍有压倒性表现的极少数标杆。
- **加分**（并列路径，满足任一即可，不要求全部）：
  - 经常多开战斗，按规模与频率加分。本人多个已确认小号 KB 都很高，即可推断经常多开，不必另找同时操作的证明；主号和小号的战斗积累一起看。
  - 经常驾驶旗舰、超级航母乃至泰坦参战，经历本身即加分，不要求单杀或亲手决定战局。
  - KB 击杀数高加分，solo 数量或比例高也加分。不因随队抹掉高击杀，也不因总数少于大舰队玩家就低估单杀高手；少量击杀造成的高比例不能与大量单杀下的高比例等量齐观。
- **不算**：仅有旗舰库存或停站展示；零击杀、办公室身份或单次战损不能单独证明战斗力低。现成数据不足时在理由里说明判断范围，不为评分新增调查。

### 统御力

看 zKB FC 资质与标注、Monitor 记录的大战参与、带队履历与实际指挥地位。

- **硬底线**：
  - 本人或已确认小号有 zKB FC（medium 或 high）标注，或有稳定实战带队履历 → 至少 B（缺 FC 标注但有明确骨干指挥经历同样有效）。
  - 有 zKB FC (low) 资质，已说明具备高于常人的指挥表现与出勤协同积累 → 至少 C。
  - 上述都没有 → 评 D，按普通随队队员处理，不用待考。
  - 评 S 或 EX 必须有可靠的大量大战指挥记录（本人长年驾驶 Monitor 且多场本站大战匹配，或战报、媒体明确记载为主力舰队指挥），并符合 `著名FC` 标准；做不到的最高 A。
- **天梯**：E 行动反复极度失序或完全没有舰队协同经验｜D 普通随队协同｜C 小队带队、教官、部门协调，或有 zKB FC (low) 资质｜B 有 FC (medium/high) 标注或稳定带队履历的指挥骨干｜A 多次大战支撑的联盟重要 FC、成建制大舰队主力指挥｜S 长期统领主要战区或联盟主力舰队的顶级 FC｜EX 长期统筹全服级大战、数千人联军的总指挥标杆。
- **加分**：大战参与多是经验加分，与 FC 标注或重要指挥身份结合时支持更高档。
- **不算**：普通参战者的参战数不当指挥场次，整场联军成绩不归给每个参与者；军团法人、联盟／军团 CEO 身份、成员规模与动员能力、内务、建筑与月矿管理不算舰队指挥。已有 FC 或带队事实时不能写“未见指挥”压低；材料没写不等于无经验，一次失败不抹掉长期带队能力。

### 魅力

看吸引关注、获得喜爱与支持、使人追随的能力，B 站与贴吧人气都算。

- **天梯**：E 见下方专门门槛｜D 正常社交、熟人好友圈｜C 军团骨干，有稳定粉丝与拥趸｜B 跨团队号召力，B 站／贴吧人气显著，圈内著名作者、活宝或领袖｜A 大型稳定受众、跨圈人气或跨联盟号召力｜S 跨阵营乃至全服级精神图腾｜EX 享誉新伊甸的千古偶像。
- **加分**：B 站粉丝、播放、互动与长期观众；贴吧帖子热度、回复互动、熟识度与稳定拥趸。做成 B 站大 UP 或贴吧长期高人气，魅力不应低，按受众规模、持续时间和跨圈影响定档；不要求先证明能动员舰队或担任领袖。
- **E 门槛**：必须有列传或素材里的具体事件——被团员、老东家或联盟公开声讨，被联名驱赶，坑骗同胞后失去团内支持，被吧友长期当反面典型而无人替他说话，或材料明说长期没人愿意同队。同一人另有真实粉丝与拥趸的不评 E。
- **不算**：单纯吵架、被骂、独行、不爱社交、没人气都不是 E，没有事件只能评 D 或待考。一次性争议围观不等于长期人气，纯骂声不等于拥戴；有争议、会骂人也不抹掉真实粉丝。人品好坏、恐惧与岗位服从不代替魅力。

### 政治力

看职位、任期、组织规模、治理外交与权力博弈成果。职位可以换算为政治能力，任期越长支撑越强，不要求另找一场公开外交胜利。

- **硬底线**：实际履职的军团 CEO、核心总监 → 至少 B；长期在职的大型军团 CEO 或总监 → 基准 A；实际履职的联盟管理、外交与执政核心（尤其非 FC 类长期管理）→ 至少 A。不能因为不打仗、不是 FC 或少有公开发言就评成散人的 D。
- **天梯**：E 本人协调与决策反复造成基层体系瓦解｜D 专注自身事务，不涉组织管理｜C 基层管理，协调内部与局部纠纷｜B 实际履职的 CEO、核心总监｜A 长期大型军团 CEO／总监，或联盟管理与外交核心｜S 长期掌控顶级联盟或重要派系｜EX 长期塑造全服政治格局，留下决定性权力重组成果。
- **加分**：按联盟规模、任期、权力与成果上调。宫斗获胜（夺权、排除对手、保住领导地位、建立稳定派系）明确加分，具体档位仍结合任期和规模。
- **不算**：挂名或代持不等于长期实际管理；仅被卷入政变不等于主动操盘获胜；只凭“有争议”不加分。最终失势、迁徙失败或大战失利不倒推多年高层经营为低政治力。

### 财力

看生产经营、交易、筹资与资源供给。

- **硬底线**（小号须确属同一自然人并由其实际运营，挂名或代持不适用）：
  - 个人资产达数 T（数万亿 ISK）及以上 → EX；按本人及已确认小号合并，不把参与击杀价值、交易流水或代管的军团／联盟国库当成个人资产。
  - 在大亨名单 → 至少 A。
  - 拥有、驾驶或实装混血超旗（派系超旗／泰坦，如科摩多、征服者、归魂者、万古等）或 AT 船参战／持有 → 至少 A。
  - 拥有、驾驶或实装混血旗舰（派系无畏／航母，如天使无畏萨拉希尔级、静谧之主、泽尼塔等）或统合部元帅级（Marshal）等高价值特种舰船（如能玩天使无畏等混血无畏）→ 至少 B。
  - 统筹成规模军团矿业且有名下泰坦实装或数百亿泰坦蓝图交易 → 一般考虑 A。
  - 拥有或驾驶长须鲸级（大鱼）开采／作业，或名下持有大鱼采矿号（长须鲸为工业旗舰，门槛与资产投入极高，普通人不会涉足开大鱼）→ 至少 B。
  - 名下小号很多（成排同名号、多开矿队或生产线、整套号打包出售）→ 至少 B。
  - 名下三个及以上击杀过百的活跃号，或长期靠刷故土、刷怪养出一整排号 → 至少 A。
  - 能十二开及以上同时生产或挖矿 → 至少 S。
  - 刷怪、深渊能手（深渊教学或频道、单刷高等级深渊、魔像刷怪、无畏刷标并自报收益）→ 至少 S，其他五项平平也不降。燃烧任务、虫洞刷怪与五级任务不适用此保底：这些刷法劳动强度高，仅凭刷得熟练、刷得多或总收益高不得直接评 S；须结合投入时间、劳动强度与个人资产积累定档，评 S 需有其他达到该档的依据。
  - KB 薄、击杀账面小、列传没写具体数额，都不能把以上人物压回 C 或 D。
- **天梯**：E 难以为继，破产停摆甚至发帖讨饭｜D 自给自足，承担日常主力单船｜C 资产充裕，可自立工业或随手自备高价值重船｜B 个人产业雄厚，能为队伍垫资筹资｜A 执掌大军团／顶级联盟财政与战备体系，个人资产巨擘｜S 执掌顶级联盟中枢国库，超强金融运作｜EX 个人资产达数 T 的巨富，或操控全服金融大盘的工业金融巨擘。
- **加分**：经常开好船、贵船打 PVP，按舰船与配置档次、投入频率和持续承担战损的规模上调；混血旗舰、混血超旗、AT 船与元帅等高价值特装舰船门槛与造价极高，是资产与财力的直接硬证明；可依据出勤、KB 舰型、配置和战损合理推断，不必另查产业或收入来源。
- **不算**：普通“常规战备自给”不能写成 B。

### 神力

看蠢事、烂事、恶行的程度，是否突破一般道德底线与人类基本预期。**S 是分界线：S／EX 与神人标签同一门槛，A 及以下不达标签规格。**

- **天梯**：E 长期有明确表现的理性克制、守序典范｜D 普通常人，平淡守序（基准）｜C 轻微蠢事、口角或小纠纷｜B 鲜明或反复的蠢事烂事、恶行骂战，尚属常见范围｜A 普通层面的严重蠢事烂事恶行（S 以下的上限）｜S 极为荒唐出格、突破一般道德底线和人类基本预期｜EX 达到 S 后，出格程度与代表性仍极端罕见的标杆事件。
- **定档要点**：
  - 偶发争吵与普通辱骂按严重和反复程度在 C、B、A 间区分，堆积普通对喷推不到 S。
  - 长期、反复、跨场合针对他人的持续谩骂或骚扰，严重超出普通争吵时可直接 S；看持续时间、频率、对象范围和后果，不以围观声量或单次失控代替。评的是可见行为，不作医学诊断。
  - B 及以上必须基于真实的严重出格行为，例如倒卖军团战备违规 RMT、洗劫军团机库、背信卷走盟友资产、滥用管理特权对新人封锁与现实恐吓，按恶劣与越界程度定档。
  - 用已有事件判断，不以流量、骂声或是否破圈代替出格程度。
  - 没有坏事记录不等于低，也不自动等于 E；E 需要明确的理性克制表现。翻译或公共服务的身份本身不替代行为判断。
- **不算神人（这些情形基准一律为 D）**：
  - **游戏机制与对抗玩法**：负安全等级红名海盗、低安掠夺拦截、收买路钱、高安强暴、打捞残骸、多开小号刷 KM、常规收割与追猎。
  - **社区亚文化与自嘲**：名片或简介里的整活、骚话、反差自嘲，二次元喜好，流行游戏梗，群聊吐槽金句，个人口癖。
  - **常规阵营口水**：贴吧对线、本地频道口水战、胜负互嘲，只要未升级为持续开盒人肉、造谣诽谤或现实人身骚扰，至多 C。
  - **正常间谍与情报**：间谍小号、潜伏、伪装、情报搜集；另有独立出格行为时只按该行为评。
  - **单纯有趣**：幽默、自嘲、熟人互损、普通搞笑视频、昂贵舰船损失、政治失败。同时有真实蠢事时按那件事评。

## 横向校准

- 战斗力的全仓统计参照用[人物战绩底表](combat-statistics/README.md)，离线生成主号与全部已确认小号的击杀价值、Solo、年均及分布；先核覆盖范围和快照日期，不能把局部 FC 样本当成全仓或全服排名。底表不自动换算档位。
- 同一维度比较相近人物时用同一口径：战斗力看相同的本人／小号范围、击杀与 solo、实战舰型；统御力看 FC、大战积累和指挥地位；政治力看职位、任期、规模与博弈成果；财力也看 PVP 舰船与配置档次、投入频率；魅力也看 B 站、贴吧的受众、互动和持续影响。不能对一人认可某项加分，对另一人却无理由忽略同类事实。
- 不强制按比例分配各档人数。一般论坛争执和“大家都知道他”不能直接推出高档。
- 标准修订不等于旧评分已重评。旧理由只写“有钱船”“是 CEO”“未见带队”“吐槽有趣”等笼统说法的，后续按对应维度优先校准；仍只验组件，不触发列传复审。

## 与已有标记的关系

雷达品评不自动授予或撤销名人、战神、大亨、神人、UP 主标记，标记仍按[名人与特殊标记](rules-person.md#名人与特殊标记)单独维护。评分须服从的底线见“评分流程”第 1 步；神力 S／EX 与神人标签共用同一出格门槛。

## 附录：FC 专项重核

本节只适用于 FC 相关评分的批量重核，只改战斗力和统御力，另四维保持原样。平时单人评分不需要走这套流程。

**触发条件**（强制复核，可以保留原档，但要写出支持该档的个人事实与数据局限，不套模板，也不因标签自动升档）：

- 有任一 `FC` 标签而统御为 C／D；
- 有 `著名FC` 标签而统御为 B 或更低；
- 统御为 S／EX 而没有 `著名FC` 标签。

**数据准备**：

1. 改分前先查本机 `.cache/person-radar/facts-<阶段>.json`。第一阶段是 FC 标签名单，第二阶段是正文提及指挥的名单，只保留本人或已确认小号有 Monitor 记录者。缓存缺项或抓取失败标为未完成，不凭列传措辞补猜。
2. 横向排序运行 `node scripts/person-radar-data.mjs compare`，生成 `.cache/person-radar/facts-comparison.tsv`：每人一行，含现档位、角色统计合计与分项、旗舰分类、Monitor 日期和战役匹配。此表只便于筛选，原始依据仍是分角色快照；缺项不得按零排序。
3. `.cache/person-radar/` 下的事实表与快照长期保留，供续跑和横向分析，不当临时文件清理。

**战斗力核对**：主号加最多两个按 KB 活跃度选出的已确认主力小号，逐个看总击杀、损失、击毁 ISK、solo 击杀、各旗舰类别击杀和最近活动时间（UTC）。保留各角色分项；合计可能因同一 KM 多个小号都有记录而重叠，不能当作去重数。

**统御力核对**：看 Monitor 记录的 UTC 日期数、首次与最近时间，以及日期和星系都与本站战役匹配的记录，再结合 zKB FC 标注、带队履历和指挥规模定档。

- 每条记录须同时匹配本人角色 ID 与其驾驶的 Monitor 船型。高级搜索同时筛角色和 Monitor 的结果只是线索：同一 KM 里出现角色和 Monitor，不证明该角色本人驾驶；KM 另一方的 Monitor 不计。
- Monitor 于 2018 年 3 月推出，更早不可能有记录；推出后没有记录也不代表没带过队。
- Monitor 天数只说明有公开 KM 观察到其驾驶该舰，不等于带队场次、开麦天数或指挥胜场，不能按天数直接换算档位。

**归档与理由**：

- 把适合长期分析的数字摘要归档到本人 `materials-<短名>.json`：快照日期、来源、角色范围和完整性；按角色列击杀、损失、击毁 ISK、Solo、各类旗舰击杀和最近活跃时间；综述 zKB 活跃月份、Monitor 日期数与首末时间、匹配的本站战役篇数和 KM 数。缺项注明未知及失败原因；只写汇总与代表性记录，不倾倒逐条数据。
- 每次调档的理由写明已核对的关键数字和一场代表性本站战役。参考区间须注明公开来源，只用于人工横向校准，不由脚本自动给分。
