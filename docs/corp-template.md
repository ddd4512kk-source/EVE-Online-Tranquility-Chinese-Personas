# 军团志模板

军团篇是一套独立的写法，不沿用列传和战役的写作标准、料块与验收；成稿按[军团验收](corp-review.md)。列传拿人开涮，军团志则是一张浮夸高调的**星际集团招商皇榜与商业路演白皮书**——读的人无论是在挑下一个下家，还是看热闹，进门感受到的都是扑面而来的排场、财力与自吹自擂。

## 文风

- **浮夸、商业性、理直气壮地吹嘘。** 口吻像顶奢财阀招股书、金牌防务承包商宣传册或王牌俱乐部招募海报：排场拉满、豪气冲天、金句频出，把自家来历、地盘、战绩、基建与福利吹得天花乱坠、风光无限。
- **绝口不提丑事，靠卡片上的“含神量”横条拉满反差。** 正文不用红料、黑料和朱批块，不阴阳怪气，也不转述列传里的黑历史；哪怕打输搬家、人员流失，也按商业公关口径写成“战略转进、资产重组、百战涅槃”。团里现役到底有没有出格人物，交给页面上方公司卡里的“含神量”横条无声揭底。
- **牛皮要有真账撑腰。** 吹嘘不是凭空捏造，也不要自创“星际领航财团”“传世总舵”之类的网文假头衔：人口规模、月矿工业、补损额度、哪年搬迁、哪场大战上了多少人、哪位骨干做了什么，都必须有仓库线索和出处，不编造没发生过的事。把真实的硬指标包装成金光闪闪的宣传牌面。
- **各吹各的调，拒绝千团一面与程序员式干瘪罗列。** 配合档案里的六种卡片视觉主题（`tycoon`、`warlord`、`syndicate`、`neon`、`dynasty`、`phantom`），大航母军团有集团路演腔，海盗佣兵有军火商腔，比赛精锐团有俱乐部腔，老字号有世家腔。
- **长度随材料，不写履历流水账。** 一家有几百字料就写几百字精品招商词，有几千字料就铺陈鸿篇巨制；“甲哪年进团、乙哪年进团”不是路演，页面会自动列列传中人。点到一个人，就吹他给集团立下了什么汗马功劳。

## 结构

开头一段直接亮出集团金字招牌：创立渊源、坐镇掌门、联盟席位、主宰星域与核心排面。之后按材料挑小节，用 `##` 标题，标题要像商业发布会或招商大纲一样高调吸睛，写这家独有的牌面，不写“来历”“福利”之类的干瘪通用词：

- 发家史与版图扩张：谁竖的大旗、跨服传承、几次战略迁徙与联盟博弈。
- 战争机器与王牌编制：重甲旗舰、特种黑隐、比赛冠军或百人会战战果，链到战役页。
- 印钞基建与皇榜福利：月矿产线、工业税率、新人一条龙扶持、补损与奖金制度。招新帖里的承诺与自述放开引，须链到原帖；招新群号由公司卡横幅醒目展示，正文不重复抄群号。
- 明星高管与定海神针：链到列传，只吹此人对本团的正面功绩，绝不拆台。

页面会自动列出列传中人和参战录，正文不必再抄一遍名单。

## 档案评价与视觉风格

同名 JSON 的 `corp` 字段除 `id`、`cn_name`、`epithet`（写成响亮的商业口号）外，还须填写：

- `style`：六选一卡片与页面视觉主题（`tycoon`、`warlord`、`syndicate`、`neon`、`dynasty`、`phantom`），只决定边框、底纹与配色，不生成虚假头衔文字，按军团气质凭印象选定。
- `ratings`：三个 0–100 的整数评价维度，`shenren`、`influence` 凭大致印象填写，页面以装甲/HP 横条展示为**武德**、**含神量**、**声望**：
  - `pvp`（显示为**武德**）：不手填，`corps:snapshot` 按 zKB 最近排名（`rank_recent`）换算（第 1 名 95、第 100 名 86、第 1000 名 72、第 7000 名 55，之间按对数折线，无最近排名记 10）。
  - `shenren`（显示为**含神量**）：现役神人与出格黑料浓度。**只计现任成员（现任 CEO 与现属成员），前成员与仅交集提及的一律不算**；且必须对标[列传规则](rules-person.md#名人与特殊标记)中“神人”的高标准（`src/_data/shenrenPeople.js` 或同等极端出格事迹），普通对喷、常规战术翻车或一般内讧不算，无现役神人的常规军团应保持低分。
  - `influence`（显示为**声望**）：华人社区贡献与江湖影响力。

## 示例

> 2017 年，三位手握矿业资本的资深实业家敲响了星尘联合体的开市钟声。彼时不过一艘长须鲸级工业旗舰与一间租赁机库的精悍火种，短短两年便凭高安冰矿贸易完成原始资本的狂飙积累；2019 年集团挥师南下、整建制入驻零安主权星域，一举奠定今日横跨采掘、制造与星域防务的商业帝国基石。

## 事实与出处

- 仓库里任何线索都能用，来源不必严格：列传和素材提到的一句话、招新帖、论坛回忆、视频、KB、官方资料、军团简介、战役页。事件要有线索，修辞排场可以尽情铺张。
- 素材放 `materials-<短名>.md`，只记事实与出处，含军团简介原文。
- 门槛见[军团规则](rules-corp.md#门槛)。过了门槛就写，线索再少也写成一段体面的商业招牌，别因为材料薄就不开页。
- 现实隐私、歧视内容和未成年人的边界见[军团规则](rules-corp.md#边界)；公开招新群不算隐私。
