# 人物战绩统计底表

供六维战斗力的横向裁量使用。范围为已收录人物的收录号与**全部已确认小号**，不局限于已有雷达或 FC 标签，也不沿用 FC 专项“最多两个主力小号”的抽样范围。

这里保存 zKillboard 公开数字及来源，不生成综合战力分、不自动改档。人物、身份对应和评分仍由原档案维护；取数不触发列传复审。

## 使用

```powershell
node scripts/person-combat-data.mjs seed
node scripts/person-combat-data.mjs collect
node scripts/person-combat-data.mjs report
```

- `seed`：优先导入已有分角色统计缓存；缺少 Solo 的旧身份摘要只作为部分数据，不补成零。完整记录不会覆盖。
- `collect`：只为核心字段不完整的角色请求一次 stats；串行并复用请求守卫。每成功一个角色就保存，可续跑。API 未提供有效角色统计时标记该号 `unavailable`，保留已有摘要和缺口，继续既定名单；以后默认复用失败记录，不反复查询。403、429、412、挑战页、超时或请求预算用尽立即停下，失败保留原因，不用零填平。遇平台停止状态不能为了补齐而换工具、出口或重置冷却。
- `report`：离线重新读取当前人物与全部确认小号，生成比较表及分布。新人物、新小号纳入后先 `seed`，再按实际缺口 `collect`。

原始事实保存在 `characters.json`，每个角色一条；这是独立统计数据，不回写人物快照。可推导的结果生成到 `.cache/person-combat/`，无需手工维护全员总表：

| 文件 | 用途 |
| --- | --- |
| `people.tsv`、`people.json` | 一人一行，主号与全部确认小号合计、覆盖状态与年均口径 |
| `characters.tsv` | 一角色一行，核对主小号贡献、来源、取数时间与失败原因 |
| `summary.json` | 样本数、全仓及现有各战斗档的四分位数、中位数、P90、P95 |
| `roster.json` | 最近一次联网采集冻结的对象清单，不作为身份权威记录 |
| `collection.json` | 最近一次采集实际请求数、停止位置和原因 |

## 统计口径

- **参与击杀数与总价值**：角色出现在攻击者名单的累计战果，不是个人独立输出、收益或资产。旗舰分类记录的是击杀目标舰型，不表示本人驾驶或拥有旗舰。
- **Solo 数与比例**：采用 stats 的 `soloKills`，比例为 Solo／参与击杀数；展示数量和比例两项，避免把几次单杀的高比例与大量单杀等同。数字缺失、抓取失败与真实零值分开。
- **年均参与击杀价值**：直接复用站内 `personCombat` 的现行算法：主号与全部确认小号价值合计，除以“收录号创号月到各号最后活跃月中最晚者”的年数，**至少按两年计**。按月份计算，不是近十二个月，也不是逐年平均活跃月收益。缺创号月或无法确定止月时留空；表内保留起止月和实际除数。
- **账号年龄的局限**：老号、购入号与停玩多年者会受分母影响；只比较年均会低估长时间停玩的老角色。换主号可能改变现行分母。此表为对照保留现有站内算法，不凭数字推断实际持有人或偷偷改变战神标准。
- **多开合计不去重**：同一 KM 可能被本人多个号共同记录，人物合计是账号统计之和。保留角色明细及多号标记，不将其称为唯一击杀数；不把所有角色击杀价值叠加称为全服损失。
- **完整性**：人物的所有确认角色均有参与击杀、损失、击杀价值、Solo，才标为 `complete`；任何一号缺某项，该项人物合计留空。完整人物才进入总体分布，不能把缺项人数当作零战绩。
- **时间与来源**：API 新取数记录真实 `observedAt`；既有雷达缓存保留其原有记录时间。旧原始 stats 未记录抓取时间的，`observedAt` 留空、另记文件修改时间；文件修改时间不是抓取时间，不能冒充同日刷新。不同来源、不同日期的累计数允许作为生涯参考，不能宣称全仓为同一时刻的实时排行。
- **所有权边界**：只合并已确认角色；售号、代管前后的历史战果仍需结合素材判断归属。底表保存的是角色公开累计数据，不自动裁定全生涯属于当前自然人。

## 如何用于裁量

先看本人主号和所有确认小号的贡献，再比较全仓分布和现有同档人物。至少同时看参与击杀价值、参与击杀数量、Solo 数与比例、年均、角色数和取数范围；多开强项、旗舰实战、比赛实际登场仍结合人物材料判断。

分位数描述的是**本站已收录样本**，不能直接称为全服排名，也不是 A／S／EX 的自动阈值。现档位分布只用于暴露尺度不一致，不用旧评分循环证明新评分。补全范围或统一快照前，不拿局部 FC 表代替全仓样本。
