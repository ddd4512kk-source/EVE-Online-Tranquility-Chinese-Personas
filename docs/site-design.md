# 网站设计约束

由 `AGENTS.md` 第 7 节要求：改布局、样式、前端交互时读取。

- **纯静态**：无数据库、后端、运行时 API；游戏数据是一次性快照。
- **零外部资源**：不引用 CDN、Google Fonts、统计脚本；只用系统字体栈。唯一例外：页眉的 hits.sh 访问计数徽章（一张图，全站共用一个计数，地址在 `src/_data/site.js`）。
- **移动优先**：16px 页边距，任何宽度无横向滚动。改完在 390px 与 1366px、深色与浅色下检查，无 JS 报错。
- **深浅双色**：默认深空墨底，浅色模式为宣纸底；新样式只用 `site.css` 的 CSS 变量。
- **无 JS 也能读**：JS 只做增强（筛选、排序、随机、搜索、标签折叠）。
- **视觉**：史书列传 × 深空。衬线正文；`epithet` 与 `::: 评` 用朱砂色（朱批）；红料红边框“红”字徽记，黑料墨块“黑”字徽记；站印红底白字“野”。
- **首页**：按创号时间排序（可倒序、随机），连续网格，每年首张卡挂年份签；标签栏单选同步 `?t=`，筛选框同步 `?f=`。列传页网址 `/p/<角色ID>/`。
- 简单胜于花哨，不引入运行时依赖。
