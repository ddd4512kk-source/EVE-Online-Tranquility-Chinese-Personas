# 网站设计约束

由 `AGENTS.md` 第 7 节要求：改布局、样式、前端交互时读取。

- **纯静态**：无数据库、后端、运行时 API；游戏数据是一次性快照。
- **零外部资源**：不引用 CDN、Google Fonts、统计脚本；只用系统字体栈。唯一例外：页眉的 hits.sh 访问计数徽章（一张图，全站共用一个计数，地址在 `src/_data/site.js`）。
- **移动优先**：16px 页边距，任何宽度无横向滚动。改完在 390px 与 1366px、深色与浅色下检查，无 JS 报错。
- **深浅双色**：默认深空墨底，浅色模式为宣纸底；默认跟随系统，页眉日／月按钮可手动切换（`html[data-theme]`，存 `localStorage`，无 JS 时按钮隐藏）。新样式只用 `site.css` 的 CSS 变量；浅色取值在 `site.css` 里有两段（跟随系统、手动选定），改一段必须同步另一段。
- **无 JS 也能读**：JS 只做增强（筛选、排序、随机、搜索、标签折叠）。
- **视觉**：史书列传 × 深空。衬线正文；`epithet` 与 `::: 评` 用朱砂色（朱批）；红料红边框“红”字徽记，黑料墨块“黑”字徽记；站印红底白字“野”。
- **首页**：按创号时间排序（可倒序、随机），连续网格，每年首张卡挂年份签；标签栏单选同步 `?t=`，筛选框同步 `?f=`。列传页网址 `/p/<角色ID>/`。
- **板块**：页眉导航按 `src/_data/sections.js` 依次列板块，再接搜索、随机、深浅切换（标签在列传首页标签栏筛选，`/tags/` 页保留但不进导航）；板块尚无内容时不进导航。战役目录 `/battles/`，战役页 `/battles/<短名>/`，默认按开打日期倒序，可切时间新旧、按损失、随机排序，标签栏单选（规模档位在前）同步 `?t=`；一场一行，标题与总损失、参战人数用大字（总损失朱砂、人数金色），行内并排列各方阵营（主要联盟、参战角色数、损失金额、损失记录条数、华人军团与收录人数）。战役页标题下先列总损失、参战角色、交战方三个大数字，再接时间地点（星系有中文名的写“欧贝（Obe）”，名表在 `src/_data/systemNames.js`）、阵营卡片（每方突出显示参战角色数、损失金额、损失记录条数，再列损失占比条、联盟、华人军团、人物；缺数保留标签并显示“待补”），再接正文。联盟、军团名一律链到 EveWho，与列传页一致。史诗用朱砂实底徽记，大型用金边徽记，中型用灰边徽记。新板块沿用卡片、`bio-facts`、`prose`、朱批与翻页组件，网址用 `/<板块>/<短名>/`，不改动已有网址。全文搜索按 `板块` 筛选。
- 简单胜于花哨，不引入运行时依赖。
