# 找料方法

取材手册。目的是**找故事**，不是凑完备档案：找到能写的料就可以先立传，以后再补（门槛见 AGENTS.md 第 2 节）。本文件只写通用方法，不提具体人物；人物材料写进本人 `materials-<短名>.md` 或 `docs/leads/`。

## 一、三条原则

1. **先问此人以什么出名。** 那件事必须是列传最重的一块。画像（常用船、星系、联盟）和料对不上时，说明还有没找到的。
2. **搜不到 ≠ 没料。** 验证码、403、外号撞常用词都是搜索失败，记为【搜索失败】并换渠道，不当成零结果。
3. **找到就收。** 有出处的料全部入列；轻料并进相关块。对立说法并列，本人自吹与别人揭短对不上时并排放——往往最好笑。
4. **先留素材，再判断能否写。** 搜索到或收到材料时，尽量保存原始内容/关键摘录、必要上下文、出处、时间、作者或说话者及角色对应线索。暂时不适合写、归属不明或尚未核实的内容，归入对应人物素材或 `docs/leads/`，写明待核问题/暂缓原因，留待未来补写或复核；不因当前用不上而丢弃。不得为存档而保留现实隐私。

## 二、必查四项（每项在素材文件记一行：命中 / 零结果 / 搜索失败）

### 1. 游戏画像（最先做）

`node scripts/research/profile.mjs <角色ID> [论坛用户名] > 画像.md`

一次拉齐：头衔与简介全文、每段军团当时所在联盟、zKillboard 常用船/星系/高价值月份、凛冬论坛本人全部发帖。重点看：

- 本人写的角色简介，常常就是最好的料；
- 常用船 + 星系暴露玩法（Catalyst/Talos + Uedama、Niyabainen = 高安强暴）；
- 某月 ISK 暴增 = 大会战，去查那个月；
- 凛冬论坛标题带敏感词（强暴、骗、举报……）的帖子必读。

需要细查：zKillboard `api/kills/characterID/<ID>/year/<Y>/month/<M>/`（curl 要加 `-L`）、ESI `killmails/<id>/<hash>/`、DOTLAN 军团事件史。

**追历史 CEO 时查任期和角色归属。** 遇到军团旧事、踢人、封号或管理争议，打开 DOTLAN 对应军团的 `/events` 页，逐条看 CEO 辞任、接任记录，再用事件发生日期对上当时的 CEO 角色；接着核对历任角色是否属于同一人。DOTLAN 只记录角色换任，不证明换了真人。EveWho、ESI 军团页显示的现任 CEO，不能倒推旧事归谁管；某个小号的入团日期，也不能当作本人首次掌管军团的日期。把角色任期、本人对应和事件日期记进人物素材，再写归责。

### 2. 贴吧（eve欧服吧为主，其次 eve吧）

首选匿名客户端工具，不弹验证码：

| 要做什么 | 命令 |
| --- | --- |
| 站内搜索 | `node scripts/research/tieba-client-search.mjs "eve欧服 关键词" 4 eve` |
| 翻帖子列表（约两年） | `node scripts/research/tieba-client-forum.mjs eve欧服 1 110 temp/frs.tsv` |
| 读帖 | `tieba-client-read.mjs <帖子ID> <临时.json> [页数]`，再 `tieba-client-dump.mjs <临时.json>`；加 `--images <楼层数> <目录>` 下载截图 |
| 某账号全部发帖 | `tieba-client-user.mjs <帖子.json> <用户名片段> [1主题\|0回帖]` |

- 关键词带“eve欧服”；外号撞常用词时改搜事件词、联盟名、英文角色名。
- 搜索命中常只是一句回帖，点进主题读完整楼层。截图里的聊天人名、KM 常常就是角色名。检索脚本的结果可能混入其他吧，逐条确认吧名；前三页没命中目标吧，不算零结果。
- 账号追踪同时核对客户端的展示名 `name_show`、原用户名 `name` 和 uid。展示名变成“贴吧用户_……”时不能因此判断此人没发帖；`hide_post=1` 只说明回复列表隐藏，转查主题、站内命中与他参与的帖。
- 原始输出可能含现实隐私，只放临时目录。

### 3. 搜索引擎

先 Google（代理自带网页搜索，加 `site:tieba.baidu.com`）和必应，最后才用百度/360（容易限流）：

- `node scripts/research/baidu-search.mjs "某某 eve欧服吧"`；被拦用 `--so`（360）、`--bing`。
- 批量：`node scripts/research/batch-search.mjs <清单.tsv> <输出目录>`，自动轮换、冷却续跑；国内引擎各二十来条就会被拦，分批少量跑。

| 目的 | 关键词（“某某”换成中文名、外号、角色名） |
| --- | --- |
| 评价 | `某某 eve欧服吧`、`如何评价某某` |
| 黑料 | `某某 封号` `吧主` `洗号` `骗` `RMT` `跑路` `叛逃` `谴责某某` `强暴` `举报` |
| 国服旧账 | `某某 eve吧`、`某某 国服` |
| 整理文 | `某某 EVE领航员`、`名人堂`、`传奇` |

### 4. B 站（与贴吧同等重要）

`node scripts/research/bilibili.mjs <命令>`：`user <关键词>` 搜 UP、`search` 搜视频、`videos <mid>` 列全部投稿、`video <BV号> [评论页数]` 读简介与评论、`dynamics <mid>` 动态。

- 先用 Google/必应 `site:bilibili.com 外号` 找账号，再跑脚本；请求间隔 10–20 秒，被 412/-352 拦就冷却。
- 评论区与弹幕是料的主要来源：本人回怼、对面来骂、熟人揭短都记下。
- 也在别人的会战复盘、周刊、对面视角里搜他。

### 其他渠道

知乎（“如何评价某某”）、百家号“EVE领航员”、PLA 论坛 forum.pla-eve.com、外网（Reddit、forums.eveonline.com 的 `search.json`、凛冬论坛、帖中链接的 Google Docs）。外国联盟的戏多在英文圈。

## 三、原帖读不到时

- 贴吧网页被拦：先用 `tieba-client-read.mjs`；仍不行用 `node scripts/research/tieba-read.mjs <输出目录> <帖子ID>` 打开有头浏览器，请维护者手动过验证。
- 帖子被删：Google 搜标题和帖子号，查 Wayback `https://web.archive.org/web/<时间戳>id_/https://tieba.baidu.com/p/<帖子ID>`、archive.is。
- 只有搜索摘要也能当来源写（“据某帖摘要”），不必因为读不到全文就放弃。

## 四、发现新人物

按名字找只能找回已知的人。改用：

以社区帖子、回帖和作者网络为主线，名册作补充入口；一条入口的零结果不能代替另一条：

1. **社区故事发现人物**：对贴吧帖子列表的“标题 + 首楼”按职务词（总监、CEO、团长）、冲突词（弹劾、背刺、澄清、骗、跑路、封号、悬赏）、叙事词（前传、始末、回忆、经历）加分，招新、交易、求助减分；按分数而非回复数读。数字加物品或事件词的标题也要抽样读，不能只看冲突词。回复多但首楼中性的帖子，至少检查正文和楼中反复被点名的人。
2. **按楼主 uid 聚合、追被点名者**：短期连发长帖、连开十来帖的楼主本身可能就是名人；回帖多但只开过一帖的人也可能是关键人物，不能只按发主题数筛。楼中反复出现的人名、`@`、别名和“这位就是……”“又是他”，都转为候选并查重；角色藏在回复里时，不能因为标题和楼主不是他就跳过。用 uid 合并改名账号，保留原用户名和展示名。
3. 排除已读帖子号再看。列表接口只回溯到约 2024 年中，更早的用站内搜索 + 上述关键词。
4. **名册补充**：CCP 各届 CSM 候选公告与竞选区、联盟锦标赛队伍名单、重大事件战报、军团管理名单可补漏，逐名对照本站列传、人物素材和待确认角色备忘录。候选公告中的 `Chinese`、`中文`、华人军团或联盟只是优先核对线索，不凭姓名、所在联盟或贴了中文版就认定与华人圈有关；参选和当选分开核对。发现人后仍要回到社区帖子找故事。

每次名单反查记下来源、覆盖的届次或事件、逐人的“已收录 / 新候选 / 关联待核 / 排除”及依据。只写“查过 CSM”不足以说明覆盖；未逐项对照的届次继续列为未查。查到本人公开竞选与角色对应、已有一件有出处的事，就按收录规则立传；身份未对上才进 `docs/leads/` 与角色备忘录。

有自己的故事（不只是别人回忆里路过一句）的人就登记或直接立传。

## 五、已知的坑

- 角色名以本人或当事联盟写法为准；同一外号可能指不同人，用游戏数据或原帖区分。
- B 站视频被删且认不出作者时不引用。
- Playwright 报 “Executable doesn't exist”：运行 `node node_modules/playwright/cli.js install chromium`。
