# 列传九宫格阵营

九宫格阵营是独立的趣味展示组件，用守序／中立／混乱 × 善良／中立／邪恶给人物贴一个一眼可读的立场与作风标签。它是编辑印象，不是考证：按列传和素材里已有的故事判断，不为定阵营另开调查、联网核证或补写正文。

## 组件边界

- 数据存在人物档案 `<ID>-id.json` 的 `person.alignment`，由 `scripts/person-alignment.mjs` 校验；不写入列传正文、身份或游戏快照，也不进雷达评分。
- 复审指纹跳过此字段（与六维相同），增删改阵营不触发 `combat`、`writing-depth`、正文补写或列传评审子代理。只验组件本身：档案校验、页面与卡片显示。
- 阵营不授予或撤销名人、战神、大亨、神人、UP 主标记，也不作为收录或 `著名FC` 依据。

## 两条轴

- **守序／中立／混乱**看此人对规则、契约、组织和承诺的态度。守序：守联盟规矩、按合同办事、长年经营组织、言出必行。混乱：随性而为、无视军令、说走就走、爱搅局、以乱为乐。介于两者或材料只显出普通的组织生活，取中立。
- **善良／中立／邪恶**看此人对他人、同胞与队友的作为。善良：带新人、做公益工具与汉化、为队友扛事、救火补损。邪恶：坑骗同胞、卷款跑路、出卖队友、恶意内斗、长年欺凌新人。只是打仗、没有明显的好坏行为，取中立。

### 不算邪恶的情形

- 正常的游戏对抗：打仗、击杀、战损、拆建筑、围攻。
- 海盗、掠夺、自杀式拦截、虫洞清扫等玩法本身。
- 跳槽、换边、解散军团、退坑。

这些只能作为守序／混乱轴的参考：长年专业做海盗、规矩森严的可以是守序；随手打劫、四处惹事的偏混乱。游戏内骗局按野史照写，但只有骗的是同胞、队友或新人这类熟人圈，才往邪恶一边推。

### 材料单薄

性格材料少、只有任职与战斗经历时，按已知身份与行为选最接近的一格（常见是守序中立或绝对中立），省略判词；不为此补充调查。

## 判词

- 可选，一句话，不超过 40 字，写进 `note`；不写就省略字段，不留空串。
- 可以戏谑，点出为什么落在这一格；不做人身攻击、现实身份指认或现实疾病诊断，不涉及现实违法指控。
- 判词只说已有故事里的事，不另造新事件。

## 数据格式

```json
"person": {
  "alignment": { "code": "CE", "note": "合同签一半先把甲方拦了，理由是“看着就肥”。" }
}
```

`code` 取 `LG` 守序善良、`NG` 中立善良、`CG` 混乱善良、`LN` 守序中立、`NN` 绝对中立、`CN` 混乱中立、`LE` 守序邪恶、`NE` 中立邪恶、`CE` 混乱邪恶。首字母是守序（L）／中立（N）／混乱（C），次字母是善良（G）／中立（N）／邪恶（E）。只允许 `code` 与 `note` 两个字段。

## 虚构示例

- 虚构人物“甲”：长年按合同给各方护航，账目分毫不差，从不接打同胞的单 → `LN`，判词“收钱办事，钱不到位人不到场”。
- 虚构人物“乙”：低安海盗团团长，团规写了二十条，抢劫只抢外人 → `LN`，不因海盗玩法判邪恶。
- 虚构人物“丙”：做了免费的中文工具，还常在频道里给新人补船 → `NG`。
- 虚构人物“丁”：入团三个月卷走团库，转头在另一边开新团 → `CE`；若只是换边、没有卷款，则不算邪恶。
- 虚构人物“戊”：只知道某年当过军团 CEO、打过几场仗 → `NN`，不写判词。

## 定阵营的时机

- 新收录列传时必须同时定下阵营，缺阵营不得报告创建完成。
- 改写或实质补写既有列传时，若此人还没有阵营，顺手补定。
- 不为既有人物批量补定阵营。阵营由代理判断，维护者抽查；抽查后的修改只改档案字段，按组件处理。
