# 战役验收

只管战役页，落实[战役规则](rules-battle.md)与[战役模板](battle-template.md)。列传、军团的验收都不适用。

## 一票否决项（出现任一项即打回扩写）

1. **UTC 战报账单开篇**：第一段以“202X年X月X日XX:XX至XX:XX（UTC），爆发了一场……打出XXX条损失记录、XXX名角色参战与XXXB ISK总战损”开篇。
2. **八股阶段标题**：`##` 小节标题带着“起因：”“集结：”“交锋：”“转折：”“收场：”前缀，或按“甲方／乙方”分节。
3. **报菜名式点名**：正文出现“本地档案可查 A、B、C、D 等人在参战名单之列”“甲方有 A、B、C，乙方有 D、E、F”这类只有人名列表、没有具体动作与处境的句子。
4. **背诵船型统计表**：在正文里罗列“某级损失 118 条（100.2B）、某级损失 75 条（76.1B）、某联盟损失 XXB”来充当交锋过程。
5. **高潮块偷懒**：全篇只写 1 块 `::: 高潮`，或把素材里已有的人物翻车、主小号双交、高价战损、旧怨重逢、第三方偷鸡、战后视频自嘲与评论区／Reddit 嘴仗漏在块外、一句话带过。
6. **人物扁平无反差**：点到核心参战人物却只写“某人开某船参战／丢了船”，没有结合其列传里的外号、老东家、旧怨或日常人设写出反差。
7. **只摘抄不发挥**：高潮块或章节只是把战报数字和视频简介拼在一起，没有写出当时的战场处境、各方盘算与损人落点。

## 成稿逐项核对

通读 `_site/battles/<短名>/index.html`、战役目录和受影响的人物页，逐项核对：

- **够不够格**：是一场真打起来的仗，不是少数旗舰事故、单方面围猎或转移事故。编组的 `start`／`end` 覆盖全程，已编组的单场没有另立页。
- **分方**：读过 BR 网页的完整分队，映射与采用理由留在素材。分方改动已同步数字、人物与军团归属、正文和素材。
- **数字与展示**：各方人数、损失、记录条数和主标对得上；缺数有 `stats_note`，小规模第三方按门槛隐藏。
- **标签**：战斗类型依据留素材，没有按损失金额或一条无畏升级。
- **人物**：以自然人为主语，主号小号合并讲。开监视者的直接当 FC 写，不提船型、不念次数；集体战果不算成个人功劳。点到名的人物有具体动作、座驾或战损，并借列传背景写出反差；立场中立，打赢谁都只是战绩。
- **取材**：素材里有参战人物列传（含核心人物人设与旧怨背景）、相邻战役和相关视频的检索结果；那里记过的本场事件与名场面已全部充分进正文，或在素材写明不用的理由。
- **故事与群像**：开篇从华人这边的设局、狠话或反差切入，没有以数字开篇；正文按时间线推进，小节标题抓戏且不带阶段标签；镜头在攻守各方与第三方之间轮流切换，没有写成单方视角流水账；每个 `##` 小节都有完整场面，没有报菜名点名，也没有拿船型统计清单代替故事。
- **高潮**：凡是有戏的战局转折、人物特写（主小号双交、高价或离奇战损、旧怨重逢、FC 带队或被点杀）、第三方外圈摸鱼、战后视频与评论区嘴仗都已用 `::: 高潮` 展开（不设上限，中型一般不少于 3 块，大型／史诗随素材充分铺开，绝不仅有 1 块）；每块都是四五句以上、带人设反差和现场发挥的完整小故事。新写或修订的稿没有 `::: 红料`／`::: 黑料`，旧块已悉数保留内容并改进时间线高潮块。
- **口吻**：没有“据传”“帖主称”“想来”等护身词，没有“尚无法确认”“不能证明”等收尾；待核的账都在素材里。外文原话已译成中文。
- **改写**：修订已有战役时，故事只能变长不能变短，原有的人物特写与事件一块不丢。
- **相关视频**：与本场直接相关，转载和合作写明原作者，介绍只写读到的内容。
- **战役头图**：只要有 `videos`，就已配置 `cover` 并生成 `src/assets/emblems/cover-<短名>.webp`（无封面图不得过审）。
