# 战役验收

只管战役页，落实[战役规则](rules-battle.md)与[战役模板](battle-template.md)。列传、军团的验收都不适用。

通读 `_site/battles/<短名>/index.html`、战役目录和受影响的人物页，逐项核对：

- **够不够格**：是一场真打起来的仗，不是少数旗舰事故、单方面围猎或转移事故。编组的 `start`／`end` 覆盖全程，已编组的单场没有另立页。
- **分方**：读过 BR 网页的完整分队，映射与采用理由留在素材。分方改动已同步数字、人物与军团归属、正文和素材。
- **数字与展示**：各方人数、损失、记录条数和主标对得上；缺数有 `stats_note`，小规模第三方按门槛隐藏。
- **标签**：战斗类型依据留素材，没有按损失金额或一条无畏升级。
- **人物**：以自然人为主语，主号小号合并讲。开监视者的直接当 FC 写，不提船型、不念次数；集体战果不算成个人功劳。立场中立，打赢谁都只是战绩。
- **故事**：开篇交代为什么打、谁和谁；正文按时间线推进，小节标题点阶段不点阵营，每个有华人戏份的阵营都有人出场，统计清单没有代替故事。
- **高潮**：一般 2–3 块、不超过 4 块 `::: 高潮`，放在发生的位置；每块是完整场面，够格的才进，普通 KM 与普通胜负没有被吹大。新写或修订的稿没有 `::: 红料`／`::: 黑料`，旧块已改进时间线。
- **口吻**：没有“据传”“帖主称”“想来”等护身词，没有“尚无法确认”“不能证明”等收尾；待核的账都在素材里。外文原话已译成中文。
- **改写**：修订已有战役时，故事没有变短。
- **相关视频**：与本场直接相关，转载和合作写明原作者，介绍只写读到的内容。
