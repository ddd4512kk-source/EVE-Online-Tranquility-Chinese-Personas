# 军团规则

本页管军团页的开页门槛、招新判定、写法与评价指数；写或改 `src/corps/` 下的文件、判断某军团能否开页时读。[列传规则](rules-person.md)和[战役规则](rules-battle.md)都不适用于军团；这里没写的，不去那边找。

写法与结构见[军团志模板](corp-template.md)，成稿按[军团验收](corp-review.md)，字段与快照工具见[军团指令](../src/corps/AGENTS.md)，流程用 `add-corp`。

## 门槛

华人军团满足下列任一项 → 开页，线索再少也写一段：

- 有招新帖。简介写着仅限邀请，只要有招新帖就算在招。
- 有现任列传人物（CEO 也算，一个就够），且军团活人超过 20。人物已离团的不算；只看当前，不看历史雇佣记录。
- 仍活跃。在册活人不超过 20 个不算活跃。

一条都不满足的华人军团，以及所有外国军团 → 不开页，记入 `docs/corps-excluded.json` 并写明原因。

活跃、招新状态由快照计算，不手写。正文还是“待写”的军团不出页面，也不进目录，写完自动上线。

## 正在招新

满足任一项 → 页面标“招新中”：

- 一年内发布的招新帖，或一年内仍有人回复的招新帖。没有 QQ 群号，但近期仍在维护的招新帖也算。
- 找得到招新群 QQ 号，且今年任一月有超过 10 名本团驾驶员上 KB。群号可来自军团简介、招新帖，或 B 站 EVE 视频简介／回复中明确属于该军团的群号。写“招新Q”加号码的一律当招新群；归属不明的号码不算。

字段：

- `recruitment.last_seen`：最近一次可核实的招新活动日期；招新帖有新回复时记最近回复日，不只记主题帖发帖日。
- `source`：最能证明招新的原帖或视频。
- `qq`：核实归属的招新群号。

不算有效证据：普通讨论回复、对应不到该团的群号、无法确认日期的帖子。

## 写什么与评什么

### 正文

- 浮夸、商业性、自吹自擂的招商路演风，绝口不提丑事，丑事归列传；不用料块与朱批。
- 招新帖里的福利、自述可尽情铺陈吹嘘，须链到原帖。招新群号由详情公司卡横幅显示，正文不重复抄群号。
- 事件要有线索，不编没人说过的事，也不编本人原话。取材来源、事实与细节的尺度见[军团志模板](corp-template.md#事实与出处)。
- 舰船、建筑、星系、星域名按[术语用法](terminology.md)写中文。

### 卡片主题与评价指数

军团档案另记两项，在 `/corps/` 目录与军团公司卡上展示，与正文的官方自吹形成反差：

- `corp.style`：卡片视觉主题，取值见[军团志模板](corp-template.md)；只控制配色与轮廓，不造假头衔。
- `corp.ratings`：三项 0–100 指数，以 HP 横条展示。

| 字段 | 显示名 | 怎么定 |
| --- | --- | --- |
| `pvp` | 武德 | 由快照按 zKillboard 最近排名换算（公式见[军团志模板](corp-template.md)），不手填 |
| `shenren` | 含神量 | 凭大致印象填；只看现任成员，前成员不算；对标[列传规则](rules-person.md#名人与特殊标记)中“神人”的高门槛 |
| `influence` | 声望 | 凭大致印象填 |

## 边界

- 不写现实隐私（真名、单位、住址、电话、照片）、地域民族性别外貌歧视、未成年人；公开招新群不算隐私。
- 不写游戏世界观与 NPC 势力（种族、NPC 学校、NPC 军团）；进出 NPC 军团只说“换军团”“退团”。

## 目录与素材

`src/corps/<短名>/` 放同名 `.md`、`.json` 与 `materials-<短名>.json`。素材只记事实与出处，含军团简介原文；不记录素材提供者身份或对话过程。
