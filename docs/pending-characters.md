## 维护方法

- 查人前先检查素材库索引、备忘录与已有列传，确认是否同一人的其他角色。
- 没有可靠对应角色时，记录身份线索、候选与一个具体待核对问题；故事、原帖及渠道结果写入素材库对应人物节。
- 角色已确认但尚未写列传时，移入待撰表；不要因为查到 ID 就让人选消失。
- 完成列传后更新素材库的收录状态和源文件链接，从待撰表移除；关联角色疑问可以继续保留。
- 排除的同名候选保留排除原因，避免重复误认。
- 多人同时编辑时先检查认领和最新文件，避免重复建档；已有人认领的条目沿用当前分工。
- 全部材料按人物和用途维护，不再按取材轮次另建文件。
