# 添加／修订战役

读取 `docs/content-rules.md` 第 3 节、第 5 节“战役”及第 6 节，字段与口径读 `docs/battle-template.md`；写作前读内容规则第 4 节和 `docs/writing-review.md`。涉及新人物收录再读第 2 节。

1. 用 `npm run materials -- "星系或战役名"` 定位已有战役与来源，再在相关战役表、人物素材中查重，核对星系、日期和编组范围；按内容规则决定单场或编组。跨篇复查或修改分方功能，先按[增量复查](../../../docs/review-workflow.md)筛 `battle-attribution` 卡片与变更影响，不整批加载所有战役正文。标题与短名按战役模板。
2. 选择战报来源与窗口，按取材手册读取网页完整分队，与当事人复盘及逐舰记录交叉核对后点名归方，把完整映射、冲突与采用理由、逐方核对结果写进素材；执行内容规则的分方交叉核对要求。配置统一存于`<短名>.json`的`battle`，归方只用`organizations`、主标单独用`emblem`；Markdown只留正文。快照用`npm run fetch`抓入同一JSON的`br`，刷新只替换`br`；手填按模板逐方核统计。联盟重名时认本场 ID。
3. 对照算出的各方、自动参战联盟、人物及华人军团。联盟名单按模板由历史快照汇总，展示与名称补取遵守内容规则的10人／华人军团条件，不逐场手补或用当前联盟回填；核对同一联盟及其所属军团均在同一方，跨方即回查并修正，不解释为军团独立站队。小号未识别时补本人 `<ID>-id.json` 的 `identity.alts`，人物落错方时改组织归属；按内容规则标记华人军团。人物列传引用本场战报处改链到战役页，KM 链接保留。
4. 按阵营写有戏的人与事，按战役模板整理相关视频，素材存 `materials-<短名>.md`；只更新仍有待办的原队列，材料目录按需生成。
5. 按 AGENTS.md 校验，通读 `_site/battles/<短名>/index.html`、目录及受影响人物页；核对分方数字、主力归属、缺项说明与小规模第三方隐藏。
