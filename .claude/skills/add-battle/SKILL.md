# 添加／修订战役

读取 `docs/content-rules.md` 第 3 节、第 5 节“战役”及第 6 节，字段与口径读 `docs/battle-template.md`；写作前读内容规则第 4 节和 `docs/writing-review.md`。涉及新人物收录再读第 2 节。

1. 在 `docs/sources/` 战役表、人物素材及已有战役中查重，核对星系、日期和编组范围；按内容规则决定单场或编组。标题与短名按战役模板。
2. 选择战报来源与窗口，先读分队再点名归方，把映射依据写进素材。快照用 `npm run fetch` 抓取；手填按模板逐方核统计。联盟重名时认本场 ID。
3. 对照算出的各方、人物及华人军团。小号未识别时补本人 `alts`，人物落错方时改组织归属；按内容规则标记华人军团。人物列传引用本场战报处改链到战役页，KM 链接保留。
4. 按阵营写有戏的人与事，按战役模板整理相关视频，素材存 `materials-<短名>.md`，同步 `docs/materials.md`。
5. 按 AGENTS.md 校验，通读 `_site/battles/<短名>/index.html`、目录及受影响人物页；核对分方数字、主力归属、缺项说明与小规模第三方隐藏。
