# 小号深挖

目标是挖出某人的全部小号，查军团只是手段之一。被要求挖某人小号、被指出某个号或军团“像是一个人开的”，或 `research-community` 调查中碰到疑似一人多开的小团、成批同词根号、无外人的多开编队且能对上已收录人物时使用；普通收录与修订不跑。合并底线见 `docs/rules-person.md` 的“敌对势力的同名先排除”“小号直接合并”，常规查漏手段见 `docs/research-person.md` 的“小号查漏”；本技能只补深挖的步骤和判定。动 `src/people/` 前先读 `add-person`；联网前读 `docs/research-method.md` 的“联网条件与预算”。

## 步骤

1. **列种子**：`node scripts/person-identity.mjs <短名>` 取主号和已确认小号，把维护者新给的号一并列入。读本人素材的身份一节，已排除和待定的号不重查。
2. **多线找候选**：以下线索互不替代，一条零结果不算查完；每冒出一个新确认的号，就把它当新种子回到这一步，直到不再出新号或预算用完。
   - **命名**：按 `research-person` 的名字扩查和 EveWho 前缀搜索，从全部种子名拆词根、编号、姓氏、形近写法。
   - **雇佣记录与马甲军团**：取每个种子的 ESI `/characters/<ID>/corporationhistory/`，再查 ESI `/corporations/<ID>/` 的 `member_count`、`creator_id`、`ceo_id`、`date_founded`、`ticker`。不超过 20 人、或创建者／CEO 是种子的个人仓库团、诱导团等马甲团，在 EveWho 军团页读全部当前与历史成员及进出时间；同一创建者几分钟内连建、军团 ID 相邻（含错拼重建的空团）、ticker 同词根的团一并算入。大团、NPC 军团和联盟只作背景。
   - **头衔与简介**：同团角色的军团头衔写着本人名字或外号的；简介、诗句、签名与种子或本人 B 站等平台逐字相同的。
   - **多开战斗**：从种子的 KM 统计反复同场、且队里没有外人的共同出击者；同场同款装配同价船阵亡、几十秒内同星系先后爆采矿船或运输船、一号开诱导另一号紧接跳来投送，都把对方号列为候选。
   - **社区自报**：本人素材、贴吧帖与截图里出现过的号名、KM 链接和“我小号”一类说法。
3. **逐号核对**：对候选取 ESI 角色资料（建号日、简介）和雇佣记录，按下面的判定归档。用 `zkillboard.com/api/stats/characterID/<ID>/` 看量级；zKB 列表接口按时间筛选用 `/year/<年>/month/<月>/` 或 `/shipTypeID/<ID>/`，`startTime`／`endTime` 会被忽略。用 `git grep -n "<ID>" src/battles` 查新号的站内参战记录。
4. **分档**：每个候选归入“确认”“待定”“排除”。待定的号用选择题问维护者，不自行并入。
5. **登记**：确认的号写进 `<ID>-id.json` 的 `identity.alts`（`id`、`name`、一句话 `basis`、`sources` 指向本人素材身份一节），本人素材身份一节逐号写清依据，待定与排除也留在这里；依据只写事实和来源。然后跑 `node scripts/research/zkb-stats.mjs <短名>` 补战绩，用 `scripts/activity.mjs` 的 `personCombat` 重算战神标准；正文里有小号数量或参战描述的按新结果改实；更新提到这些角色的 `docs/corporations/notes/` 调查记录。
6. **验收**：跑 `node scripts/person-identity.mjs <短名>`、`npm run materials:check`、`npm run corporations:check`、`node scripts/fetch-characters.mjs --check`；正文有改动时按 `add-person` 第 4、5 步重登 `combat` 与 `writing-depth`。向维护者汇报：确认了哪些号、各自最强的一条依据、待定号的疑点与选项、没查完的线索和原因。

## 判定

- **强依据**（任一条，再加同团或同场即可并号）：与已确认号同分钟进出同一军团且不止一次；种子所建马甲团的建团人或成员几乎全是种子；建号日紧贴马甲团创建或已确认号入团的日子；名字成对（同词根、同姓氏、编号）；简介、诗句或签名与本人逐字相同；本人自报。
- **旁证**（加固，不单独定案）：无外人的多开编队反复出现；同场同款装配；几十秒内同星系先后爆船；诱导号与投送号的固定搭配；长期两人击杀。
- **待定**：比主号建号更早、早年在其他势力活动、长期休眠后复出、曾击杀主号，或只在某段时期与本人同操的号，写明时段和疑点，问清是本人更早的号、买来的号还是熟人共用，确认前不进 `identity.alts`。
- **不算依据**：只是同一大团或同联盟、只有常见头衔、只有相似建号日、只在大型会战同场。售号后的新持有人不归原主。

临时脚本放在 `.cache/` 下，所有请求走 `scripts/research/request-guard.mjs`；EveWho 每次运行最多 8 次请求，报预算用尽或 403／429 就停，记下已查和未查的线索、军团与角色，不换脚本续跑。
