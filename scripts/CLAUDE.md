# 脚本代理约定

适用于本目录及子目录，继承根目录指令。共同标准见[仓库统一标准](../docs/repository-standards.md)。

- 正式工具在这里维护；取材工具另遵守 `research/` 的下级指令。先找现有读取器、查询器、统计函数和测试，再增加脚本。
- 路径从 `import.meta.url` 或显式传入的仓库根目录解析，不硬编码本机路径。Node 版本支持范围以 `package.json` 为准。
- 可复用核心逻辑与 CLI 分开，导入核心模块不启动抓取或写文件；CLI 明确帮助、参数校验、输出和非零退出码。已有纯入口脚本保持职责，不为形式拆文件。
- JSON／TSV 结构与默认分页保持稳定；机器读取输出不混入进度日志。报错交代文件、对象或参数，不吞掉非预期错误。
- 抓取保留原始来源与时间，刷新只替换约定字段；不以重抓覆盖人工身份和分方。不绕过 `research/request-guard.mjs` 的取材限制。
- 自动测试使用 `node:test`，正式工具测试为同目录 `*.test.mjs`，取材测试在 `research/tests/`。文件场景使用独立临时目录并清理，网络、时间等通过可注入边界控制。
- 改脚本跑 `npm test`，按任务补充实际行为与失败路径验证；再执行根目录的完整验收。不能通过缩小测试 glob、弱化校验或更新豁免掩盖新问题。
