# 取材工具代理约定

适用于本目录及子目录，继承上级指令。共同标准见[仓库统一标准](../../docs/repository-standards.md)。

- 本目录不接入网站运行时；联网前读[取材手册](../../docs/research-method.md)对应平台入口，批量调查先读 `research-community` 技能。
- 正式 HTTP 请求复用 `request-guard.mjs` 的预算、串行间隔、拦截停止和共享冷却；不得换入口、换工具或重试循环绕过停止状态。
- 优先复用已连接的浏览器会话与公开文字入口；遵守本任务阅读范围，不将文字抓取状态写成已看过影像。身份、作者、取得、核读、归档与入文状态分别维护。
- 大表通过 `query-table.mjs` 分页查询；输出保存来源、读取范围与可恢复缺口，不批量生成叙事套话。
- 核心逻辑可离线测试；测试放 `tests/*.test.mjs`，不得连接真实网站或依赖维护者本机账号、路径和浏览器端口。
- 验收跑 `npm test`；实际平台读取只在已授权的调查范围内验证，并如实区分离线测试与真实平台验证。
